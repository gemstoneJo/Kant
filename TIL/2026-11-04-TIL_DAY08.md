## 1. 함수 기본 개념 — `def`, 매개변수, `return`

```python
def greet(name, message="안녕하세요"):
    return f"{name}님, {message}"

print(greet("손흥민"))
print(greet("손흥민", "반갑습니다"))
```

| 문법 | 의미 |
| --- | --- |
| `def` | 함수를 정의하는 키워드 |
| `name`, `message` | 함수가 값을 받는 **매개변수(parameter)** |
| `"손흥민"` | 함수를 호출할 때 전달하는 **인자(argument)** |
| `message="안녕하세요"` | 인자가 생략됐을 때 사용하는 기본값 |
| `return` | 값을 반환하면서 **함수 전체를 즉시 종료** |
| `print()` | 값을 화면에 출력. `return`과 역할이 다름 |

- `return a, b`와 `return (a, b)`는 모두 두 값을 **튜플**로 반환한다.
- 반환한 튜플은 `x, y = 함수호출()` 형태로 **언패킹**할 수 있다.

> **참고:** 이 절의 코드는 개념 복습을 위한 예시이며 수업 원본 코드와 정확히 동일하다는 의미는 아니다.

## 2. 가변 인자 `*args`, `**kwargs`

| 표현 | 함수 내부에서 받는 자료형 | 용도 |
| --- | --- | --- |
| `*args` | 튜플(`tuple`) | 개수가 정해지지 않은 여러 **위치 인자** |
| `**kwargs` | 딕셔너리(`dict`) | 개수가 정해지지 않은 여러 **키워드 인자** |

```python
def show_scores(*scores):
    print(scores)

show_scores(90, 75, 85)  # (90, 75, 85)
```

```python
def show_profile(**info):
    print(info)

show_profile(name="손흥민", age=34)
# {'name': '손흥민', 'age': 34}
```

- `scores`는 여러 점수를 담고 있는 **전체 튜플**이다.
- `for score in scores:`에서 `score`는 현재 꺼낸 **점수 하나**다.
- `len(scores)`는 전달한 점수의 개수를 반환한다.
- `plue`와 `plus`처럼 변수 이름의 철자가 서로 다르면 `NameError`가 발생할 수 있다.

## 3. 변수 스코프, `lambda`, `map()`, `filter()`

| 개념·함수 | 의미 |
| --- | --- |
| 지역 변수(local variable) | 보통 함수 내부에서 만들고 그 함수 안에서 사용하는 변수 |
| 전역 변수(global variable) | 함수 밖에서 정의한 변수. 같은 이름의 지역 변수와 구분 필요 |
| `lambda` | 간단한 함수를 표현식으로 작성 |
| `map()` | 데이터의 각 요소에 함수를 적용 |
| `filter()` | 조건에 맞는 요소만 선택 |
| `sum()` | 여러 수치의 합계 계산 |
| `len()` | 데이터 요소 개수 계산 |

**개념 복습 예시**

```python
numbers = [1, 2, 3, 4]

print(list(map(lambda x: x * 2, numbers)))
# [2, 4, 6, 8]

print(list(filter(lambda x: x % 2 == 0, numbers)))
# [2, 4]
```

> 12번 장바구니 문제에서는 `sum()`을 사용하지 않고 **`for`와 `+=`로 합계를 직접 계산하는 것**이 조건이었다.

## 4. `for`와 `while`의 차이

| 구분 | `for` | `while` |
| --- | --- | --- |
| 기본 원리 | 범위나 데이터에서 요소를 하나씩 순회 | 조건이 `True`인 동안 반복 |
| 적합한 예 | 상품 가격 전체 합산, 학생 전체 점수 검사 | 사용자가 종료할 때까지 게임 진행 |
| 횟수 관리 | `range()` 등으로 반복 범위 지정 | 카운터와 종료 조건을 직접 만들 수 있음 |
| 주의할 점 | 반복 변수와 누적 변수를 혼동하지 않기 | 종료 조건이 없으면 무한 반복 가능 |

- `range(1, 6)`은 `1, 2, 3, 4, 5`를 순회하며 **5번** 반복한다.
- `while`에도 시도 횟수 제한을 둘 수 있다.
- `for` 역시 일정 횟수를 정해 게임을 진행할 때 사용할 수 있다.

## 7. 문제 12 — 장바구니 계산기 [최종 완성]

### 요구사항

1. `*prices`로 여러 상품 가격을 전달받는다.
2. `sum()` 없이 `for`와 `+=`를 사용해 총액을 계산한다.
3. **총액 50,000원 이상이면 무료 배송**, 미만이면 배송비 3,000원이다.
4. 빈 장바구니는 `(0, 0, 0)`을 반환한다.
5. `(상품 합계, 배송비, 최종 결제 금액)` 순서로 반환한다.

### 최종 코드

```python
# 총 가격 total_price, 배송비 shipping_fee, 최종 결제 금액 final_price

def calculate_cart(*prices):
    total_price = 0

    if len(prices) == 0:
        return (0, 0, 0)

    for price in prices:
        total_price += price

    if total_price >= 50000:
        shipping_fee = 0
    else:
        shipping_fee = 3000

    final_price = total_price + shipping_fee
    return (total_price, shipping_fee, final_price)

print(calculate_cart(20000, 15000, 18000))
print(calculate_cart(10000, 12000))
print(calculate_cart(50000))
print(calculate_cart())
```

**실행 결과**

```text
(53000, 0, 53000)
(22000, 3000, 25000)
(50000, 0, 50000)
(0, 0, 0)
```

### 가장 헷갈렸던 세 변수

| 변수 | 역할 | 예시 |
| --- | --- | --- |
| `prices` | 전체 상품 가격을 담는 튜플 | `(20000, 15000, 18000)` |
| `price` | 현재 반복에서 꺼낸 상품 가격 하나 | `20000` |
| `total_price` | 계속 더해 나가는 합계 | `0 → 20000 → 35000 → 53000` |

### 직접 겪은 오류 → 수정 이유

| 잘못 작성한 부분 | 원인과 수정 |
| --- | --- |
| `for prices in total_price:` | `total_price`는 정수이므로 순회 대상이 아님. `prices`를 순회해야 함 |
| `for total_price in prices:` | 합계 변수에 현재 가격을 덮어씀. 반복 변수 `price`를 따로 사용 |
| `total_price += prices` | `prices`는 전체 튜플. 매회 꺼낸 숫자 `price`를 더해야 함 |
| `else total_price < 50000` | `else`에는 조건을 쓰지 않음. `else:`가 올바른 문법 |
| `else` | 끝에 `:`가 빠지면 `SyntaxError` 발생 |
| 배송비 조건을 반복문 안에서 계산 | 합계를 모두 구한 **뒤** 배송비를 한 번 판단해야 함 |

**기억할 표현**

```python
for price in prices:
    total_price += price
```

> `for A in B`는 **B에서 값을 하나씩 꺼내 A에 담는다**는 뜻이다.

## 8. 문제 13 — 시험 점수 합격·불합격 집계 [최종 완성]

### 요구사항

- 각 학생의 점수가 하나씩 주어진다.
- 학생마다 **80점 이상이면 합격**, 80점 미만이면 불합격으로 판정한다.
- 평균이 80점인지 판단하거나, 한 학생이 불합격했다고 전체가 탈락하는 문제가 아니다.
- 합격자 수와 불합격자 수를 각각 누적한다.
- `(합격자 수, 불합격자 수)` 튜플을 반환한다.

### 최종 코드

```python
def count_pass_fail(*scores):
    if len(scores) == 0:
        return (0, 0)

    pass_count = 0
    fail_count = 0

    for score in scores:
        if score >= 80:
            pass_count += 1
        else:
            fail_count += 1

    return (pass_count, fail_count)

print(count_pass_fail(90, 75, 85, 60, 100))
print(count_pass_fail(80, 79, 95))
print(count_pass_fail(50, 60, 70))
print(count_pass_fail())
```

**실행 결과**

```text
(3, 2)
(2, 1)
(0, 3)
(0, 0)
```

### 수정 과정에서 가장 중요했던 부분

**처음 작성한 코드**

```python
for score in scores:
    if score >= 80:
        return "합격"
    else:
        return "불합격"
```

**문제점**

1. 첫 번째 학생에게서 바로 `return`하므로 나머지 학생을 검사하지 않는다.
2. 문제의 정답은 `"합격"`이라는 문자열이 아니라 **합격자와 불합격자의 수**다.
3. 반복문 밖에서 다시 `if score >= 80:`를 검사해도 마지막 학생만 판정하므로 불필요하다.

**해결한 방법**

- `pass_count = 0`과 `fail_count = 0`을 초기화한다.
- 매 학생마다 조건에 맞는 변수에 `+= 1`을 사용한다.
- 반복을 모두 끝내고 `return (pass_count, fail_count)`를 실행한다.

참고로 `return(pass_count, fail_count)`도 정상 동작하지만, **`return (pass_count, fail_count)`처럼 공백을 넣는 스타일**을 권장한다.

## 9. 오늘 실수 총정리

| 실수 유형 | 잘못된 예시 | 교훈 |

| 숫자 | 선택 |
| --- | --- |
| `1` | 가위 ✌️ |
| `2` | 바위 ✊ |
| `3` | 보 ✋ |

**선택 기능(기본 구현 완료 후):** 사용자 이름, 3판 2선승, 라운드 기록, 연승 기록.

**오늘 배운 문법과 연결하기**

- 컴퓨터 선택 → `random.randint()`
- 사용자 입력 → `input()`
- 승패 판정 → `if / elif / else`
- 전적 누적 → `+= 1`
- 게임 반복 → `while`
- 종료 → `break`
