## 2. 상품 클래스 구현

```python
class Product:
    def __init__(self, name, price, stock):
        self.name = name
        self.price = price
        self.stock = stock

product1 = Product("무선이어폰", 89000, 3)
product2 = Product("텀블러", 15000, 10)
product3 = Product("보조배터리", 32000, 5)
product4 = Product("마우스패드", 9000, 0)
product5 = Product("USB 허브", 18000, 3)
```

- `Product`: 상품을 표현하는 클래스
- `__init__()`: 객체 생성 시 실행되는 초기화 메서드
- `self.name`: 상품 이름을 저장하는 인스턴스 변수
- `self.price`: 상품 가격
- `self.stock`: 상품 재고

**헷갈렸던 부분:** `Product`는 부모 클래스가 아니라 일반 클래스다. 다른 클래스가 `Product`를 상속할 때 부모 클래스가 된다.

## 3. 상품 번호와 리스트 인덱싱

```python
number = int(input("상품 번호: "))
item = products[number - 1]
```

사용자에게 표시하는 상품 번호는 1부터 시작하지만, 파이썬 리스트의 인덱스는 0부터 시작한다.

| 상품 번호 | 리스트 인덱스 | 상품 |
|---|---|---|
| 1 | 0 | 무선이어폰 |
| 2 | 1 | 텀블러 |
| 3 | 2 | 보조배터리 |
| 4 | 3 | 마우스패드 |
| 5 | 4 | USB 허브 |

사용자가 `2`를 입력하면 `products[1]`을 조회하여 텀블러 객체를 가져온다.

`number`와 `item`은 파이썬 예약어가 아닌 개발자가 정한 변수 이름이다.

```python
product_number = int(input("상품 번호: "))
selected_product = products[product_number - 1]
```

이렇게 변경해도 동일하게 작동한다.

**주의:** `0`을 입력하면 `products[-1]`이 되어 마지막 상품이 선택된다. 상품 번호의 범위 검사가 필요하다.

## 4. 장바구니 담기

장바구니는 딕셔너리로 관리했다.

```python
cart = {}
```

상품 번호를 키로, 수량을 값으로 저장한다.

```python
cart = {
    2: 4,
    3: 2
}
```

위 코드는 텀블러 4개, 보조배터리 2개가 담긴 상태다.

### 기존 수량 확인

```python
already_qty = cart.get(number, 0)
```

`get()`은 딕셔너리에서 키에 해당하는 값을 가져온다.

- `number`: 조회할 상품 번호
- `0`: 해당 상품이 없을 때 반환할 기본값
- `already_qty`: 기존에 담긴 수량을 저장하는 변수

`cart[number]`는 키가 없으면 `KeyError`가 발생하지만, `cart.get(number, 0)`은 기본값 0을 반환한다.

### 재고 확인 및 수량 누적

```python
already_qty = cart.get(number, 0)
available_qty = item.stock - already_qty

if qty > available_qty:
    print("재고가 부족합니다.")
    return

cart[number] = already_qty + qty
```

**중요:** 장바구니에 담는 단계에서는 실제 재고를 차감하지 않는다. 결제가 완료될 때 재고를 차감하는 방식으로 설계했다.

## 5. 장바구니 빼기

처음에는 다음 코드를 사용했다.

```python
del cart[number]
```

하지만 이 코드는 해당 상품을 전부 삭제한다.

원하는 수량만 빼기 위해 다음과 같이 수정했다.

```python
already_qty = cart[number]
qty = int(input("뺄 수량: "))

if qty <= 0:
    print("수량은 1개 이상 입력하세요.")
    return

if qty > already_qty:
    print("장바구니 수량이 부족합니다.")
    return

cart[number] = already_qty - qty

if cart[number] == 0:
    del cart[number]
```

### 오늘 발생한 오류

텀블러 4개 중 2개를 뺐는데 장바구니 조회 시 여전히 4개로 출력되는 문제가 있었다.

원인은 수량을 차감한 결과를 딕셔너리에 저장하는 코드가 누락된 것이었다.

```python
cart[number] = already_qty - qty
```

이 코드를 추가하여 해결했다.

또한 `if qty < 0:`은 0을 허용하므로 `if qty <= 0:`으로 변경해야 한다.

## 6. 장바구니 조회와 합계 계산

```python
def show_cart():
    if not cart:
        print("장바구니가 비어있습니다.")
        return

    total = 0

    for number, qty in cart.items():
        item = products[number - 1]
        price = item.price * qty
        total += price

        print(f"{item.name} x {qty} = {price:,}원")

    print(f"상품합계 {total:,}원")
```

### 주요 개념

| 코드 | 의미 |
|---|---|
| `if not cart:` | 장바구니가 비어 있는지 확인 |
| `cart.items()` | 딕셔너리의 키와 값을 함께 가져옴 |
| `item.price * qty` | 상품별 금액 계산 |
| `total += price` | 전체 금액 누적 |
| `{price:,}` | 천 단위 쉼표 표시 |

예시:

```text
텀블러 x 2 = 30,000원
보조배터리 x 2 = 64,000원
상품합계 94,000원
```

## 8. 할인 쿠폰 클래스 학습

할인 쿠폰을 구현하기 위해 상속과 오버라이딩 구조를 학습했다.

```python
class Discount:
    def discount_amount(self, total):
        return 0

class RateDiscount(Discount):
    def discount_amount(self, total):
        return min(int(total * 0.1), 5000)

class FixedDiscount(Discount):
    def discount_amount(self, total):
        if total >= 20000:
            return 3000
        return 0
```

| 클래스 | 역할 |
|---|---|
| `Discount` | 기본 할인 없음 |
| `RateDiscount` | 10% 할인, 최대 5,000원 |
| `FixedDiscount` | 20,000원 이상 구매 시 3,000원 할인 |

**상속:** `class RateDiscount(Discount)`는 `Discount`를 상속한다.

**오버라이딩:** 부모 클래스와 같은 이름의 `discount_amount()`를 자식 클래스에서 재정의한다.

**다형성:** 동일한 `discount_amount(total)` 호출이 객체의 종류에 따라 다르게 동작한다.

쿠폰 기능은 개념과 구현 코드를 학습했으며, 실제 프로그램에 최종 반영했는지는 별도 확인이 필요하다.
