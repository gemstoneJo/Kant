## 오늘 사용한 명령어&함수&메서드

> 함수와 메서드의 차이 : 함수는 print()처럼 독립적으로 호출할 수 있고, 메서드는 fruits.append()처럼 특정 객체에 소속되어 호출되는 함수

```
print("Hello")           # 함수
fruits.append("apple")   # 메서드
```

## 함수

`print()`: 괄호 안의 값을 출력 ex) print("hello") -> # hello

`ord()` : 문자 하나의 Unicode 포인트를 정수로 변환 ex)ord("a") -> # 97

`len()` : 문자열이나 리스트등의 요소의 갯수를 반환 ex) len(1,2,3) -> # 3
 
`type()` : 데이터의 자료형 확인 ex) type(10) -> # <class 'int'>

`susgetsizeof()` : 객체가 차지하는 메모리 크기를 바이트 단위로 변환 sys.getsizeof(1,2,3), 사용 전에 import sys가 필요하고, 반환값은 환경에 따라 달라질 수 있음

## 메서드

`.format` : 문자열의 특정한 위치에 값을 넣어 출력 형식 구성 ex) "안녕 {}".format("철수") -> # 안녕 철수

`append()` : 리스트 맨 뒤에 요소 하나 추가 

`insert()` : 리스트의 지정한 인덱스에 요소 삽입 ex) fruits.insert(0,kiwi)

`remove()` : 리스트에서 지정한 값과 일치하는 첫 번째 요소 삭제 ex) fruits.remove(apple)

## 논리&포함 연산자

`in` : 특정 값이 포함되어 있는지 확인

`not in` : 특정 값이 포함되지 않았는지 확인

`and` : 두 조건이 모두 참일 때 True

`or` : 조건 중 하나 이상이 참이면 True

`not` : 논리 값을 반대로 바꿈

### format 방식

print(format_str) # 주문내역: Cake 2 -> 총     13,000원

format_str = f"주문내역: {name} {qty} -> 총 {(price*qty):<10,}원" # 좌측정렬

## 리스트와 튜플

| 구분 | 리스트 (List) | 튜플 (Tuple) |
|---|---|---|
| 표기 방법 | 대괄호 `[]` | 소괄호 `()` |
| 생성 예시 | `[1, 2, 3]` | `(1, 2, 3)` |
| 가변성 | 가변 (Mutable) | 불변 (Immutable) |
| 요소 수정 | 가능 | 불가능 |
| 요소 추가 | 가능 | 불가능 |
| 요소 삭제 | 가능 | 불가능 |
| 인덱싱 | 가능 | 가능 |
| 슬라이싱 | 가능 | 가능 |
| 메모리 사용량 | 일반적으로 더 큼 | 일반적으로 더 작음 |
| 주요 메서드 | `append()`, `insert()`, `remove()` | `count()`, `index()` |
| 사용 목적 | 변경이 필요한 데이터 | 고정된 데이터 |

### 슬라이싱

| 구분 | 인덱싱 (Indexing) | 슬라이싱 (Slicing) |
|---|---|---|
| 의미 | 특정 위치의 요소 하나를 가져옴 | 지정한 범위의 요소를 가져옴 |
| 기본 문법 | `변수[인덱스]` | `변수[시작:끝:간격]` |
| 사용 예시 | `numbers[2]` | `numbers[1:4]` |
| 반환 결과 | 요소 하나 | 여러 요소로 구성된 새로운 자료구조 |
| 시작 위치 | 0부터 시작 | 0부터 시작 |
| 음수 인덱스 | 사용 가능 | 사용 가능 |
| 리스트 사용 | 가능 | 가능 |
| 튜플 사용 | 가능 | 가능 |
| 범위 초과 | `IndexError` 발생 | 가능한 범위까지만 반환 |


### 슬라이싱 실습

numbers = [0, 1, 2, 3, 4, 5]

#### 1번 부터 4번 미만까지

print(numbers[1:4]) # [1, 2, 3]

#### 2칸 간격으로 추출

print(numbers[::2])  # [0, 2, 4]

#### 역순

print(numbers[::-1]) # [5, 4, 3, 2, 1, 0]

#### 앞에서 3개만 추출

print(numbers[:3]) # [0, 1, 2]

#### 3번부터 끝까지

print(numbers[3:]) # [3, 4, 5]
