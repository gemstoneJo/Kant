### 오늘 사용한 명령어 

1. `winget search uv` : windows 패키지 관리자에서 uv 프로그램을 검색
2. `winget install uv` : uv프로그램을 설치
3. `uv --version` : 현재 설치된 uv의 버전을 확인

---

4. `uv_init` : 현재 폴더 초기화
5. `uv init --no-package --python 3.13` : pthon의 버전을 3.13으로 지정하면서 파이썬을 초기화
6. `uv run main.py` : 프로젝트의 가상환경을 이용해 `main.py`를 실행함. 없다면 자동으로 생성
7. `uv python pin 3.12` : 프로젝트에서 사용할 파이썬 버전을 3.12로 지정하고 `python-verson`파일을 생성한다.

---

8. `uv add fastapi` : 프로젝트에 Fastapi 패치키를 추가하고 필요한 의존성을 설치한다.
9. `uv add ipykernel` : jupyter Notebook에서 python 코드를 실행하기 위한 커널 패키지를 추가한다. 
10. `uv sync` : `uv.lock`를 기준으로 프로젝트의 가상환경의 패키지 구성을 동기화
11. `uv sync --depth 1` : 프로젝트의 의존성 구조를 한 단계 깊이까지 표시

---

12. `which python` : 현재 터미널에 실행될 python 프로그램의 경로 확인
13. `source .venv/Scripts/activate` : Git Bash 에서 프로젝트의 Python 가상환경을 활성화한다.
14. `deactivate` : 활성화된 python 가상환경을 종료한다.

---
15. `cat .python-version` : 프로젝트의 지정된 python 버전 확인
16. `touch chapter01.inynb`: `chaper01.inynb`라는 빈 파일을 생성

---

17. `Ctrl + P` : VsCode에서 파일을 빠르게 검색하고 연다
18. `Ctrl + Shift + P` : VS Code 명령 팔레트를 연다.
19. `Ctrl + Space` : 코드 자동완성 목록을 표시한다.
20. `DD` : 명령 모드에서 현재 셀을 삭제한다.
21. `A` : 현재 셀 위에 새 셀 추가
22. `B` : 현재 셀 아래에 새 셀 추가
23. `M` : 현재 셀을 Markdown 셀로 변경
24. `Y` : 현재 셀을 Code 셀로 변경
25. `Ctrl + Ent` : 현재 셀 실행
26. `Shift + Ent` : 현재 셀을 실행 후 다음 셀로 이동
