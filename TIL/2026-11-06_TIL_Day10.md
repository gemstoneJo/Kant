## 2. 핵심 개념 정리

### 2-1. 딕셔너리로 가위바위보 데이터 관리

```python
HANDS = {1: "가위", 2: "바위", 3: "보"}
```
딕셔너리는 `key: value` 형태로 데이터를 저장하는 자료구조다.

| Key | Value |
|---|---|
| `1` | `"가위"` |
| `2` | `"바위"` |
| `3` | `"보"` |

**사용 예시**

```python
print(HANDS[1])  # 가위
print(HANDS[2])  # 바위
print(HANDS[3])  # 보
```

- `HANDS`는 가위바위보 정보를 저장하는 변수다.
- 대문자 변수명은 일반적으로 상수를 나타내는 관례다.
- `HANDS[번호]`를 사용하면 해당 번호에 연결된 문자열을 가져올 수 있다.
* 처음 배우는 내용이었는데 앞으로 코딩할 때 이 방식을 활용하면 코드를 더 짧고 보기 쉽게 짤 수 있을 것 같다. 

### 2-2. 함수로 게임 타이틀 출력

```python
def show_title():
    print("=" * 40)
    print("가위/바위/보 게임")
    print("=" * 40)
```

`def`는 함수를 정의할 때 사용하는 키워드다.

`"=" * 40`은 문자열 `"="`을 40번 반복한다.

**함수 정의와 호출의 차이**

```python
show_title    # 함수 객체를 참조
show_title()  # 함수를 실제로 실행
```

함수를 정의하는 것만으로는 실행되지 않으며, `()`를 붙여 호출해야 한다.

### 2-3. 사용자 입력과 공백 제거

```python
def ask_name():
    name = input("플레이어 이름을 입력하세요.").strip()

    if name == "":
        name = "게스트"

    return name
```

**`input()`**

사용자가 키보드로 입력한 값을 문자열로 반환한다.

**`strip()`**

문자열 양쪽의 공백과 줄바꿈 문자를 제거한다.

```python
name = "  원석  "
print(name.strip())  # 원석
```

**`if name == ""`**

입력값이 빈 문자열인지 확인한다.

사용자가 이름을 입력하지 않고 Enter만 누르거나 공백만 입력하면 `"게스트"`가 저장된다.

**`return name`**

함수에서 처리한 이름을 호출한 곳으로 반환한다.

### 2-4. random 모듈로 난수 생성

```python
import random

computer_number = random.randint(1, 3)
```

`random`은 무작위 값을 생성하는 파이썬 표준 라이브러리 모듈이다.

`randint(a, b)`는 a 이상 b 이하의 정수를 무작위로 반환한다.

따라서 `random.randint(1, 3)`은 `1`, `2`, `3` 중 하나를 반환한다.

### 2-5. 난수와 딕셔너리 연결

```python
computer_number = random.randint(1, 3)

print(f"컴퓨터는 {HANDS[computer_number]}를 냈습니다.")
```

실행 흐름:

1. `random.randint(1, 3)`으로 난수 생성
2. 생성된 숫자를 `computer_number`에 저장
3. `HANDS[computer_number]`로 해당하는 손 조회
4. f-string으로 결과 출력

예를 들어 `computer_number = 2`라면 `HANDS[2]`는 `"바위"`가 된다.

## 3. 오늘 작성한 전체 실습 코드

```python
# 가위 바위 보 게임 (3판 2선승제)

import random

# 번호와 손 저장한 딕셔너리
HANDS = {1: "가위", 2: "바위", 3: "보"}

# 게임 타이틀 출력
def show_title():
    print("=" * 40)
    print("가위/바위/보 게임")
    print("=" * 40)

# 플레이어 이름 입력
def ask_name():
    name = input("플레이어 이름을 입력하세요.").strip()
    if name == "":
        name = "게스트"

    return name

# 게임의 전체 루프
def main():
    show_title()
    name = ask_name()

    computer_number = random.randint(1, 3)

    print(f"{name}님, 컴퓨터는 {HANDS[computer_number]}를 냈습니다.")
    print(computer_number)

# 게임 시작
main()
```

### 실행 결과 예시

```text
========================================
가위/바위/보 게임
========================================
플레이어 이름을 입력하세요.원석
원석님, 컴퓨터는 바위를 냈습니다.
2
```

**현재 구현 상태**

게임 타이틀 출력, 플레이어 이름 입력, 컴퓨터의 무작위 선택 및 결과 출력까지 구현했다.

아직 플레이어의 가위바위보 선택, 승패 판정, 2선승제 반복 기능은 구현하지 않았다.

## 4. 오늘 발생한 오류와 해결 방법

### 오류 1. 모듈 이름 오타

```python
import landom  # 잘못된 코드
import random  # 올바른 코드
```

**원인:** `random`을 `landom`으로 잘못 입력했다.

존재하지 않는 모듈을 불러오면 `ModuleNotFoundError`가 발생한다.

### 오류 2. 문자열 메서드 호출 오류

```python
name = input("플레이어 이름을 입력하세요.")strip()
```

**원인:** `strip()` 앞에 점(`.`)이 누락되었다.

**수정**

```python
name = input("플레이어 이름을 입력하세요.").strip()
```

문자열 메서드는 일반적으로 `문자열.메서드()` 형태로 호출한다.

### 오류 3. 함수 호출 괄호 누락

```python
name = ask_name
```

**원인:** 함수 이름만 사용하여 함수가 실행되지 않았다.

**수정**

```python
name = ask_name()
```

함수 이름만 작성하면 함수 자체를 참조하고, `()`를 붙이면 함수를 실행한다.

### VS Code 환경 관련 문제

수업 시작 시 VS Code에서 한글, 숫자 등의 문자 주변에 노란색 테두리가 나타나는 현상이 발생했다.

- 유니코드 강조 설정을 비활성화했지만 해결되지 않았다.
- 검색 및 선택 강조, 확장 프로그램 등 다른 원인을 확인할 필요가 있다.
- 원인은 아직 확정되지 않았다.

추가로 `F5` 실행 시 터미널로 입력 포커스가 이동하지 않는 현상을 질문했다.

`F5`는 디버깅 시작, `Ctrl + F5`는 디버깅 없이 실행하는 단축키다. 실행 결과가 터미널에 표시되는 것과 키보드 포커스가 이동하는 것은 별개다.
