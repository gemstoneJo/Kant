## 2. 딕셔너리(Dictionary)

딕셔너리는 `key: value` 형태로 데이터를 저장한다. 키는 중복될 수 없고, 값은 중복될 수 있다. Python 3.7 이상에서는 삽입 순서가 보장된다.

```python
user_info = {"name": "손흥민", "age": 30, "role": "Player"}
print(user_info["name"])  # 손흥민
user_info["age"] = 31     # 기존 값 변경
user_info["team"] = "Tottenham"  # 새 키 추가
del user_info["role"]     # 키 삭제
```

| 메서드 | 기능 | 예시 |
|---|---|---|
| `keys()` | 모든 키 조회 | `menu.keys()` |
| `values()` | 모든 값 조회 | `menu.values()` |
| `items()` | 키·값 쌍 조회 | `menu.items()` |
| `get()` | 키 조회, 없으면 기본값 반환 | `menu.get("cake", 5000)` |
| `pop()` | 키 삭제 후 값 반환 | `menu.pop("coffee")` |

```python
menu = {"coffee": 4000, "tea": 4500}
print(list(menu.keys()))       # ['coffee', 'tea']
print(sum(menu.values()))      # 8500
print(menu.get("cake", 5000))  # 5000
print("coffee" in menu)        # True: 키 검사
print(4000 in menu.values())   # True: 값 검사
```

**주의:** `menu["cake"]`는 `KeyError`가 발생하지만 `menu.get("cake")`는 `None`을 반환한다. `get()`은 기본값을 반환할 뿐 새 키를 추가하지 않는다. `del`은 메서드가 아닌 문장이다.

## 3. 집합(Set)

집합은 중복 원소를 허용하지 않고, 원소의 순서도 보장하지 않는다.

```python
numbers = {1, 2, 2, 3}
print(len(numbers))  # 3
numbers2 = set([1, 2, 2, 3, 3])
```

| 구분 | 딕셔너리 | 집합 |
|---|---|---|
| 저장 형태 | 키·값 | 고유한 원소 |
| 중복 | 키 중복 불가 | 원소 중복 불가 |
| 순서 | 삽입 순서 보장 | 순서 보장 안 됨 |
| 빈 자료형 | `{}` | `set()` |

> `{}`는 빈 집합이 아니라 빈 딕셔너리다.

## 4. 조건문

### 4.1 `if`, `elif`, `else`

```python
score = 95
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
# 출력: A
```

조건은 위에서 아래로 검사한다. **처음 참이 된 `if`/`elif` 블록만 실행**되므로 순서가 중요하다.

```python
score = 95
if score >= 80:
    print("B")
elif score >= 90:
    print("A")
# 출력: B
```

### 4.2 들여쓰기와 참·거짓 판정

```python
temp = 30
if temp >= 28:
    print("에어컨을 켭니다.")
    print("1시간 후에 자동 종료됩니다.")
print("프로그램 종료")  # if 블록 밖: 조건과 무관하게 실행

cart = ["카메라", "삼각대"]
if cart:
    print("결제를 진행합니다.")
else:
    print("장바구니가 비었습니다.")
```

- 빈 리스트 `[]`는 거짓, 요소가 있는 리스트는 참으로 평가된다.
- 조건문 블록은 일반적으로 공백 4칸으로 들여쓴다.

### 4.3 `and`, 삼항 조건 표현식, `pass`

```python
is_login = True
has_permission = True
if is_login and has_permission:
    print("관리자 페이지 이동")

age = 19
message = "성인" if age >= 20 else "미성년자"
print(message)  # 미성년자

if True:
    pass  # TODO: 나중에 구현할 코드
```

- `and`: 두 조건이 모두 참일 때 참
- `참일 때 값 if 조건 else 거짓일 때 값`: 삼항 조건 표현식
- `pass`: 아무 작업도 하지 않는 자리 채우기

## 5. `for` 반복문

```python
fruits = ["사과", "바나나", "체리"]
for fruit in fruits:
    print(fruit) # 사과 / 바나나 / 체리

for ch in "스파르타":
    print(ch) # 스 / 파 / 르 / 타

menu = {"아아": 4000, "홍차": 4500}
for key in menu:
    print(key)  # 아아 / 홍차
for name, price in menu.items():
    print(f"{name} : {price}") # 아아 : 4000 / 홍차 : 4500
```

**수업 코드 보완:** `for fruits in fruits:`보다는 리스트 변수 `fruits`와 요소 변수 `fruit`를 구분하는 편이 좋다.

### `range()`

`range(start, stop, step)`에서 **`stop`은 포함되지 않는다.**

| 코드 | 값 |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(1, 6, 2)` | 1, 3, 5 |
| `range(1, 6, 3)` | 1, 4 |

```python
for i in range(5):
    print(f"{i + 1} 번째 로직 수행")

print(range(5))       # range(0, 5)
print(list(range(5))) # [0, 1, 2, 3, 4]
```

## 6. `while` 반복문

조건이 참인 동안 반복한다.

```python
num = 1
while num <= 3:
    print(f"현재 숫자는 {num}입니다.")
    num += 1

count = 3
while count > 0:
    print(count)
    count -= 1
# 3, 2, 1
```

| 구분 | `for` | `while` |
|---|---|---|
| 기준 | 반복 가능한 데이터 | 조건식 |
| 활용 | 리스트 순회, 횟수 지정 | 입력 대기, 조건 충족까지 반복 |
| 주의 | 반복 범위 | 무한 반복 가능성 |

## 7. `break`, `continue`, `pass`

| 키워드 | 기능 |
|---|---|
| `break` | 현재 반복문을 즉시 종료 |
| `continue` | 현재 반복의 나머지 코드를 건너뛰고 다음 반복으로 이동 |
| `pass` | 아무 동작도 하지 않음 |

```python
for num in range(1, 6):
    if num == 3:
        print("즉시 종료")
        break
    print(num)
# 1, 2, 즉시 종료

for num in range(1, 6):
    if num % 2 == 0:
        continue
    print(f"홀수 {num}")
# 홀수 1 / 홀수 3 / 홀수 5
```

`num % 2 == 0`은 나머지가 0인지 확인하는 짝수 판별 조건이다.

## 8. 중첩 반복문 — 구구단

```python
for x in range(2, 10):
    print(f"---{x} 단 ---")
    for y in range(1, 10):
        print(f"{x} x {y} = {x * y}")
```

- 바깥 반복문: 2단부터 9단까지
- 안쪽 반복문: 각 단에서 1부터 9까지 곱하기

### `break`를 적용한 수업 실습

```python
for x in range(2, 10):
    if x == 4:
        break
    print(f"---{x} 단 ---")
    for y in range(1, 10):
        if y == 6:
            break
        print(f"{x} x {y} = {x * y}")
```

2단과 3단에서 각각 1~5까지만 출력된다. **중첩 반복문의 `break`는 가장 가까운 반복문 하나만 종료한다.**

## 9. 종합 실습 ① 회원 데이터 분석

### 실습 목표
- 활성 회원 필터링
- VIP/Gold 회원 쿠폰 발행 메시지 출력
- 활성 회원 수 집계
- 활성 VIP 회원 포인트 누적

```python
user_database = [
    {"name": "손흥민", "Level": "VIP", "active": True, "point": 15000},
    {"name": "손인욱", "Level": "VIP", "active": True, "point": 12000},
    {"name": "김찬호", "Level": "Gold", "active": True, "point": 10000},
    {"name": "장지환", "Level": "Silver", "active": False, "point": 8000},
    {"name": "정상길", "Level": "Bronze", "active": False, "point": 5000}
]

total_vip_point = 0
active_user_count = 0

print("=== 마케팅 대상 활성 VIP 및 Gold 회원 결과 ===")

for user in user_database:
    if user["active"]:
        active_user_count += 1
        if user["Level"] == "VIP":
            total_vip_point += user["point"]
            print(f"[VIP 등급] {user['name']} 회원님에게 VIP 쿠폰이 발행되었습니다.")
        elif user["Level"] == "Gold":
            print(f"[Gold 등급] {user['name']} 회원님에게 Gold 쿠폰이 발행되었습니다.")

print(f"전체 회원 수 : {len(user_database)}명")
print(f"전체 활성 회원 수 : {active_user_count}명")
print(f"활성 VIP 포인트 누적 : {total_vip_point}점")
```

### 실행 결과

```text
=== 마케팅 대상 활성 VIP 및 Gold 회원 결과 ===
[VIP 등급] 손흥민 회원님에게 VIP 쿠폰이 발행되었습니다.
[VIP 등급] 손인욱 회원님에게 VIP 쿠폰이 발행되었습니다.
[Gold 등급] 김찬호 회원님에게 Gold 쿠폰이 발행되었습니다.
전체 회원 수 : 5명
전체 활성 회원 수 : 3명
활성 VIP 포인트 누적 : 27000점
```

### 실행 흐름
1. `for`로 회원을 한 명씩 가져온다.
2. `user["active"]`가 참이면 활성 회원 수를 증가시킨다.
3. VIP이면 포인트를 누적하고 VIP 쿠폰 메시지를 출력한다.
4. Gold이면 Gold 쿠폰 메시지를 출력한다.
5. 전체 회원 수는 `len(user_database)`로 구할 수 있다.

**추가 질문:** 전체 회원 수를 구하기 위해 비활성 회원 수 변수를 반드시 추가할 필요는 없다. `len(user_database)`를 쓰거나 반복문 시작 부분에서 전체 카운터를 증가시키면 된다.

## 10. 종합 실습 ② 숫자 맞추기 게임

### 실습 목표
- 1~100 난수 생성
- 사용자 입력 및 유효성 검사
- Up/Down 힌트 출력
- 시도 횟수 집계
- 정답 또는 `q` 입력 시 종료

### 주요 기능

| 코드 | 역할 |
|---|---|
| `import random` | 난수 모듈 불러오기 |
| `random.randint(1, 100)` | 양 끝값을 포함한 무작위 정수 생성 |
| `input()` | 사용자 입력(문자열) |
| `isdecimal()` | 십진 숫자 문자열인지 확인 |
| `int()` | 정수로 변환 |
| `while True` | 반복 실행 |
| `continue` | 잘못된 입력 시 다음 반복 |
| `break` | 게임 종료 |
| `try_count += 1` | 유효한 시도 횟수 증가 |

### 오류 수정 코드

```python
import random

number = random.randint(1, 100)
try_count = 0

print("=" * 40)
print("컴퓨터가 1부터 100 사이의 숫자를 생성했습니다.")
print("=" * 40)

while True:
    user_input = input("컴퓨터의 숫자를 맞춰보세요 (1~100): ")

    if user_input == "q":
        print(f"게임 종료합니다. 정답은 {number}입니다.")
        break

    # int()로 변환하기 전에 먼저 검증
    if not user_input.isdecimal():
        print("숫자만 입력해 주세요.")
        continue

    user_number = int(user_input)

    if user_number < 1 or user_number > 100:
        print("1~100 사이의 숫자를 입력해주세요.")
        continue

    try_count += 1

    if user_number < number:
        print("Up! 더 큰 수 입니다.")
    elif user_number > number:
        print("Down! 더 작은 수 입니다.")
    else:
        print(f"정답입니다! {try_count}회 만에 성공했습니다.")
        break
```

### 발생한 오류와 해결

기존 코드에서는 다음 검사를 `isdecimal()`보다 먼저 실행했다.

```python
if int(user_input) > 100:
    ...
```

입력이 빈 문자열 `""`이면 `int("")`를 실행하면서 다음 오류가 발생한다.

```text
ValueError: invalid literal for int() with base 10: ''
```

**해결 순서:** `q` 확인 → `isdecimal()` 검사 → `int()` 변환 → 1~100 범위 검사 → 시도 횟수 증가 → 정답 비교.

또한 기존 코드의 `int(user_input) < 0`은 0을 허용하므로 `user_number < 1`로 수정했다.
