## 2. 오전 수업 — 가위바위보 프로그램 복습

### 2-1. 프로그램을 함수로 분리하는 이유

프로그램 전체를 하나의 함수에 작성하는 대신, 각 기능을 여러 함수로 나누어 구현했다.

예시 함수:

| 함수 | 역할 |
|---|---|
| `show_title()` | 게임 제목 출력 |
| `ask_name()` | 플레이어 이름 입력 |
| `ask_number()` | 가위·바위·보 번호 입력 및 검증 |
| `check_result()` | 승패 판정 |
| `show_result()` | 한 라운드 결과 출력 |
| `show_score()` | 현재 점수 출력 |
| `show_final_result()` | 최종 승패 출력 |
| `show_records()` | 게임 기록 출력 |
| `ask_play_again()` | 다시 플레이할지 확인 |
| `play_game()` | 한 게임의 전체 진행 |
| `main()` | 프로그램 전체 실행 관리 |

**함수를 분리하는 이유**

- 기능별로 코드를 관리할 수 있다.
- 오류가 발생한 위치를 찾기 쉽다.
- 같은 기능을 여러 번 재사용할 수 있다.
- 전체 프로그램의 실행 순서를 이해하기 쉽다.

### 2-2. `return`의 역할

`return`은 함수의 실행을 종료하고, 필요한 경우 값을 호출한 곳으로 돌려준다.

```python
def ask_number():
    while True:
        answer = input("1.가위 / 2.바위 / 3.보 : ")

        if answer in ("1", "2", "3"):
            return int(answer)

        print("1, 2, 3 중에서 입력하세요.")
```

**실행 흐름**

1. 사용자에게 번호를 입력받는다.
2. 올바른 번호인지 검사한다.
3. 올바르면 `return`으로 정수를 반환하고 함수를 종료한다.
4. 잘못 입력하면 오류 메시지를 출력하고 다시 입력받는다.

```python
number = ask_number()
```

반환된 숫자는 `number`에 저장된다.

### 2-3. `return True`와 `return False`

함수가 특정 조건을 만족하는지 알려줄 때 불리언 값을 반환할 수 있다.

```python
def ask_play_again():
    answer = input("다시 하시겠습니까? (y/n): ")

    if answer == "y":
        return True

    return False
```

```python
if ask_play_again():
    print("게임을 다시 시작합니다.")
else:
    print("게임을 종료합니다.")
```

- `True`: 조건을 만족함
- `False`: 조건을 만족하지 않음

### 2-4. `enumerate()`로 기록 출력하기

`enumerate()`는 반복 가능한 데이터의 순서 번호와 값을 함께 가져온다.

```python
records = ["승리", "패배", "무승부"]

for number, result in enumerate(records, start=1):
    print(f"{number}번째 경기: {result}")
```

실행 결과:

```text
1번째 경기: 승리
2번째 경기: 패배
3번째 경기: 무승부
```

| 코드 | 의미 |
|---|---|
| `records` | 기록이 저장된 리스트 |
| `enumerate(records)` | 인덱스와 값을 함께 가져옴 |
| `start=1` | 번호를 1부터 시작 |
| `number` | 현재 순서 번호 |
| `result` | 현재 리스트의 값 |

### 2-5. 게임 반복과 기록 관리

- `while` 반복문으로 게임을 계속 진행한다.
- 승리 횟수와 패배 횟수를 비교한다.
- 목표 승리 횟수에 도달하면 게임을 종료한다.
- 리스트에 라운드별 기록을 저장할 수 있다.
- 게임이 끝나면 다시 플레이할지 확인한다.
- 연속 승리 기록은 이전 결과와 현재 결과를 비교해 관리할 수 있다.

**주의:** `show_result()`처럼 출력만 담당하는 함수를 여러 곳에서 중복 호출하면 같은 결과가 반복 출력될 수 있다.

## 3. 클래스와 객체 복습

### 3-1. 클래스(Class)란?

클래스는 객체를 만들기 위한 설계도이다.

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

이 클래스는 사용자 이름과 나이를 저장하는 객체를 생성할 수 있다.

### 3-2. 객체와 인스턴스

```python
user1 = User("철수", 20)
user2 = User("영희", 25)
```

- `User`: 클래스
- `user1`: `User` 클래스로 생성한 인스턴스
- `user2`: 또 다른 인스턴스

각 인스턴스는 독립적으로 데이터를 저장한다.

```python
print(user1.name)  # 철수
print(user2.name)  # 영희
```

객체와 인스턴스는 비슷하게 사용되지만, **인스턴스는 특정 클래스로부터 생성되었다는 관계를 강조하는 표현**이다.

## 4. ⭐ 중요 복습 — `__init__`, `self`, `.`, `()`

오늘 특히 헷갈렸던 개념이다.

### 4-1. `__init__`이란?

인스턴스가 생성될 때 초기 상태를 설정하는 메서드이다.

```python
class User:
    def __init__(self, name):
        self.name = name
```

```python
user1 = User("철수")
```

`User("철수")`로 인스턴스를 생성하면 `__init__`이 호출되어 이름이 저장된다.

### 4-2. `self`란?

`self`는 **현재 메서드를 실행하는 인스턴스 자신**을 가리킨다.

```python
class User:
    def __init__(self, name):
        self.name = name
```

여기서:

- `name`: 외부에서 전달받은 매개변수
- `self.name`: 현재 인스턴스에 저장되는 속성

```python
user1 = User("철수")
user2 = User("영희")
```

각각의 `self.name`에는 서로 다른 값이 저장된다.

### 4-3. `name`과 `self.name`의 차이

| 구분 | `name` | `self.name` |
|---|---|---|
| 종류 | 지역 변수 또는 매개변수 | 인스턴스 속성 |
| 사용 범위 | 해당 함수 실행 범위 | 해당 인스턴스의 메서드에서 접근 가능 |
| 저장 목적 | 전달받은 값 처리 | 객체의 상태 저장 |
| 접근 예시 | `name` | `user1.name` |

### 4-4. `.`과 `()`의 차이

```python
user1.name
user1.show()
```

| 기호 | 의미 | 예시 |
|---|---|---|
| `.` | 객체의 속성이나 메서드에 접근 | `user1.name` |
| `()` | 함수·메서드 호출 | `user1.show()` |
| `=` | 값을 변수에 할당 | `name = "철수"` |
| `==` | 두 값이 같은지 비교 | `name == "철수"` |

**핵심:** `.`은 접근, `()`는 호출이다. 메서드를 실행하려면 일반적으로 괄호가 필요하다.

## 5. 상속(Inheritance)

### 5-1. 상속이란?

상속은 기존 클래스의 속성과 메서드를 새로운 클래스에서 재사용하는 기능이다.

- 부모 클래스(Parent Class): 공통 기능을 제공하는 클래스
- 자식 클래스(Child Class): 부모 클래스의 기능을 물려받는 클래스

### 5-2. Animal과 Dog 예제

```python
class Animal:
    def breath(self):
        print("숨을 쉽니다.")

    def sound(self):
        print("동물이 소리를 냅니다.")


class Dog(Animal):
    def bark(self):
        print("멍멍!")
```

```python
dog1 = Dog()

dog1.breath()
dog1.sound()
dog1.bark()
```

실행 결과:

```text
숨을 쉽니다.
동물이 소리를 냅니다.
멍멍!
```

`Dog` 클래스에는 `breath()`를 직접 작성하지 않았지만, 부모 클래스인 `Animal`에서 상속받았기 때문에 사용할 수 있다.

**상속 문법**

```python
class 자식클래스(부모클래스):
    pass
```

괄호 안에 부모 클래스를 작성한다.

## 6. 메서드 오버라이딩(Overriding)

### 6-1. 오버라이딩이란?

부모 클래스에 이미 정의된 메서드를 자식 클래스에서 다시 정의하는 것이다.

```python
class Animal:
    def sound(self):
        print("동물이 소리를 냅니다.")


class Cat(Animal):
    def sound(self):
        print("야옹!")
```

```python
cat1 = Cat()
cat1.sound()
```

실행 결과:

```text
야옹!
```

부모 클래스의 `sound()`가 아니라 자식 클래스에서 재정의한 `sound()`가 실행된다.

### 6-2. 상속과 오버라이딩 비교

| 구분 | 상속 | 오버라이딩 |
|---|---|---|
| 목적 | 기존 기능 재사용 | 기존 기능의 동작 변경 |
| 자식 클래스에 메서드 작성 | 필요하지 않을 수 있음 | 같은 이름으로 다시 작성 |
| 예시 | `Dog`가 `breath()` 사용 | `Cat`이 `sound()` 재정의 |

## 7. `super()` — 부모 클래스의 메서드 호출

자식 클래스에서 부모 클래스의 메서드를 사용하고 싶을 때 `super()`를 활용할 수 있다.

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age


class Student(Person):
    def __init__(self, name, age, grade):
        super().__init__(name, age)
        self.grade = grade
```

```python
student1 = Student("철수", 20, 3)

print(student1.name)
print(student1.age)
print(student1.grade)
```

실행 결과:

```text
철수
20
3
```

### 코드 해석

```python
super().__init__(name, age)
```

- `super()`: 부모 클래스의 메서드를 호출할 수 있게 함
- `.__init__`: 부모 클래스의 초기화 메서드에 접근
- `(name, age)`: 부모 초기화 메서드에 값을 전달

부모 클래스가 처리하는 이름과 나이는 재사용하고, 자식 클래스에 필요한 학년만 추가한다.

**주의:** 자식 클래스가 자체 `__init__`을 정의했다면 부모 클래스의 `__init__`이 자동으로 함께 실행되는 것은 아니다. 필요한 경우 `super().__init__()`을 명시적으로 호출해야 한다.

## 8. 다형성(Polymorphism)

다형성은 **같은 이름의 메서드를 호출하더라도 객체에 따라 다른 동작을 수행할 수 있는 성질**이다.

```python
class Animal:
    def sound(self):
        print("동물 소리")


class Dog(Animal):
    def sound(self):
        print("멍멍")


class Cat(Animal):
    def sound(self):
        print("야옹")
```

```python
animals = [Dog(), Cat()]

for animal in animals:
    animal.sound()
```

실행 결과:

```text
멍멍
야옹
```

같은 `sound()`를 호출했지만 객체의 종류에 따라 결과가 다르다.

오버라이딩은 이러한 다형성을 구현하는 대표적인 방법이다.

## 9. ⭐ 중요 복습 — `return`, `break`, `continue`

| 구분 | 역할 | 종료 범위 |
|---|---|---|
| `return` | 함수 종료 및 값 반환 | 현재 함수 |
| `break` | 반복문 종료 | 가장 가까운 반복문 |
| `continue` | 현재 반복의 나머지를 건너뜀 | 다음 반복으로 진행 |

### `return` 예시

```python
def test():
    print("시작")
    return 10
    print("종료")

result = test()
print(result)
```

실행 결과:

```text
시작
10
```

`return` 아래의 `print("종료")`는 실행되지 않는다.

### `break` 예시

```python
while True:
    answer = input("종료하려면 q: ")

    if answer == "q":
        break
```

`q`를 입력하면 반복문이 종료된다.

### `continue` 예시

```python
for number in range(1, 6):
    if number == 3:
        continue

    print(number)
```

실행 결과:

```text
1
2
4
5
```

`3`일 때는 아래의 출력문을 건너뛰고 다음 반복으로 진행한다.

## 12. 오늘의 회고

오늘은 기존에 배운 함수와 클래스 개념을 바탕으로 객체지향 프로그래밍의 구조를 더 깊이 이해했다.

특히 클래스를 단순히 만드는 것에서 나아가, 부모 클래스의 기능을 상속받고 필요한 메서드를 재정의하는 방법을 학습했다.

아직 `self`, `__init__`, 속성 접근과 메서드 호출의 차이가 헷갈릴 수 있으므로, 실제 인스턴스를 생성하고 메서드를 호출하는 코드를 반복해서 작성하며 익힐 필요가 있다.

**다음 복습 우선순위**

1. `self`와 `__init__`의 관계
2. 클래스와 인스턴스의 차이
3. 상속과 오버라이딩의 차이
4. `super()`의 사용 목적
5. `return`, `break`, `continue`의 실행 흐름

**오늘의 한 줄 정리:** 클래스는 객체를 만드는 설계도이고, 상속은 기능을 재사용하는 방법이며, 오버라이딩과 다형성은 객체에 따라 서로 다른 동작을 구현하는 핵심 개념이다.
