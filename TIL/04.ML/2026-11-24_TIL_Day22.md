## 1. 오늘의 학습 내용과 전체 흐름

오늘의 최종 목표는 **오피스텔의 면적을 입력하면 가격을 예측하는 모델을 만들고, 그 모델이 얼마나 잘 예측하는지 확인하는 것**이다.

```text
[그래프를 배우는 단계]
타이타닉 객실별 요금 박스플롯 → 월별 매출 선 그래프
                               ↓
[관계를 발견하는 단계]
미국 주택의 면적과 가격 산점도 → 상관계수 계산
                               ↓
[연습할 데이터를 준비하는 단계]
오피스텔 면적 200개 생성 → 면적에 따른 가격 생성 → 특이 매물 5개 추가
                               ↓
[컴퓨터에게 규칙을 학습시키는 단계]
X(면적), y(실제 가격) 준비 → LinearRegression() → fit(X, y)
                               ↓
[학습한 규칙을 사용하는 단계]
새 면적 33, 59의 가격 예측 → 기존 200건의 가격도 예측
                               ↓
[잘 예측했는지 확인하는 단계]
실제 가격과 예측 가격 비교 → MAE / MSE / RMSE / R² 계산
                               ↓
[오차가 발생하는 이유를 살펴보는 단계]
전체 200건 평가 vs 특이 매물 제외 195건 평가
```

| 단계 | 내가 알고 싶은 것 | 사용하는 도구 |
|---|---|---|
| 시각화 | 데이터가 어떻게 생겼는가? | `boxplot()`, `plot()`, `scatter()` |
| 상관관계 | 두 값이 함께 증가하거나 감소하는가? | `corr()` |
| 데이터 준비 | 학습시킬 면적과 가격을 어떻게 만들까? | NumPy, Pandas |
| 학습 | 면적을 가격으로 바꾸는 공식을 어떻게 찾을까? | `model.fit(X, y)` |
| 예측 | 새로운 면적의 가격은 얼마일까? | `model.predict()` |
| 평가 | 실제 가격과 예측값의 차이는 어느 정도인가? | `mean_absolute_error()` 등 |
| 비교 | 특이 매물의 영향은 얼마나 큰가? | Boolean Mask |

상관계수는 관계를 설명하는 숫자이고, 선형 회귀는 가격을 계산할 공식을 만드는 방법이다. 평가 지표는 그 공식이 얼마나 잘 맞는지 알려준다. 세 가지는 목적이 다르다.

### 2-3. 코드 읽는 순서 복습

```python
result = object.method(argument)
```

1. 오른쪽부터 읽는다: `object`가 가진 `method()`를 실행한다.

## 3. 이전 노트북 이어서 — 박스플롯(Box Plot)

박스플롯은 데이터가 어느 범위에 몰려 있는지, 가운데 값은 얼마인지, 유난히 크거나 작은 값은 있는지를 요약한 그래프다. 오늘은 타이타닉의 객실 등급별 승선 요금 분포를 비교했다.

### 3-1. 박스플롯 읽는 법

이해용 예시로 오름차순으로 정렬된 요금이 10, 20, 30, 40, 50이라고 하자. 가운데 값(중앙값)은 30이다. Q1은 전체 분포의 25% 위치, Q3는 75% 위치에 해당하는 값이다. Q3-Q1을 IQR(사분위 범위)이라고 한다.

```text
     아래쪽 수염       상자(가운데 50%)        위쪽 수염       이상치 후보
         |-----------[ Q1 --- 중앙값 --- Q3 ]-----------|        o
```

일반적인 박스플롯의 수염은 Q1-1.5×IQR, Q3+1.5×IQR 범위 안에 있는 실제 데이터 끝점까지 표시한다. 바깥에 표시되는 점은 이상치 후보이지, 자동으로 삭제해야 하는 오류 데이터는 아니다.

### 3-2. Figure와 Axes

```python
fig, ax = plt.subplots(figsize=(6, 3))
```

| 구성 | 한글 풀이 |
|---|---|
| `plt` | 그래프 작성에 사용하는 pyplot 모듈 |
| `subplots()` | 전체 그림(Figure)과 그래프 영역(Axes)을 함께 만드는 함수 |
| `figsize` | 그림 크기를 지정하는 매개변수 |
| `(6, 3)` | 가로 6인치, 세로 3인치의 튜플 |
| `fig, ax =` | 반환된 두 객체를 각각의 변수에 나누어 저장(언패킹) |

한글 해석: 가로 6인치, 세로 3인치 크기의 그림과 그래프 영역을 만들고, 각각 `fig`와 `ax`에 저장한다.

Figure는 도화지 전체, Axes는 도화지에 실제 그래프를 그리는 공간이라고 이해하면 된다. 이전 파이썬 함수 수업에서 학습한 다중 반환값의 언패킹을 이용한다.

### 3-3. 객실 등급별 요금 시각화

```python
sns.boxplot(x="class", y="fare", data=df, ax=ax,
            hue="class", palette="Set2", legend=False)
```

| 코드 | 한글 풀이 |
|---|---|
| `sns.boxplot()` | Seaborn으로 박스플롯을 그린다. |
| `x="class"` | 가로축에 객실 등급 컬럼을 배치한다. |
| `y="fare"` | 세로축에 승선 요금 컬럼을 배치한다. |
| `data=df` | 사용할 원본 표를 `df`로 지정한다. |
| `ax=ax` | 앞에서 만든 Axes 객체에 그린다. 왼쪽 `ax`는 매개변수, 오른쪽 `ax`는 내 변수이다. |
| `hue="class"` | 객실 등급마다 색상을 다르게 지정한다. |

한글 해석: 타이타닉 데이터에서 객실 등급별로 승선 요금을 그룹화하여 분포를 비교하는 박스플롯을 그린다.

### 3-4. 특정 그룹의 요금 조회

수업 노트북에 있던 코드:

```python
groups = df.loc[df["class"] == "c", "fare"]
```

`df["class"] == "c"`는 class 값이 c인 행을 찾는 조건이고, `"fare"`는 가져올 열이다. `df.loc[행 조건, 열 이름]`의 반환 결과를 `groups`에 저장한다. 저장된 실행 결과는 빈 Series였다. `class`의 실제 등급 값은 `First`, `Second`, `Third`이므로 c와 일치하지 않는다.

복습용 수정 예시(수업 원본과 구분):

```python
groups = df.loc[df["class"] == "First", "fare"]
```

한글 해석: 1등실 승객의 승선 요금만 선택한다. 문자열 비교는 대소문자와 실제 값을 맞춰야 한다.

## 4. 선 그래프(Line Chart) — 월별 매출

앞에서는 여러 그룹의 값 분포를 비교했다. 이번에는 시간에 따라 값이 어떻게 변하는지 확인한다.

```python
plt.rcParams["font.family"] = "Malgun Gothic"
fig, ax = plt.subplots(figsize=(6, 3))
months = ["1월", "2월", "3월", "4월", "5월", "6월"]
sales = [120, 135, 120, 160, 170, 192]
ax.plot(months, sales, marker="o", label="매출")
ax.set_title("My Mall 월 매출")
ax.set_xlabel("월")
ax.set_ylabel("매출(만원)")
ax.legend()
plt.show()
```

### 코드 한 줄씩 풀이

| 코드 | 한글 해석 및 사용 이유 |
|---|---|
| `plt.rcParams["font.family"] = "Malgun Gothic"` | Matplotlib의 폰트 설정을 맑은 고딕으로 변경한다. 한글 그래프 제목이 깨지지 않도록 하기 위해서다. |
| `fig, ax = plt.subplots(figsize=(6, 3))` | 그림과 그래프 영역을 생성한다. |
| `months = [...]` | 가로축에 들어갈 월 이름 6개를 리스트로 만든다. |
| `sales = [...]` | 각 월의 매출액 6개를 같은 순서의 리스트로 만든다. |
| `ax.plot(months, sales, marker="o", label="매출")` | 각 월과 매출을 짝지어 점을 찍고 입력 순서대로 선으로 연결한다. |
| `ax.set_title(...)` | 그래프 위에 제목을 붙인다. |
| `ax.set_xlabel("월")` | 가로축(X축)의 이름을 월로 설정한다. |
| `ax.set_ylabel("매출(만원)")` | 세로축(Y축)의 이름을 매출(만원)으로 설정한다. |
| `ax.legend()` | `label`로 설정한 데이터 이름을 범례로 표시한다. |

`marker="o"`는 각 데이터 위치에 원형 점을 추가한다. `label="매출"`은 선의 이름을 지정하는 것이고, 범례를 실제로 표시하려면 `legend()`를 호출한다.

| 1월 | 120 |
| 2월 | 135 |
| 3월 | 120 |

두 리스트의 길이와 순서가 일치해야 한다. 첫 번째 월은 첫 번째 매출과 연결된다. 선 그래프는 월별 매출, 회원 수, 일별 방문자 같은 시간에 따른 변화를 볼 때 사용한다.

house = pd.read_csv("./datasets/usa_housing.csv")

한글 해석: 2016년 이후 건축되었고 범죄율 수치가 40 미만인 주택만 따로 추출한다. 실제 결과는 10행 10열이다. 각 조건을 소괄호로 감싸는 이유는 연산 순서를 명확하게 하기 위해서다.

### 5-2. 산점도(Scatter Plot)란?

하나의 데이터에 가로값과 세로값을 지정해 점으로 표시한다. 예를 들어 면적 30, 가격 18000인 집은 좌표 (30, 18000)에 점 하나로 표시된다. 집 300채라면 점 300개가 생긴다(같은 좌표에서는 겹칠 수 있다).

```python
plt.subplots(figsize=(6, 3))
plt.scatter(house["SquareFeet"], house["Price"],
            alpha=0.5, label="전체 300채", s=10)
plt.scatter(small["SquareFeet"], small["Price"],
            color="red", s=20, label="2015이후 건축")
plt.xlabel("면적")
plt.ylabel("가격")
plt.legend()
plt.show()
```

| 구성 | 한글 풀이 |
|---|---|
| `plt.subplots(figsize=(6, 3))` | 그림과 그래프 영역을 만들고 현재 Axes로 설정한다. 여기서는 반환값을 변수에 따로 저장하지 않는다. |
| `plt.scatter()` | 두 수치 컬럼의 값을 짝지어 점을 찍는다. |
| `house["SquareFeet"]` | 가로축에 들어갈 전체 주택 면적(제곱피트) |
| `house["Price"]` | 세로축에 들어갈 전체 주택 가격 |
| `alpha=0.5` | 점의 불투명도를 50%로 설정한다. 겹침을 보기 쉽다. |
| `s=10` | 점의 면적 크기를 지정한다(단위 points²). |
| `small[...]` | 앞서 조건을 만족한 주택 10채의 면적과 가격 |
| `color="red"`, `s=20` | 선택된 10채를 빨간색의 더 큰 점으로 표시한다. |
| `label` / `legend()` | 각 데이터 그룹의 이름 지정 / 범례 표시 |
| `xlabel()`, `ylabel()`, `show()` | 축 이름 설정 / 그림 출력 |

두 번째 산점도는 첫 번째 산점도를 지우지 않는다. 같은 그래프 위에 조건을 만족한 점들을 강조한다. `small`은 전체 300채에 이미 포함된 10채다. 범례 이름에는 건축 연도만 쓰여 있지만 실제 필터는 범죄율 조건도 포함한다.

### 5-3. 상관계수(Correlation Coefficient) — 수학 기초

상관관계는 두 값이 함께 변하는 경향이다. 상관계수는 그중 선형 관계의 방향과 강도를 -1~1 사이의 숫자로 나타낸다(오늘의 `corr()` 기본값인 피어슨 상관계수 기준).

| 면적 | 가격 A | 가격 B | 가격 C |
|---:|---:|---:|---:|
| 20 | 100 | 300 | 200 |
| 40 | 200 | 200 | 100 |
| 60 | 300 | 100 | 200 |

- A: 면적이 커질수록 가격도 증가 → 양의 상관관계, 상관계수 +1.
- B: 면적이 커질수록 가격 감소 → 음의 상관관계, 상관계수 -1.
- C: 면적이 증가해도 가격이 일정 방향으로 변하지 않음 → 선형 상관계수 0.

```text
양의 관계             뚜렷한 선형 관계 없음       음의 관계
가격                  가격                      가격
|       *             |    *  *                | *
|    *                | *                      |    *
| *                   |       *  *             |       *
+-------- 면적        +-------- 면적           +-------- 면적
```

0은 모든 종류의 관계가 없다는 뜻이 아니라 직선으로 설명되는 관계가 약하다는 뜻이다. 상관계수 0.9는 90%의 정확도라는 뜻도 아니다. 상관관계만으로 원인과 결과를 확정할 수 없다.

### 5-4. 코드로 상관계수 계산

```python
print("전체 300채의 상관관계:", round(house["SquareFeet"].corr(house["Price"]), 2))
print("2015이후 10채의 상관관계:", round(small["SquareFeet"].corr(small["Price"]), 2))
```

첫 번째 줄의 실행 순서:

1. `house["SquareFeet"]`: 전체 주택 면적 Series를 가져온다.
2. `house["Price"]`: 전체 주택 가격 Series를 가져온다.
3. `.corr(house["Price"])`: 면적과 가격의 상관계수를 계산한다.
4. `round(..., 2)`: 계산한 값을 소수점 둘째 자리까지 반올림한다.
5. `print(...)`: 설명 문구와 숫자를 출력한다.

두 번째 줄은 `house` 대신 `small`을 사용해 선택된 주택에서 동일한 분석을 한다.

실제 수업 출력:

```text
전체 300채의 상관관계: 0.08
2015이후 10채의 상관관계: 0.89
```

전체 집에서는 선형 관계가 매우 약했지만 선택한 10채에서는 강한 양의 선형 관계가 나타났다. 선택한 표본이 작고 조건이 다르므로 전체 주택에 일반화할 수 없다.

**다음 단계로 넘어가는 이유:** 그래프와 상관계수로 관계를 발견할 수는 있지만 특정 면적의 가격을 바로 계산할 수는 없다. 그러려면 면적을 입력했을 때 가격을 출력하는 공식, 즉 예측 모델이 필요하다. 먼저 우리가 답을 알고 있는 가상 데이터로 학습을 연습한다.

## 6. 선형 회귀에 필요한 수학 기초 — 직선, 기울기, 절편

### 6-1. 변수와 함수의 관계

수학에서 `y = 2x + 3`은 `x`에 숫자를 넣으면 `y`가 정해지는 규칙이다. 파이썬에서는 `y = 2 * x + 3`으로 쓴다.

| 입력 x | 계산 | 결과 y |
|---:|---|---:|
| 0 | 2×0+3 | 3 |
| 1 | 2×1+3 | 5 |
| 2 | 2×2+3 | 7 |
| 3 | 2×3+3 | 9 |

점들을 연결하면 직선이 된다. 이 직선의 일반적인 표현이 `y = wx + b`이다.

| 기호 | 이름 | 쉽게 이해하기 |
|---|---|---|
| `x` | 입력 변수 | 내가 알고 있는 숫자(면적) |
| `y` | 결과 변수 | 계산 결과(가격) |
| `w` | 기울기, 가중치(Weight), 회귀계수 | x가 1 증가할 때 y가 얼마나 변하는가 |
| `b` | 절편(Intercept), 편향(Bias) | x가 0일 때 y의 값 |

### 6-2. 기울기와 절편을 구분하기

예시 공식 `y = 2x + 3`에서 기울기는 2, 절편은 3이다. x가 1에서 2로 늘면 y는 5에서 7로 2 증가한다. x가 0이라면 y는 3이다.

기울기는 세로값 변화량 / 가로값 변화량이다. 예를 들어 두 점이 (10, 30), (20, 50)이면 `(50 - 30) / (20 - 10) = 2`이다. 이 기울기를 공식에 대입하면 `30 = 2×10 + b`이므로 절편은 10이다.

오늘 만든 가격 규칙은 다음과 같다.

```text
가격 = 면적 × 450 + 5000
```

| 면적 | 계산 | 기본 가격 |
|---:|---|---:|
| 30 | 30×450+5000 | 18,500 |
| 50 | 50×450+5000 | 27,500 |
| 70 | 70×450+5000 | 36,500 |

면적이 1 증가할 때 가격은 450 증가한다. 절편 5000은 이 수학적 직선을 결정하는 상수이며, 실제 면적이 0인 오피스텔에 시장 가격 5000이 존재한다는 뜻은 아니다. 가격 단위는 실습 데이터의 단위를 그대로 사용한다.

**왜 이 공식을 먼저 배우는가?** 우리는 450과 5000을 직접 지정하여 가격 데이터를 만든 뒤, 컴퓨터가 이 값을 모르는 상태에서 데이터만 보고 비슷한 규칙을 찾는지 확인할 것이다.

## 7. NumPy 난수 — 가상 오피스텔 데이터 생성

### 7-1. 난수와 시드(Seed)

난수(Random Number)는 무작위처럼 보이는 숫자다. 시드(Seed)는 난수 생성기를 초기화하는 값이다. 같은 시드로 생성기를 다시 만들고 같은 순서로 같은 함수를 실행하면 실습을 재현할 수 있다.

```python
rng = np.random.default_rng(40)
n = 200
area = rng.uniform(20, 85, n)
```

| 구성 | 한글 풀이 |
|---|---|
| `np.random` | NumPy의 난수 관련 기능 |
| `default_rng(40)` | 시드 40으로 난수 생성기를 초기화하는 함수 |
| `rng` | Random Number Generator의 의미로 지은 변수. 생성기 객체를 저장한다. |
| `n = 200` | 생성할 매물 개수를 200으로 설정한다. |
| `rng.uniform(20, 85, n)` | 20 이상 85 미만 범위의 균등분포 난수를 200개 만든다. |
| `area =` | 생성된 면적 배열(NumPy ndarray)을 저장한다. |

`uniform`은 균등하다는 뜻이다. 구간 내 어느 부분에 값이 등장할 가능성이 한쪽으로 치우치지 않도록 숫자를 생성한다. 정수만 생성하는 함수가 아니므로 42.37 같은 실수도 나올 수 있다. 시드 40이 난수 개수나 최댓값을 의미하는 것은 아니다. `rng.uniform()`을 같은 생성기에서 반복 호출하면 생성기의 상태가 진행되므로 매번 같은 배열이 나오는 것도 아니다.

### 7-2. 표준편차, 정규분포, 노이즈(Noise)

평균은 모든 값을 더한 뒤 개수로 나눈 값이다. 표준편차(Standard Deviation)는 데이터가 평균 주변에서 얼마나 퍼져 있는지를 나타낸다. 표준편차가 작으면 값들이 평균 근처에 모이고, 크면 넓게 퍼진다.

정규분포(Normal Distribution)는 평균 근처가 가장 높고 멀어질수록 빈도가 낮아지는 종 모양의 분포이다. 노이즈(Noise)는 일정한 규칙에서 벗어나는 무작위 변동이다. 실제 부동산 가격에는 위치, 층수 등 면적 외의 요인이 있으므로 연습용 데이터도 모든 값이 정확한 직선에 놓이지 않도록 만든다.

```python
rng.normal(0, 2500, n)
```

| 인수 | 의미 |
|---|---|
| `0` | 정규분포의 평균(중심). 양수와 음수 양쪽으로 오차가 생기게 한다. |
| `2500` | 표준편차. 오차가 퍼지는 정도이다. |
| `n` | 만들 난수 개수 200개 |

주의: 2500은 최대 오차가 아니다. 정규분포는 ±2500보다 큰 값도 생성할 수 있다. `normal()`은 정상 매물 여부를 뜻하는 변수 `normal`과는 다른 이름이다.

### 7-3. 가격 계산 코드 완전 해석

```python
price = (area * 450 + 5000 + (rng.normal(0, 2500, n))).round(-1)
```

안쪽부터 읽으면 다음과 같다.

1. `area * 450`: 면적 배열 안의 각 값에 450을 곱한다.
2. `+ 5000`: 각각의 결과에 기본값 5000을 더한다.
3. `rng.normal(0, 2500, n)`: 매물별 무작위 오차 200개를 생성한다.
4. `+ (...)`: 같은 위치의 기본 가격과 오차를 하나씩 더한다.
5. `.round(-1)`: 모든 가격을 10 단위로 반올림한다.
6. `price =`: 결과 배열을 `price`에 저장한다.

이해용 예시(실제 난수 결과가 아님):

| 면적 | 기본 가격 | 무작위 오차 | 최종 가격 |
|---:|---:|---:|---:|
| 30 | 18,500 | +1,300 | 19,800 |
| 50 | 27,500 | -2,000 | 25,500 |
| 70 | 36,500 | +500 | 37,000 |

NumPy 배열의 계산은 같은 위치의 원소끼리 자동으로 이루어진다. 따라서 200개를 처리하기 위해 `for`문을 직접 작성하지 않아도 된다.

```python
# 반올림 이해용 예시
round(123.456, 2)   # 123.46
round(123.456, 0)   # 123.0
round(123.456, -1)  # 120.0
round(123.456, -2)  # 100.0
```

`round(-1)`은 소수점 한 자리를 의미하지 않고 십의 자리 단위(10 단위) 반올림을 의미한다. 가격 생성 코드에서는 NumPy 배열의 `.round()` 메서드이므로 배열 속 모든 숫자에 적용된다.

### 7-4. 특이 매물 5개 만들기

```python
special = rng.choice(n, 5, replace=False)
price[special] += rng.uniform(15000, 25000, 5).round(-1)
```

첫 줄: `choice()`는 주어진 후보 중 무작위로 선택한다. `n`이 정수 200이므로 선택 후보는 0~199이다. `5`는 선택할 개수, `replace=False`는 뽑은 번호를 다시 뽑지 않는다는 뜻이다. 결과는 매물의 번호(배열 위치) 5개가 저장된 `special` 배열이다.

두 번째 줄을 읽는 순서:

| 구성 | 한글 풀이 |
|---|---|
| `rng.uniform(15000, 25000, 5)` | 추가 가격 5개를 균등분포로 생성한다. |
| `.round(-1)` | 추가 가격을 각각 10 단위로 반올림한다. |
| `price[special]` | `special`에 들어 있는 위치의 가격 5개만 선택한다. |
| `+=` | 선택한 기존 값에 오른쪽 값을 더하여 다시 저장한다. |

이해용 예시:

```python
price = np.array([100, 200, 300, 400])
special = np.array([1, 3])
price[special] += np.array([50, 70])
# 결과: [100, 250, 300, 470]
```

실제 수업의 특이 매물 위치는 `[53 13  2 92 71]`이다. 200개 중 5개만 가격이 크게 올라가며, 매물 개수 자체는 늘어나지 않는다. 이 다섯 매물은 나중에 평가에서 제외하여 비교할 예정이다. 실제 데이터에서 비싼 매물을 무조건 제외하라는 뜻은 아니다.

## 8. 머신러닝과 선형 회귀(Linear Regression)

### 8-1. 일반 계산과 머신러닝의 차이

| 구분 | 우리가 주는 것 | 컴퓨터가 구하는 것 |
|---|---|---|
| 일반적인 계산 | 공식 + 면적 | 가격 |
| 머신러닝 학습 | 면적 + 실제 가격 | 가격을 계산하는 공식의 계수 |
| 머신러닝 예측 | 학습한 공식 + 새로운 면적 | 새로운 예측 가격 |

선형 회귀는 실제 값과 예측값 사이의 제곱 오차 합이 가장 작아지는 직선의 기울기와 절편을 찾는 방법이다(오늘 사용한 기본 LinearRegression 기준).

예를 들어 면적이 10, 20, 30이고 가격이 30, 50, 70인 세 점이 있다고 하자. 다음 직선 중 두 번째가 모든 점과 정확히 일치한다.

| 후보 공식 | 면적 10 예측 | 면적 20 예측 | 면적 30 예측 |
|---|---:|---:|---:|
| y = x + 10 | 20 | 30 | 40 |
| y = 2x + 10 | 30 | 50 | 70 |
| y = 3x | 30 | 60 | 90 |

실제 데이터에는 오차가 있으므로 모든 점과 완벽히 일치하는 직선은 보통 없다. 가장 잘 맞는 직선을 수학적으로 계산한다. 이 방법을 최소제곱법(Least Squares)이라고 부른다. 오늘은 모델이 계산을 대신해 주므로 수학적 증명까지 이해할 필요는 없다.

### 8-2. 모델 기능 가져오기

```python
from sklearn.linear_model import LinearRegression
```

`from`은 어느 모듈에서 가져올지 지정하고, `import`는 필요한 기능을 불러온다. `sklearn.linear_model`은 선형 모델을 모아 둔 모듈이며 `LinearRegression`은 선형 회귀 모델을 생성할 수 있는 클래스이다.

### 8-3. 입력 데이터 X와 정답 데이터 y — 2차원과 1차원

```python
X = office[["area"]]
y = office["price"]
```

예시 원본 표:

| index | area | price |
|---|---:|---:|
| 0 | 30 | 18500 |
| 1 | 50 | 27500 |
| 2 | 70 | 36500 |

`X`는 입력 특성(Feature), `y`는 정답 또는 목표값(Target)이다. 대문자 X와 소문자 y는 관례적으로 쓰는 변수 이름이다.

**`X = office[["area"]]` 읽는 순서**

1. 안쪽 `["area"]`는 컬럼 이름 하나를 담은 파이썬 리스트이다.
2. 바깥쪽 `office[...]`는 리스트에 들어 있는 컬럼들을 선택한다.
3. 반환되는 결과는 한 열짜리 DataFrame이다.
4. 이를 X에 저장한다.

한글 해석: 오피스텔 표에서 면적 컬럼을 표 형태 그대로 가져와 모델의 입력 데이터 X에 저장한다.

**`y = office["price"]` 읽는 순서**

1. `"price"`라는 하나의 컬럼 이름을 문자열로 전달한다.
2. Pandas는 해당 컬럼을 Series로 반환한다.
3. 이를 y에 저장한다.

한글 해석: 실제 가격 컬럼을 한 줄의 값들(Series)로 가져와 정답 데이터 y에 저장한다.

| 구분 | X | y |
|---|---|---|
| 선택 코드 | `office[["area"]]` | `office["price"]` |
| 자료형 | DataFrame | Series |
| 차원 | 2 | 1 |
| 예시 모양 | `[[30], [50], [70]]` | `[18500, 27500, 36500]` |
| 실제 shape | `(200, 1)` | `(200,)` |
| 의미 | 매물 200건, 특성 1개 | 매물 200건의 정답 가격 |

차원은 데이터의 축 개수이다. DataFrame은 행과 열 두 축을 유지한다. 열이 1개여도 2차원이다. Series는 값이 순서대로 놓인 하나의 축을 가진다. 위 중첩 리스트는 형태를 이해하기 위한 비유이며 실제 자료형은 DataFrame/Series이다.

왜 입력 X는 2차원일까? Scikit-learn은 입력 데이터를 `(샘플 수, 특성 수)` 구조로 받기 때문이다. 향후 면적 외에 층수와 건축연도를 추가하면 열이 3개가 되지만 구조는 그대로이다. 오늘처럼 정답이 가격 하나인 경우 y는 1차원으로 전달할 수 있다.

복습용 확인 코드:

```python
print(type(X))   # pandas.DataFrame
print(X.ndim)    # 2
print(X.shape)   # (200, 1)
print(type(y))   # pandas.Series
print(y.ndim)    # 1
print(y.shape)   # (200,)
```

`ndim`은 축의 수를 나타내는 속성, `shape`는 각 축의 크기를 나타내는 속성이다. 속성이므로 `()`를 붙이지 않는다.

### 8-4. 모델 생성과 학습

```python
model = LinearRegression()
model.fit(X, y)
```

| 구성 | 한글 풀이 |
|---|---|
| `LinearRegression` | 선형 회귀 클래스(설계도) |
| `LinearRegression()` | 선형 회귀 객체를 생성한다. 이 시점에는 아직 학습되지 않았다. |
| `model` | 생성한 객체를 저장한 변수 |
| `.fit()` | 데이터에 모델을 맞추는 학습 메서드 |
| `X` | 첫 번째 인수: 면적 200건 |
| `y` | 두 번째 인수: 각 면적에 대응하는 실제 가격 200건 |

한글 해석: 선형 회귀 모델을 하나 생성한다. 그 모델에 면적과 가격을 함께 전달하여 두 값 사이의 가격 예측 규칙을 학습시킨다.

`model.fit()`은 학습 후 모델 내부에 기울기와 절편을 저장한다. `fit()`은 학습된 자기 자신을 반환하기도 하지만 여기서는 객체가 직접 갱신되므로 다시 대입하지 않았다. 이미 배운 객체지향 프로그래밍의 클래스, 인스턴스, 메서드가 그대로 사용된다.

정답이 주어진 데이터를 이용하여 학습하는 방식을 지도학습(Supervised Learning)이라고 한다. 회귀(Regression)는 가격처럼 연속적인 숫자를 예측하는 문제이다.

### 8-5. 모델이 학습한 결과 확인

```python
print(f"기울기 w = {model.coef_[0]} /정답 : 450")
print(f"절편 b = {model.intercept_} /정답 : 5000")
```

| 구성 | 한글 풀이 |
|---|---|
| `coef_` | Coefficient(계수)의 줄임말. 학습된 입력 변수별 계수 배열이다. |
| `[0]` | 배열의 첫 번째 값(면적의 기울기) 선택 |
| `intercept_` | 학습된 절편 값 |
| `f"...{...}..."` | f-string. 중괄호의 값을 문자열에 삽입한다. |
| `/정답 : 450`, `/정답 : 5000` | 우리가 데이터 생성 때 사용했던 기준 값을 비교용 문구로 출력한다. 나눗셈 연산이 아니다. |

`coef_`, `intercept_`는 메서드가 아닌 학습된 속성이다. 따라서 괄호를 쓰지 않는다. Scikit-learn에서는 학습으로 만들어진 속성에 뒤쪽 밑줄 `_`을 붙이는 관례가 있다.

실제 실행 결과:

```text
기울기 w = 439.45870417134705 /정답 : 450
절편 b = 5926.680580056112 /정답 : 5000
```

학습된 가격 공식(반올림해서 표시): `예측 가격 = 면적 × 439.46 + 5926.68`

450과 5000이 정확히 나오지 않는 이유는 가상 데이터에 무작위 오차와 특이 매물 5건이 포함되었기 때문이다. 모델은 원래 공식을 전달받은 것이 아니라 면적과 가격 데이터만 전달받았다.

개인 반올림 테스트(수업 코드에 별도로 표시되어 있던 부분):

```python
test = round(model.coef_[0], 2)
print(f"기울기 w = {test} /정답 : 450")
```

출력은 `439.46`이다. `test`에 반올림 결과를 저장했을 뿐 모델의 원래 계수는 변경되지 않는다.

## 9. 학습한 모델 사용하기 — 새로운 면적의 가격 예측

### 9-1. `fit()`과 `predict()`의 차이

`fit`은 데이터에 맞추다, `predict`는 예측하다라는 뜻이다.

```text
fit(X, y)   : 입력과 정답을 함께 제공 → 기울기와 절편을 찾음
predict(X)  : 입력만 제공           → 학습한 기울기와 절편으로 결과를 계산
```

학습할 때만 정답 가격이 필요하다. 새 매물은 아직 가격을 모르므로 면적만 제공한다. `predict()`는 기존 학습 결과를 사용하며 기울기와 절편을 다시 학습하지 않는다.

### 9-2. 면적 33과 59인 새로운 오피스텔

```python
new = pd.DataFrame({"area": [33, 59]})
model.predict(new).round(-1)
```

첫 번째 줄:

| 구성 | 한글 풀이 |
|---|---|
| `{"area": [33, 59]}` | 컬럼 이름 area와 두 면적을 딕셔너리로 구성한다. |
| `pd.DataFrame(...)` | 입력값 2개를 2행 1열의 표로 변환한다. |
| `new =` | 새로운 입력 데이터를 new라는 변수에 저장한다. |

학습할 때 입력 컬럼명이 `area`였기 때문에 예측할 때도 같은 이름을 사용한다. 행 개수는 달라져도 된다. `new`의 모양은 `(2, 1)`이다.

두 번째 줄:

| 구성 | 한글 풀이 |
|---|---|
| `model` | 앞에서 학습시킨 모델 객체 |
| `.predict(new)` | 새로운 면적 2개를 넣어 예측 가격 배열을 반환한다. |
| `.round(-1)` | 반환된 배열의 각 값을 10 단위로 반올림한다. |

한글 해석: 학습이 끝난 모델에게 면적 33과 59를 전달하여 가격을 예측하고 10 단위로 반올림한다.

직접 계산해 보면 컴퓨터가 하는 일이 이해된다.

```text
면적 33 → 439.45870417134705 × 33 + 5926.680580056112
        ≈ 20428.82 → 20430

면적 59 → 439.45870417134705 × 59 + 5926.680580056112
        ≈ 31854.74 → 31850
```

실제 수업 출력:

```text
array([20430., 31850.])
```

NumPy 배열이며 입력 순서에 맞추어 가격이 반환된다. 33의 예측 가격은 20430, 59의 예측 가격은 31850이다. 끝에 점이 붙은 것은 실수형(float) 출력이기 때문이다. 새 매물의 실제 정답 가격을 확인한 것은 아니므로 이 단계만으로 오차를 알 수 없다.

## 10. 기존 매물 예측과 회귀 직선 시각화

### 10-1. 왜 이미 학습한 데이터의 가격을 또 예측할까?

새로운 면적의 가격을 구하는 것과 별개로, 모델이 기존 데이터에서 얼마나 잘 맞는지 확인하려고 한다. 기존 매물 200건은 이미 실제 가격 `y`가 있으므로 예측값과 비교할 수 있다.

```python
y_pred = model.predict(X)
line = X.sort_values("area")
line_pred = model.predict(line)
```

### 첫 번째 줄 — `y_pred = model.predict(X)`

| 구성 | 한글 풀이 |
|---|---|
| `y_pred` | Predicted y(예측된 y)의 뜻으로 지은 변수 이름 |
| `model` | 학습된 선형 회귀 객체 |
| `.predict()` | 학습한 공식을 입력값에 적용하는 메서드 |
| `X` | 학습 때 사용한 면적 200건의 DataFrame |
| `=` | 예측 결과 배열을 왼쪽 변수에 저장한다. |

한글 해석: 기존 200건의 면적을 학습된 모델에 넣어 각각의 가격을 예측하고 `y_pred`에 저장한다.

반환 결과: 원본 X의 행 순서에 대응하는 200개 가격의 1차원 NumPy 배열. `y`의 실제 가격과 같은 순서로 비교할 수 있다. 이후 MAE, MSE, RMSE, R² 평가에 이용한다.

### 두 번째 줄 — `line = X.sort_values("area")`

| 구성 | 한글 풀이 |
|---|---|
| `X` | 기존 면적 200건을 담은 DataFrame |
| `.sort_values()` | 행을 지정된 컬럼의 값에 따라 정렬하는 메서드 |
| `"area"` | 정렬 기준으로 사용할 면적 컬럼명 |
| `line` | 정렬된 면적 표를 저장하는 변수. 함수나 그래프 자체가 아니다. |

한글 해석: X에 있는 모든 면적을 작은 값부터 큰 값 순서로 정렬하여 `line`에 저장한다.

기본값 `ascending=True`가 적용된다. 원본 X는 바뀌지 않으며, 정렬 결과는 기존 인덱스를 유지한다. 정렬하는 이유는 선 그래프가 입력 순서대로 점을 잇기 때문에 왼쪽에서 오른쪽 순서로 회귀 직선을 그리기 위해서다.

### 세 번째 줄 — `line_pred = model.predict(line)`

| 구성 | 한글 풀이 |
|---|---|
| `model` | 위에서 사용한 것과 같은 모델 |
| `.predict(line)` | 정렬된 면적 표를 넣어 그 순서대로 가격을 계산한다. |
| `line_pred` | 정렬된 면적에 대응하는 예측 가격 배열을 저장한다. |

한글 해석: 작은 면적부터 큰 면적 순서로 정렬된 `line`을 입력하여 예측 가격을 다시 계산하고 `line_pred`에 저장한다.

### 10-2. `y_pred`와 `line_pred`가 왜 둘 다 필요한지 이해하기

이해용 작은 예시: 학습된 공식이 `y = 2x + 10`이라고 가정하자.

원본 순서:

| 인덱스 | X(면적) | y(실제 가격) | y_pred(예측 가격) |
|---:|---:|---:|---:|
| 0 | 30 | 72 | 70 |
| 1 | 10 | 28 | 30 |
| 2 | 20 | 55 | 50 |

정렬 후:

| 기존 인덱스 | line(정렬 면적) | line_pred(예측 가격) |
|---:|---:|---:|
| 1 | 10 | 30 |
| 2 | 20 | 50 |
| 0 | 30 | 70 |

두 예측 배열은 같은 값들을 담지만 순서가 다르다.

```text
y_pred    = [70, 30, 50]  → 실제 가격 y와 비교하는 용도
line_pred = [30, 50, 70]  → 정렬된 면적 line과 그래프를 그리는 용도
```

`line_pred`를 원본 `y`와 그대로 비교하면 서로 다른 매물의 가격을 비교하게 된다. 반드시 같은 매물끼리 비교해야 한다. 단순 선형 회귀의 점들은 모두 한 직선 위에 있어서 정렬 없이 그려도 같은 선을 지나지만, 순서대로 그리면 불필요하게 선이 왕복하지 않고 일반적인 선 그래프 작성에서도 안전한 습관이다.

### 10-3. 실제 산점도와 모델 직선을 하나의 그래프에 그리기

```python
plt.figure(figsize=(8, 5))
plt.scatter(office["area"], office["price"], alpha=0.6, label="실제 시세")
plt.plot(line["area"], line_pred, color="red", label="모델의 직선")
plt.title("오피스텔 시세 200건")
plt.xlabel("면적")
plt.ylabel("가격")
plt.show()
```

| 코드 | 한글 풀이 |
|---|---|
| `plt.figure(figsize=(8, 5))` | 가로 8인치, 세로 5인치 크기의 그림 생성 |
| `plt.scatter(office["area"], office["price"], ...)` | 각 매물의 실제 면적과 실제 가격을 점으로 표시 |
| `alpha=0.6` | 점의 불투명도 60% |
| `label="실제 시세"` | 점 그룹의 이름을 지정 |
| `plt.plot(line["area"], line_pred, ...)` | 정렬된 면적과 그 면적의 예측 가격을 연결하여 회귀 직선을 그림 |
| `color="red"` | 회귀 직선을 빨간색으로 표시 |
| `label="모델의 직선"` | 선 그룹의 이름을 지정 |
| `title()`, `xlabel()`, `ylabel()` | 제목 및 가로·세로축 이름 설정 |
| `show()` | 그림 출력 |

참고: 수업 원본에서는 이 셀에 `plt.legend()`를 호출하지 않았으므로 label을 지정해도 범례가 자동으로 표시되지는 않는다. 범례가 필요하면 `plt.show()` 앞에 `plt.legend()`를 추가할 수 있다.

그래프 읽는 법:

```text
가격
  |                         *  ← 실제 가격이 예측보다 높은 매물
  |                    /         빨간 직선: 모델의 예측 가격
  |              *   /   *
  |               /      ↕       같은 면적에서의 세로 거리 = 오차의 크기
  |          *  /       *
  |         /  *
  |      /
  +-------------------------- 면적
```

- 점은 실제 가격이고 빨간 선은 모델이 학습한 예측 가격이다.
- 같은 면적의 실제 점이 직선 위에 있으면 오차가 0이다.
- 점이 직선보다 높으면 실제 가격이 예측보다 높다(과소 예측).
- 점이 직선보다 낮으면 실제 가격이 예측보다 낮다(과대 예측).
- 특이 매물은 직선에서 크게 벗어날 수 있다.

**다음 단계:** 이제 그래프로 오차를 눈으로 보았다. 오차를 숫자로 계산하면 모델을 더 객관적으로 비교할 수 있다.

## 11. 모델 성능 평가 — 오차부터 이해하기

### 11-1. 오차(Error)란?

실제 가격과 예측 가격의 차이다. 학습 데이터에서 실제값과 적합된 값의 차이는 잔차(Residual)라고도 부른다. 여기서는 편의상 `오차 = 실제값 - 예측값`으로 계산한다.

| 매물 | 실제 가격(y) | 예측 가격(y_pred) | 오차(y - y_pred) |
|---|---:|---:|---:|
| A | 100 | 90 | +10 |
| B | 200 | 220 | -20 |
| C | 300 | 290 | +10 |

오차를 그대로 평균 내면 `(10 - 20 + 10) / 3 = 0`이다. 하지만 모델은 세 개 모두 틀렸다. 양수와 음수가 서로 상쇄되는 문제를 해결하기 위해 절댓값 또는 제곱을 사용한다.

### 11-2. 절댓값(Absolute Value), 제곱(Square), 제곱근(Square Root)

| 수학 개념 | 의미 | 작은 예시 | 파이썬 표현 |
|---|---|---|---|
| 절댓값 | 부호와 상관없이 0에서 얼마나 떨어져 있는지 | -20 → 20 | `abs(-20)` |
| 제곱 | 같은 수를 두 번 곱함 | (-20)×(-20)=400 | `(-20) ** 2` |
| 제곱근 | 제곱해서 해당 값이 되는 수 중 음이 아닌 값 | √400=20 | `400 ** 0.5` |
| 평균 | 값의 합계를 개수로 나눔 | (10+20+10)/3 | `sum(values) / len(values)` |

제곱은 음수도 양수가 되며 큰 오차를 훨씬 크게 반영한다. 제곱근은 제곱으로 바뀐 단위를 원래 단위로 돌려준다.

이 개념을 그대로 적용한 것이 MAE, MSE, RMSE다. R²는 평균값만 사용한 단순 예측과 비교하여 모델이 어느 정도 변동을 설명했는지 나타낸다.

### 11-3. 평가 함수 불러오기

```python
from sklearn.metrics import mean_absolute_error, mean_squared_error, root_mean_squared_error, r2_score
```

`metrics`는 측정 지표라는 뜻이다. `sklearn.metrics` 모듈에서 아래 네 평가 함수를 불러온다. 이 함수들은 모델을 학습시키지 않고 실제값과 예측값을 비교하는 역할을 한다.

| 함수 | 영어 단어 풀이 | 한글 이름 |
|---|---|---|
| `mean_absolute_error()` | Mean 평균 + Absolute 절댓값 + Error 오차 | MAE, 평균 절대 오차 |
| `mean_squared_error()` | Mean 평균 + Squared 제곱한 + Error 오차 | MSE, 평균 제곱 오차 |
| `root_mean_squared_error()` | Root 제곱근 + Mean 평균 + Squared 제곱한 + Error 오차 | RMSE, 평균 제곱근 오차 |
| `r2_score()` | R-squared score, R 제곱 점수 | R², 결정계수 |

## 12. MAE, MSE, RMSE, R²를 하나의 예제로 계산하기

아래 예시는 이해를 위한 작은 데이터로, 200건의 실제 수업 출력과 다르다. 네 가지 지표 모두 앞에서 사용한 매물 A, B, C를 이용한다.

### 12-1. MAE (Mean Absolute Error) — 평균적으로 얼마나 틀렸나?

| 매물 | 실제 | 예측 | 오차 | 절댓값 |
|---|---:|---:|---:|---:|
| A | 100 | 90 | 10 | 10 |
| B | 200 | 220 | -20 | 20 |
| C | 300 | 290 | 10 | 10 |

```text
MAE = 오차의 절댓값 합 / 데이터 개수
    = (10 + 20 + 10) / 3
    = 13.33...
```

해석: 모델이 평균적으로 약 13.33 가격 단위만큼 틀렸다. 양수와 음수 오차가 상쇄되지 않는다. 실제 가격과 같은 단위이다. 0이면 모든 예측값이 실제값과 일치한다. 작을수록 좋다.

```python
print(f"MAE = {mean_absolute_error(y, y_pred):,.0f}")
```

한글 풀이: 실제 가격 `y`와 예측 가격 `y_pred`를 함수에 전달하여 평균 절대 오차를 계산하고, 천 단위 콤마와 소수점 없는 형태로 출력한다. `mean_absolute_error(y, y_pred)`의 첫 인수는 실제값, 두 번째 인수는 예측값이다.

### 12-2. MSE (Mean Squared Error) — 큰 오차를 더 민감하게 평가하기

| 매물 | 오차 | 오차 제곱 |
|---|---:|---:|
| A | 10 | 100 |
| B | -20 | 400 |
| C | 10 | 100 |

```text
MSE = 오차 제곱의 합 / 데이터 개수
    = (100 + 400 + 100) / 3
    = 200
```

오차 20은 오차 10의 두 배이지만, 제곱하면 400과 100으로 네 배 차이가 난다. 따라서 큰 오차에 민감하다. MSE의 단위는 원래 가격 단위의 제곱이므로 `200만큼 가격을 틀렸다`라고 직접 해석할 수 없다. 작을수록 좋다.

```python
print(f"MSE = {mean_squared_error(y, y_pred):,.0f}")
```

한글 풀이: 실제 가격과 예측 가격의 차이를 각각 제곱한 뒤 평균을 내어 출력한다. LinearRegression의 학습 목적도 제곱 오차 합을 최소화하는 것이다. 같은 데이터에서는 제곱 오차 합을 최소화하는 것과 MSE를 최소화하는 것이 같다.

### 12-3. RMSE (Root Mean Squared Error) — 제곱 오차를 원래 단위로 바꾸기

```text
RMSE = √MSE
     = √200
     ≈ 14.14
```

MSE를 먼저 계산하고 그 결과에 제곱근을 씌운다. 각 오차의 제곱근을 먼저 구해서 평균을 내는 것이 아니다. RMSE는 MAE와 동일하게 원래 가격 단위이므로 크기를 해석하기 쉽고, 큰 오차에는 MAE보다 민감하다.

```python
print(f"RMSE = {root_mean_squared_error(y, y_pred):,.0f}")
```

한글 풀이: 실제값과 예측값의 평균 제곱 오차를 구하고 그 제곱근을 반환하여 출력한다.

| 지표 | 계산 결과(작은 예제) | 차이점 |
|---|---:|---|
| MAE | 13.33 | 오차의 크기를 그대로 평균 |
| MSE | 200 | 큰 오차에 더 민감, 단위가 제곱됨 |
| RMSE | 14.14 | MSE의 제곱근, 원래 단위로 표시 |

### 12-4. R² (R-squared, 결정계수) — 평균만 찍는 것보다 얼마나 나은가?

R²는 단순히 가격을 몇 퍼센트 정확히 맞혔는지 나타내는 수치가 아니다. 실제 가격의 평균을 모든 매물의 예측 가격으로 쓰는 경우와 비교한다.

**1단계: 아무 관계도 학습하지 않고 평균 가격을 예측한다고 가정한다.**

```text
실제 가격 평균 = (100 + 200 + 300) / 3 = 200
평균만 사용하는 모델의 예측 = [200, 200, 200]
```

| 매물 | 실제 가격 | 평균 예측 | 평균 예측의 제곱 오차 | 학습 모델 예측 | 학습 모델 제곱 오차 |
|---|---:|---:|---:|---:|---:|
| A | 100 | 200 | 10,000 | 90 | 100 |
| B | 200 | 200 | 0 | 220 | 400 |
| C | 300 | 200 | 10,000 | 290 | 100 |
| 합계 | | | 20,000 | | 600 |

**2단계: 평균만 예측하는 방법의 오차와 학습 모델의 오차를 비교한다.**

```text
R² = 1 - (학습 모델의 제곱 오차 합 / 평균 예측의 제곱 오차 합)
   = 1 - (600 / 20000)
   = 1 - 0.03
   = 0.97
```

해석: 평균만 예측하는 기준에 비해 제곱 오차를 97% 줄였다. 또는 해당 데이터의 가격 변동을 모델이 약 97% 설명한다고 말한다. 개별 가격을 97% 정확하게 맞혔다는 의미는 아니다.

| R² 값 | 의미(정답이 모두 동일하지 않은 경우) |
|---|---|
| 1 | 예측값과 실제값이 모두 일치한다. |
| 0.8 | 평균 기준의 제곱 오차보다 80% 감소했다. |
| 0 | 평균만 사용하는 기준과 제곱 오차가 같다. |
| 음수 | 평균만 사용하는 기준보다 모델의 제곱 오차가 더 크다. |

수업 코드에 `# R SCORE : 0~1`이라는 주석이 있었지만, 일반적인 R²는 음수도 가능하다는 점을 보충한다. 오늘처럼 절편이 있는 기본 선형 회귀 모델을 학습 데이터 자체에 평가한 결과는 보통 0~1에 있다. 새로운 데이터에 평가하면 음수가 나올 수도 있다.

```python
print(f"R_SCORE = {r2_score(y, y_pred):.3}")
```

한글 풀이: 실제 가격과 예측 가격을 비교해 결정계수를 계산하고 유효 숫자 3자리의 형태로 출력한다. `.3`은 `.3f`와 다르다. `.3f`는 소수점 이하를 정확히 세 자리로 표시하고, `.3`은 실수의 기본 형식에서 유효 숫자 세 자리 정도로 표시한다.

### 12-5. f-string 출력 서식 복습

```python
value = 2492.503948887723
print(f"{value:,.0f}")  # 2,493
print(f"{value:,.2f}")  # 2,492.50
```

- `{value}`: 변수 값을 문자열 안에 넣는다.
- `:`: 값 뒤에 출력 서식을 지정한다.
- `,`: 천 단위 구분 기호를 넣는다.
- `.0f`: 소수점 이하 0자리로 반올림하여 표시한다.
- `.2f`: 소수점 이하 2자리로 표시한다.

출력 서식은 표시만 바꿀 뿐 실제 값이나 모델은 변경하지 않는다.

### 12-6. 수업 실제 평가 코드와 결과

```python
from sklearn.metrics import mean_absolute_error, mean_squared_error, root_mean_squared_error, r2_score

print(f"MAE = {mean_absolute_error(y, y_pred):,.0f}")
print(f"MSE = {mean_squared_error(y, y_pred):,.0f}")
print(f"RMSE = {root_mean_squared_error(y, y_pred):,.0f}")
print(f"R_SCORE = {r2_score(y, y_pred):.3}")
```

```text
MAE = 2,493
MSE = 16,240,971
RMSE = 4,030
R_SCORE = 0.803
```

| 지표 | 결과 | 한글 해석 |
|---|---:|---|
| MAE | 2,493 | 매물 하나당 평균 절대 가격 오차가 약 2493이다. |
| MSE | 16,240,971 | 오차를 제곱해 평균 낸 값이다. 가격 단위의 제곱이다. |
| RMSE | 4,030 | 큰 오차에 민감한 지표를 원래 가격 단위로 표현했다. |
| R² | 0.803 | 평균 가격만 예측하는 기준과 비교해 제곱 오차를 약 80.3% 줄였다. |

RMSE가 MAE보다 크게 나타났다. 특히 우리가 만든 특이 매물들이 큰 오차를 발생시켰을 가능성을 살펴볼 수 있다. 다음 실습에서 실제로 확인한다.

**중요:** 이 결과는 학습에 사용한 200건을 그대로 평가한 학습 데이터 성능이다. 새로운 매물에서도 같은 수준으로 맞힌다는 보장은 없다. 이후에는 학습용 데이터와 시험용 데이터를 분리하는 방식이 필요하지만, 오늘 노트북에서는 그 작업을 하지 않았다.

## 13. Boolean Mask (불리언 마스크) — 특이 매물 구분하기

### 13-1. 왜 특이 매물을 다시 꺼내는가?

앞에서 가상 데이터 200건을 만들 때 일부 매물 5건의 가격을 의도적으로 크게 올렸다. 이제 그 매물들을 평가에서 빼면 평균 오차가 어떻게 변하는지 알아보려고 한다.

Boolean은 참(True)과 거짓(False)의 자료형이다. Mask는 선택할 데이터를 표시하는 가림막이라고 생각하면 된다.

```text
원본 데이터       [100,   200,   300,   400]
선택 마스크       [True, False, True, False]
선택 결과         [100,         300]
```

지난 Pandas 조건 필터링에서도 같은 원리를 활용했다. `df[조건]`은 조건이 True인 행만 선택한다. 오늘은 조건을 직접 만드는 대신 특이 매물의 위치를 알고 있으므로 True/False 배열을 만든다.

### 13-2. 모든 위치가 True인 배열 만들기

```python
normal = np.ones(len(office), dtype=bool)
```

| 구성 | 한글 풀이 |
|---|---|
| `len(office)` | 오피스텔 표의 행 개수를 구한다. 200을 반환한다. |
| `np.ones()` | 지정한 크기만큼 1로 채운 배열을 생성한다. |
| `dtype` | Data Type(자료형)을 지정하는 매개변수 |
| `bool` | True, False의 불리언 자료형 |
| `normal` | 정상 매물 여부를 표시하는 배열을 저장할 변수 |

한글 해석: 매물 개수 200만큼의 배열을 생성하고 자료형을 bool로 지정한다. 숫자 1은 불리언 True로 저장되므로 모든 위치가 True인 배열이 만들어진다.

```python
# 이해용 예시: 데이터가 5건일 때
np.ones(5, dtype=bool)
# array([ True, True, True, True, True])
```

`normal`은 변수 이름이다. 이전에 사용한 `rng.normal()`이라는 정규분포 난수 함수와 구분해야 한다.

### 13-3. 특이 매물 위치만 False로 변경

```python
normal[special] = False
```

`special`은 앞에서 무작위 선택한 매물 번호 5개가 들어 있는 NumPy 배열이다. `normal[special]`은 해당 위치들을 한꺼번에 선택한다. `= False`는 선택된 위치의 값을 거짓으로 변경한다.

이해용 예시:

```python
normal = np.ones(5, dtype=bool)
special = np.array([1, 3])
normal[special] = False
# array([True, False, True, False, True])
```

| 인덱스 | 변경 전 | 변경 후 | 의미 |
|---:|---|---|---|
| 0 | True | True | 평가에 포함 |
| 1 | True | False | 평가에서 제외 |
| 2 | True | True | 평가에 포함 |
| 3 | True | False | 평가에서 제외 |
| 4 | True | True | 평가에 포함 |

실제 `office` 표의 행을 지운 것이 아니다. 어떤 행을 선택할 것인지 표시한 마스크만 변경했다.

### 13-4. 특이 매물 번호와 정상 매물 개수 확인

```python
print("특이매물:", special)
print("정상매물:", normal.sum())
```

첫 줄은 특이 매물의 위치를 출력한다. 두 번째 줄의 `.sum()`은 배열의 원소를 합산한다. 불리언 배열에서 True는 1, False는 0으로 계산되므로 True의 개수가 반환된다.

실제 출력:

```text
특이매물: [53 13  2 92 71]
정상매물: 195
```

즉 normal 배열의 길이는 여전히 200이고, True가 195개, False가 5개이다. 평가할 때만 True인 위치의 데이터를 선택한다.

## 14. 전체 200건과 특이 매물 제외 195건의 평가 비교

이 부분은 난수 생성, 리스트, 튜플, for문, Boolean Mask, 모델 평가 함수가 모두 연결되는 종합 실습이다.

### 14-1. 비교할 두 가지 경우를 준비한다

```python
all_rows = np.ones(len(office), dtype=bool)
cases = [("전체 200건", all_rows), ("특이매물 제외한 195건", normal)]
```

`all_rows`는 모든 매물을 선택하는 True 200개의 배열이다. `normal`은 특이 매물 5개 위치만 False인 배열이다.

두 번째 줄의 구조를 펼치면 다음과 같다.

```python
cases = [
    ("전체 200건", all_rows),
    ("특이매물 제외한 195건", normal)
]
```

| 구성 | 한글 풀이 |
|---|---|
| 바깥쪽 `[ ... ]` | 두 가지 경우를 담는 리스트 |
| `("전체 200건", all_rows)` | 이름 문자열과 마스크 배열을 짝지은 튜플 |
| `("특이매물 제외한 195건", normal)` | 두 번째 경우의 이름과 마스크를 짝지은 튜플 |
| `cases` | 비교할 여러 경우(Case)를 저장한 변수 |

한글 해석: 평가할 두 종류의 데이터를 이름과 선택 기준으로 묶어서 리스트에 저장한다. 같은 평가 코드를 두 번 복사하지 않고 for문으로 반복하기 위해서이다.

### 14-2. 반복문과 튜플 언패킹

```python
for name, mask in cases:
```

`for`는 리스트에서 원소를 하나씩 꺼내 반복한다. `cases`의 각 원소가 두 값을 담은 튜플이므로 `name, mask`로 나누어 저장할 수 있다. 이것을 튜플 언패킹이라고 한다.

| 반복 | name에 들어가는 값 | mask에 들어가는 값 |
|---|---|---|
| 1회차 | 전체 200건 | all_rows (True 200개) |
| 2회차 | 특이매물 제외한 195건 | normal (True 195개, False 5개) |

### 14-3. 실제 가격과 예측 가격을 같은 마스크로 선택한다

```python
    y_true = y[mask]
    y_hat = y_pred[mask]
```

| 구성 | 한글 풀이 |
|---|---|
| `y` | 원본 실제 가격 200건(Series) |
| `y_pred` | 원본 순서의 예측 가격 200건(NumPy 배열) |
| `[mask]` | True인 위치만 선택한다. |
| `y_true` | 이번 평가에 사용할 실제 가격을 저장한다. |
| `y_hat` | 이번 평가에 사용할 예측 가격을 저장한다. |

`y_true`에서 true는 실제 정답이라는 뜻이다. 변수 자체가 True/False의 배열이라는 뜻이 아니다. `y_hat`은 수학에서 예측값을 ŷ(y-hat)으로 표기하는 관례를 따른 변수 이름이다.

한글 해석: 이번 반복에서 평가할 매물만 실제 가격과 예측 가격 양쪽에서 같은 위치로 선택한다.

왜 똑같은 마스크를 사용해야 할까? 예를 들어 실제값의 두 번째 매물을 제외했다면 예측값에서도 두 번째 매물을 제외해야 동일한 매물끼리 비교할 수 있기 때문이다. 여기서 정렬된 `line_pred`를 사용하면 순서가 맞지 않을 수 있다.

### 14-4. 선택된 데이터의 오차 계산 및 출력

```python
    mae = mean_absolute_error(y_true, y_hat)
    rsme = root_mean_squared_error(y_true, y_hat)
    r2 = r2_score(y_true, y_hat)
    print(f"{name} MAE{mae} | RSME {rsme} | RScore {r2}")
```

| 코드 | 한글 풀이 |
|---|---|
| `mae = mean_absolute_error(y_true, y_hat)` | 선택한 실제 가격과 예측 가격의 평균 절대 오차를 구하여 저장한다. |
| `rsme = root_mean_squared_error(y_true, y_hat)` | 선택한 데이터의 평균 제곱근 오차를 구하여 저장한다. |
| `r2 = r2_score(y_true, y_hat)` | 선택한 데이터의 결정계수를 구하여 저장한다. |
| `print(f"{name} ...")` | 현재 평가 대상 이름과 각 평가 결과를 한 줄에 출력한다. |

원본 수업에서 변수 이름과 출력에 `rsme`, `RSME`를 사용했지만 지표의 정확한 약자는 `RMSE`이다. 변수 이름을 일관되게 사용했기 때문에 계산 오류는 발생하지 않았다.

### 14-5. 전체 실습 코드(원본)

```python
all_rows = np.ones(len(office), dtype=bool)
cases = [("전체 200건", all_rows), ("특이매물 제외한 195건", normal)]

for name, mask in cases:
    y_true = y[mask]
    y_hat = y_pred[mask]

    mae = mean_absolute_error(y_true, y_hat)
    rsme = root_mean_squared_error(y_true, y_hat)
    r2 = r2_score(y_true, y_hat)
    print(f"{name} MAE{mae} | RSME {rsme} | RScore {r2}")
```

실제 수업 출력:

```text
전체 200건 MAE2492.503948887723 | RSME 4030.0088601264406 | RScore 0.8034139611533421
특이매물 제외한 195건 MAE2075.1039768452683 | RSME 2731.5353914457346 | RScore 0.9023854405903358
```

| 평가 지표 | 전체 200건 | 특이 매물 제외 195건 | 해석 |
|---|---:|---:|---|
| MAE | 2492.50 | 2075.10 | 평균 절대 오차 감소 |
| RMSE | 4030.01 | 2731.54 | 큰 오차에 민감한 지표가 특히 감소 |
| R² | 0.803 | 0.902 | 평가 대상에서 평균 기준 대비 설명력이 높아짐 |

RMSE는 특이 매물에 포함된 큰 가격 오차에 특히 민감했음을 확인할 수 있다. R²는 평가 데이터마다 실제 가격 평균과 분산이 달라지므로 두 숫자는 각 집단에서의 상대적 지표이다.

**오늘 가장 중요한 주의점: 모델을 다시 학습시킨 것은 아니다.** `model.fit()`은 앞에서 전체 200건으로 한 번 수행했다. 위 반복문은 그 모델이 이미 계산한 `y_pred`의 일부를 선택하여 평가할 뿐이다. 기울기와 절편은 그대로이며, 평가 대상만 달라졌다. 따라서 평가 지표가 좋아졌다고 모델 자체가 개선되었다고 말하면 안 된다. 실제 서비스를 만들 때는 특이 매물의 원인과 데이터의 대표성을 검토해야 한다.

## 15. 변수들의 연결 관계 — 이름이 헷갈릴 때 보는 표

| 변수 | 무엇을 저장하는가? | 어디에서 만들어졌나? | 다음 사용처 |
|---|---|---|---|
| `rng` | 난수 생성기 객체 | `np.random.default_rng(40)` | uniform, normal, choice |
| `n` | 매물 수 200 | `n = 200` | 난수 개수, 선택 후보 |
| `area` | 무작위 면적 배열 200개 | `rng.uniform()` | 가격 생성, 표 만들기 |
| `price` | 가상 실제 가격 배열 200개 | 면적 공식 + 노이즈 + 특이 매물 추가 | office 표 |
| `special` | 특이 매물 위치 5개 | `rng.choice()` | 가격 추가, 마스크 설정 |
| `office` | 면적·가격 표 200행 2열 | `pd.DataFrame()` | 시각화, X/y 구성 |
| `X` | 면적 입력 표 200행 1열 | `office[["area"]]` | fit, predict, sort_values |
| `y` | 실제 가격 Series 200개 | `office["price"]` | fit, 평가 |
| `model` | 선형 회귀 모델 객체 | `LinearRegression()` | fit, predict, 학습 속성 |
| `new` | 새로운 면적 2행 1열 | `pd.DataFrame()` | 새로운 가격 예측 |
| `y_pred` | 원본 순서의 예측 가격 200개 | `model.predict(X)` | 평가 |
| `line` | 정렬된 면적 표 200행 1열 | `X.sort_values("area")` | 회귀 직선의 X축, 예측 |
| `line_pred` | 정렬 순서의 예측 가격 200개 | `model.predict(line)` | 회귀 직선의 Y축 |

| `y_true`, `y_hat` | 현재 평가 대상의 실제 가격, 예측 가격 | `y[mask]`, `y_pred[mask]` | MAE, RMSE, R² |

핵심 변수의 흐름:

```text
area ──가격 생성──→ price
  └─────────┬────────┘
          office
         ↙      ↘
        X        y (실제 가격)
         ↘      ↙
       model.fit(X, y)
             ↓
        학습된 model
      ↙       ↓         ↘
   predict(new)  predict(X)    predict(line)
   새 가격       y_pred       line_pred → 직선 그래프
                    ↓
       y와 y_pred 비교 (같은 순서)
                    ↓
           평가 지표 계산
                    ↓
    all_rows / normal 마스크로 비교
```

## 17. 마지막으로 전체 흐름을 작은 데이터로 다시 읽어보기

아래는 오늘 배운 핵심 과정만 연결한 **복습용 추가 예제**다. 실제 수업의 200건 코드와 결과가 아닌, 작은 데이터로 과정을 확인하기 위한 예제이다.

```python
import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error

# 1. 학습할 면적과 실제 가격을 표로 준비한다.
example = pd.DataFrame({"area": [10, 20, 30], "price": [30, 50, 70]})

# 2. 입력(2차원 표)과 정답(1차원 Series)을 나눈다.
X_small = example[["area"]]
y_small = example["price"]

# 3. 모델을 만들고 면적과 실제 가격을 함께 학습시킨다.
small_model = LinearRegression()
small_model.fit(X_small, y_small)

# 4. 모델이 찾은 공식의 기울기와 절편을 확인한다.
print(small_model.coef_[0])      # 약 2
print(small_model.intercept_)    # 약 10

# 5. 새로운 면적 40을 넣고 가격을 예측한다.
new_small = pd.DataFrame({"area": [40]})
print(small_model.predict(new_small))  # [90.]

# 6. 기존 면적의 가격을 예측하고 실제 가격과 비교한다.
small_pred = small_model.predict(X_small)
print(mean_absolute_error(y_small, small_pred))  # 0 또는 부동소수점 오차 수준
```

이 예제는 정확한 직선 위에 있는 세 데이터를 사용하여 가장 단순한 모델 학습을 보여 준다. 큰 노이즈나 특이 매물이 없으므로 모델이 `가격 = 면적×2+10`이라는 규칙을 찾는다. 오늘 수업의 200건은 이 과정에 무작위 오차와 특이 매물이 추가된 것이다.

| 헷갈리는 개념 | 한 문장으로 구분 |
|---|---|
| 상관계수 vs 선형 회귀 | 상관계수는 함께 변하는 정도, 선형 회귀는 결과를 예측할 공식 찾기 |
| 기울기 vs 절편 | 입력이 1 늘 때 결과가 얼마나 변하는지 / 입력이 0일 때 결과 |
| fit vs predict | 규칙을 학습함 / 학습한 규칙으로 계산함 |
| X vs y | 알고 있는 입력 / 실제 정답 |
| y vs y_pred | 실제 가격 / 모델의 예측 가격 |
| y_pred vs line_pred | 원본 순서의 예측값 / 그래프용 정렬 순서의 예측값 |
| MAE vs MSE vs RMSE | 절댓값 평균 / 제곱 평균 / 제곱 평균의 제곱근 |
| 상관계수 vs R² | 두 변수의 선형 관계 방향·강도 / 평균 기준 대비 모델의 제곱 오차 감소 정도 |
| 마스크 vs 데이터 삭제 | 선택 여부 표시 / 원본 자체에서 제거 |
| 평가 대상 변경 vs 재학습 | 같은 모델의 일부 결과만 측정 / 모델의 기울기·절편을 다시 학습 |

## 18. 복습 순서 및 이해도 체크

오늘은 모든 라이브러리 메서드를 외우는 것보다 코드의 연결 관계를 이해하는 것이 우선이다. 아래 순서대로 읽고, 이해되지 않는 항목의 예시로 돌아간다.

### 1순위 — 전체 흐름과 모델의 역할

- [ ] 오늘 왜 가상 오피스텔 데이터를 만들었는지 설명할 수 있다.
- [ ] `y = wx + b`에서 x, y, w, b가 무엇인지 설명할 수 있다.
- [ ] `X`를 2차원 DataFrame, `y`를 1차원 Series로 선택한 이유를 설명할 수 있다.
- [ ] `LinearRegression()`, `fit()`, `predict()`가 서로 무엇이 다른지 설명할 수 있다.
- [ ] `model.coef_[0]`과 `model.intercept_`에 괄호가 없는 이유를 안다.

### 2순위 — 예측과 평가를 연결하기

- [ ] `y_pred`, `line`, `line_pred`를 각각 어떤 목적으로 생성하는지 설명할 수 있다.
- [ ] 실제값과 예측값을 같은 행 순서로 비교해야 하는 이유를 안다.
- [ ] 오차가 양수·음수일 때 의미와 절댓값, 제곱, 제곱근의 차이를 이해한다.
- [ ] 작은 숫자 3개로 MAE, MSE, RMSE를 직접 계산해 볼 수 있다.
- [ ] R²가 예측 정확도의 백분율이 아니라는 것을 설명할 수 있다.

### 3순위 — 종합 실습

- [ ] 난수 시드, uniform, normal, choice의 역할을 이해한다.
- [ ] `normal[special] = False`가 원본 데이터를 삭제하지 않는다는 점을 안다.
- [ ] `for name, mask in cases:`가 어떻게 두 번 반복되는지 설명할 수 있다.
- [ ] 특이 매물 제외 후 평가 지표가 좋아졌지만 재학습은 하지 않았다는 점을 안다.

### 오늘의 핵심 한 문장

**데이터로부터 가격 예측 규칙을 학습하고, 그 규칙으로 가격을 예측한 뒤, 실제 가격과의 차이를 측정하여 모델을 이해하는 과정을 실습했다.**
