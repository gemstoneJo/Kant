# 6. 결측치 확인하기

## 결측치란?

**결측치(Missing Value)** 는 데이터가 누락되거나 기록되지 않은 값을 의미한다.

예를 들어 어떤 승객의 나이 정보가 없다면 `age` 열에는 `NaN`이 들어 있을 수 있다.

`NaN`은 Not a Number의 약자로, Pandas에서 누락된 수치 등을 표현할 때 사용하는 특수한 값이다.

## 6-1. 결측치 개수 확인

```python
df.isnull().sum()
```

### 한글 풀이

"전체 데이터에서 빈칸이 어디에 있는지 확인하고, 각 열마다 빈칸이 몇 개 있는지 세어줘."

### 코드 분해

```python
df.isnull()
```

→ 전체 데이터의 값이 비어 있는지 확인한다.

- 빈칸이면 `True`
- 값이 있으면 `False`

```python
df.isnull().sum()
```

→ 각 열에서 `True`의 개수를 합산한다.

### 주요 실행 결과

| 열 이름 | 결측치 |
|---|---:|
| age | 177 |
| embarked | 2 |
| deck | 688 |

### loc 문법

```python
df.loc[행 조건, 열 선택]
```

`loc`는 원하는 행과 열을 선택할 때 사용한다.

예를 들어:


한국어:

이렇게 `True`, `False` 조건으로 데이터를 선택하는 방법을 **불리언 인덱싱(Boolean Indexing)** 이라고 한다.

# 7. 평균과 중앙값으로 결측치 처리

## 7-1. 평균(Mean)

모든 값을 더한 후 개수로 나눈 값이다.

예를 들어:

`10, 20, 30`

평균 = (10 + 20 + 30) / 3 = 20

```python
df["age"].mean()
```

한국어:

"승객들의 나이에서 비어 있는 값은 제외하고 평균을 계산해라."

## 7-2. 중앙값(Median)

데이터를 작은 값부터 정렬했을 때 중앙에 위치하는 값이다.

예를 들어:

`10, 20, 30, 40, 100`

- 평균 = 40
- 중앙값 = 30

극단적으로 큰 값인 100 때문에 평균이 높아졌지만 중앙값은 30이다.

중앙값은 평균에 비해 극단적인 값의 영향을 덜 받는다.

## 7-3. 평균과 중앙값 계산

```python
print("평균:", round(df["age"].mean(), 2))
print("중앙값:", round(df["age"].median(), 2))
```

### 한글 풀이

"전체 승객들의 평균 나이를 계산하고 소수점 둘째 자리까지 반올림해서 출력해라."

"전체 승객들의 나이를 순서대로 정렬했을 때 중앙에 있는 값도 계산해서 출력해라."

원본 데이터 기준:

```text
평균: 29.7
중앙값: 28.0
```

### 새로운 문법

- `mean()`: 평균
- `median()`: 중앙값
- `round(값, 2)`: 소수점 둘째 자리까지 반올림

## 7-4. 빈칸을 평균으로 채우기

```python
mean_age = df["age"].mean()

df.loc[:, "age"] = df["age"].fillna(mean_age)
```

### 한글 풀이

**첫 번째 줄**

"승객들의 평균 나이를 계산해서 `mean_age`라는 변수에 저장해라."

**두 번째 줄**

"모든 승객의 나이 열에서 값이 비어 있는 부분만 찾아서, 앞에서 계산한 평균 나이로 채운 후 다시 나이 열에 저장해라."

### 코드 단계별 분석

```python
df["age"]
```

→ 나이 열을 선택한다.

```python
df["age"].fillna(mean_age)
```

→ 나이가 비어 있는 곳을 평균 나이로 채운 결과를 만든다.

```python
df.loc[:, "age"] = ...
```

→ 모든 행의 나이 열에 그 결과를 다시 저장한다.

### fillna란?

`fillna()`는 결측치를 지정한 값으로 채우는 메서드다.

`fill`은 채운다는 뜻이고, `na`는 결측값을 가리킨다.

### 왜 결측치를 채울까?

나이가 없는 승객을 모두 삭제하면 다른 유용한 승객 정보까지 잃어버릴 수 있다.

따라서 이번 실습에서는 평균값으로 대체했다.

다만 177명의 실제 나이를 알아낸 것은 아니며, 통계적인 값으로 추정해 채운 것이다.

이 방법을 **평균 대체(Mean Imputation)** 라고 한다.

```text
Southampton    644
Cherbourg      168
Queenstown      77
NaN              2
```

### 코드 분석

- `value_counts()`: 각각의 값이 몇 번 등장하는지 계산
- `dropna=False`: 결측치를 결과에서 제외하지 않음

## 8-2. 최빈값으로 결측치 채우기

```python
mode_town = df["embark_town"].mode()[0]

df.loc[:, "embark_town"] = df["embark_town"].fillna(mode_town)
```

### 한글 풀이

**첫 번째 줄**

"승객들이 가장 많이 탑승한 항구를 찾아서 `mode_town`이라는 변수에 저장해라."

**두 번째 줄**

"탑승 항구가 비어 있는 승객들의 정보를 가장 많이 등장한 항구 이름으로 채워라."

### 왜 mode()[0]일까?

`mode()`는 최빈값을 하나 이상 반환할 수 있다.

`[0]`은 반환된 최빈값 중 첫 번째 값을 선택한다는 뜻이다.

### 평균과 최빈값의 차이

- 나이, 금액 등의 숫자: 평균 또는 중앙값을 검토
- 지역, 성별, 항구 등의 범주: 최빈값을 검토

실제 전처리 방법은 데이터의 특징과 분석 목적에 따라 결정한다.

# 11. 사분위수와 IQR

## 11-1. 사분위수(Quartile)란?

데이터를 작은 값부터 정렬했을 때, 분포를 네 부분으로 나누어 살펴보기 위한 기준값이다.

- Q1: 제1사분위수, 25% 지점
- Q2: 제2사분위수, 중앙값
- Q3: 제3사분위수, 75% 지점

## 11-2. 승선 요금의 사분위수 확인

```python
print(df["fare"].quantile([0.25, 0.5, 0.75]).round(2))

df["fare"].describe()[["25%", "50%", "75%"]].round(2)
```

### 한글 풀이

**첫 번째 줄**

"전체 승객의 승선 요금을 낮은 값부터 정렬했을 때 25%, 50%, 75% 지점에 해당하는 요금을 계산하고, 소수점 둘째 자리까지 반올림해서 출력해라."

**두 번째 줄**

"승선 요금의 통계 정보에서 25%, 50%, 75%에 해당하는 결과만 골라 보여줘라."

### 새로운 용어

- `quantile()`: 분위수 계산
- `round(2)`: 소수점 둘째 자리까지 반올림
- `describe()`: 기초 통계 정보 출력

## 11-3. IQR 계산

**IQR(Interquartile Range)** 은 사분위 범위라는 뜻이다.

Q3에서 Q1을 뺀 값으로, 데이터의 가운데 50%가 퍼져 있는 범위를 나타낸다.

```python
q1 = df["fare"].quantile(0.25)
q3 = df["fare"].quantile(0.75)

iqr = q3 - q1
```

### 한글 풀이

**첫 번째 줄**

"승선 요금에서 하위 25% 지점에 해당하는 값을 구해 `q1`에 저장해라."

**두 번째 줄**

"승선 요금에서 하위 75% 지점에 해당하는 값을 구해 `q3`에 저장해라."

**세 번째 줄**

"Q3에서 Q1을 뺀 차이를 계산해서 `iqr`에 저장해라."

원본 타이타닉 데이터 기준:

```text
Q1 = 7.91
Q3 = 31.00
IQR = 23.09
```

# 12. 이상치 탐지: Upper와 Lower

## 이상치(Outlier)란?

대부분의 데이터와 비교해 지나치게 크거나 작은 값을 의미한다.

IQR 방식에서는 일정한 계산식을 이용해 이상치를 판단하는 경계를 구한다.

```python
upper = q3 + 1.5 * iqr
lower = q1 - 1.5 * iqr
```

### 한글 풀이

**첫 번째 줄**

"Q3에 IQR의 1.5배를 더해서, 이보다 큰 값은 이상치 후보로 판단할 상한선을 계산해라."

**두 번째 줄**

"Q1에서 IQR의 1.5배를 빼서, 이보다 작은 값은 이상치 후보로 판단할 하한선을 계산해라."

## 중요한 개념: 상한과 하한은 최댓값과 최솟값이 아니다

| 구분 | 의미 |
|---|---|
| Max | 데이터에 실제 존재하는 가장 큰 값 |
| Min | 데이터에 실제 존재하는 가장 작은 값 |
| Upper | 이상치 여부를 판단하기 위한 위쪽 경계 |
| Lower | 이상치 여부를 판단하기 위한 아래쪽 경계 |

원본 데이터에서 승선 요금의 실제 최댓값은 약 512.33이다.

그러나 IQR 기준으로 계산한 상한은 약 65.63이다.

즉, **상한을 초과했다고 실제로 존재할 수 없는 값이라는 뜻은 아니다.**

통계적으로 다른 값들과 차이가 큰 이상치 후보라는 뜻이다.

## 이상치 개수 확인

```python
print("이상 승선요금:", (df["fare"] > upper).sum(), "명")
```

### 한글 풀이

"승선 요금이 계산한 상한선보다 높은 승객들을 찾고, 그 승객이 총 몇 명인지 세어서 출력해라."

### 코드 분해

```python
df["fare"] > upper
```

→ 승선 요금이 상한선보다 큰지 확인한다.

```python
(df["fare"] > upper).sum()
```

→ 조건이 `True`인 승객 수를 계산한다.

# 13. 이상치 데이터 필터링

오늘 가장 헷갈렸던 코드다.

```python
before = len(df)
df = df[df["fare"] < 512].copy()
print(before, "=>", len(df))
```

## 전체 한글 풀이

"먼저 현재 승객이 몇 명인지 기억해 두어라."

"그다음 승선 요금이 512보다 작은 승객만 선택해서 새로운 데이터프레임으로 복사하고, 기존 `df` 변수에 다시 저장해라."

"마지막으로 변경 전 승객 수와 변경 후 승객 수를 출력해라."

## 13-1. 첫 번째 줄

```python
before = len(df)
```

**한글:**

"현재 데이터에 승객이 몇 명 있는지 세고, 그 숫자를 `before`라는 변수에 저장해라."

- `len()`: 데이터 길이 또는 개수를 구하는 함수
- `before`: 변경 전 데이터 개수를 저장하는 변수

## 13-2. 두 번째 줄

```python
df = df[df["fare"] < 512].copy()
```

이 코드는 한 번에 이해하기보다 나눠서 생각하면 쉽다.

### ① 조건 만들기

```python
df["fare"] < 512
```

한글:

"승객마다 승선 요금이 512보다 작은지 검사해라."

결과는 `True` 또는 `False`로 나타난다.

예시:

| 승객 | 요금 | 조건 결과 |
|---|---:|---|
| A | 20 | True |
| B | 50 | True |
| C | 512.33 | False |
| D | 100 | True |

### ② 조건을 만족하는 데이터 선택

```python
df[df["fare"] < 512]
```

한글:

"전체 승객 중 요금이 512보다 작은 승객만 골라라."

`df[조건]`은 조건에 맞는 행만 선택하는 Pandas 문법이다.

SQL에서 배웠던 `WHERE`와 비슷한 역할이다.

예를 들어 SQL에서는:

```sql
SELECT *
FROM passengers
WHERE fare < 512;
```

Pandas에서는:

```python
df[df["fare"] < 512]
```

### ③ 선택한 데이터 복사

```python
df[df["fare"] < 512].copy()
```

한글:

"조건을 만족하는 승객 정보만 별도의 데이터프레임으로 복사해라."

`.copy()`는 독립적인 복사본을 생성하는 메서드다.

### ④ 기존 변수에 다시 저장

```python
df = df[df["fare"] < 512].copy()
```

한글:

"복사한 데이터를 `df`에 다시 저장하여, 앞으로는 필터링한 데이터만 사용하도록 해라."

**중요:** `.copy()`가 데이터를 삭제하는 것은 아니다.

`df[조건]`이 행을 선택하고, `df =`가 선택된 결과로 기존 변수의 값을 바꾼다.

## 13-3. 세 번째 줄

```python
print(before, "=>", len(df))
```

한글:

"변경하기 전 승객 수와 변경한 후 승객 수를 나란히 출력해라."

원본 데이터에서 실행했다면:

```text
891 => 888
```

512 이상 요금을 가진 승객 3명이 제외된 것이다.

## 더 쉽게 나눈 코드

```python
# 기존 승객 수 저장
before = len(df)

# 승선 요금이 512보다 작은 승객 찾기
condition = df["fare"] < 512

# 조건을 만족하는 데이터만 복사
filtered_df = df[condition].copy()

# 변경 전후 비교
print(before, "=>", len(filtered_df))
```

이렇게 작성하면 원래 `df`는 변경하지 않고, 필터링된 결과를 `filtered_df`라는 별도 변수에 보관할 수 있다.

### 주의사항

`< 512`는 정확히 512인 값도 제외한다.

또한 이번 코드에서 사용한 512는 앞서 계산한 IQR 상한선인 약 65.63과 다른 기준이다.

# 14. 중복 데이터 확인

**중복 데이터(Duplicate Data)** 는 동일한 정보가 반복해서 기록된 데이터를 말한다.

```python
print("중복 행:", df.duplicated().sum(), "개")
```

### 한글 풀이

"현재 데이터에서 이전 행과 내용이 중복되는 행이 몇 개 있는지 확인하고 출력해라."

### 코드 분해

```python
df.duplicated()
```

→ 중복된 행을 `True`로 표시한다.

```python
df.duplicated().sum()
```

→ 중복으로 표시된 행의 개수를 계산한다.

## 중복된 데이터 조회

```python
df[df.duplicated(keep=False)].sort_values(["fare", "age"]).head(5)
```

### 한글 풀이

"중복된 데이터에 속하는 행들을 모두 가져온 다음, 승선 요금과 나이를 기준으로 정렬하여 위에서 5개만 보여줘라."

### 새로운 문법

- `duplicated()`: 중복 여부 확인
- `keep=False`: 중복된 행을 모두 표시
- `sort_values()`: 데이터를 지정한 열을 기준으로 정렬

# 15. Matplotlib 데이터 시각화

## 데이터 시각화란?

**Data Visualization**은 데이터를 그래프나 차트로 표현해 데이터의 특징을 눈으로 확인하는 방법이다.

숫자만 보는 것보다 특정 값이 많이 등장하는지, 전체 데이터가 어떻게 분포하는지 쉽게 파악할 수 있다.

## 15-1. 운영체제에 따른 한글 폰트 설정

```python
import platform
import matplotlib.pyplot as plt

os_name = platform.system()

if os_name == "Windows":
    plt.rcParams["font.family"] = "Malgun Gothic"
elif os_name == "Darwin":
    plt.rcParams["font.family"] = "AppleGothic"

plt.rcParams["axes.unicode_minus"] = False
```

"현재 컴퓨터의 운영체제를 확인해라."

"macOS라면 AppleGothic으로 설정해라."

"그리고 마이너스 기호가 깨지는 문제가 없도록 설정해라."

### 코드 분석

- `platform.system()`: 현재 운영체제 확인
- `plt`: Matplotlib의 pyplot 모듈 별칭
- `rcParams`: Matplotlib 설정값 모음
- `font.family`: 글꼴 설정
- `axes.unicode_minus`: 마이너스 기호 표시 설정

"그래프 제목을 나이분포로 정하고, 가로축 이름을 나이(세)로 설정해라."

"완성한 그래프를 화면에 보여줘라."

## 코드 분석

### ① 그래프 영역 생성

```python
fig, ax = plt.subplots(figsize=(6, 4))
```

- `fig`: 그래프 전체 그림 영역
- `ax`: 실제 그래프를 그리는 영역
- `subplots()`: Figure와 Axes 생성
- `figsize`: 그림의 크기

### ② 히스토그램 생성

```python
ax.hist(df["age"], bins=20)
```

한글:

"승객 나이를 20개 구간으로 나누고, 각 구간에 몇 명의 승객이 있는지 막대그래프로 표현해라."

### 히스토그램(Histogram)이란?

연속적인 숫자 데이터를 일정한 구간으로 나누고 구간별 빈도를 나타내는 그래프다.

예를 들어 나이를 0~10세, 10~20세, 20~30세 등의 구간으로 나누어 각 구간에 승객이 얼마나 있는지 볼 수 있다.

### ③ 막대 색상

```python
color="blue"
edgecolor="black"
```

- `color`: 막대 내부 색상
- `edgecolor`: 막대 테두리 색상

### ④ 제목과 축 이름

```python
ax.set_title("나이분포")
ax.set_xlabel("나이(세)")
```

- `set_title()`: 그래프 제목 설정
- `set_xlabel()`: 가로축 이름 설정

### ⑤ 화면 출력

```python
plt.show()
```

한글:

"지금까지 작성한 그래프를 화면에 표시해라."

- `ValueError`: 함수에 전달한 값이 허용되지 않음

Python은 철자와 대소문자를 구분하므로 오타가 있으면 정상 실행되지 않을 수 있다.
