**왜 어제의 데이터 분석이 오늘의 머신러닝으로 이어지는가?** 산점도와 상관계수로 공부 시간과 성적이 함께 증가하는 경향을 확인할 수 있지만, 상관계수 자체는 6시간 공부한 학생이 몇 점을 받을지 알려주지 않는다. 선형회귀는 이 관계를 수치 공식으로 학습해 새로운 예측을 가능하게 한다.

프로그래밍 방식으로 비교하면 사람이 `score = 10 * hours + 35`라고 직접 작성하는 대신, 모델에 공부 시간과 실제 성적을 전달하고 모델이 10과 35를 계산하도록 한다. 정답을 제공하므로 이번 실습은 지도학습 중 회귀에 해당한다. 학습할 때는 X와 y를 모두 사용하지만 예측할 때는 X만 사용한다.

> 이 문서의 코드와 실행 결과는 전체 수업 파일을 기준으로 하고, 용어의 상세 정의와 수학 예시는 이해를 위한 보충 설명으로 구분한다. 아래 코드들은 학습 단계별로 읽도록 구성되어 있으므로 위에서부터 순서대로 실행한다.

## 2. 단순선형회귀 (Simple Linear Regression)

입력 변수 하나와 연속형 결과값 사이의 관계를 직선으로 나타내는 모델이다.

- 예측 공식: `y_pred = w * x + b`
- `x`: 입력값(독립변수, Feature)
- `y`: 실제 정답(종속변수, Target)
- `y_pred`: 모델이 계산한 예측값
- `w`: Weight, 회귀계수(기울기)
- `b`: Bias, 절편

### 선형, 회귀, 가중치, 절편을 구분하기 (기초 보충)

수학에서 기울기는 가로축의 값이 한 단위 변했을 때 세로축의 값이 얼마나 변하는지를 말한다. 예를 들어 (1, 45)에서 (2, 55)로 이동하면 가로 변화는 1, 세로 변화는 10이므로 기울기는 10/1 = 10이다. `w=10`은 공부 시간을 한 시간 더 입력할 때 모델 예측값이 10점 늘어난다는 뜻이다. 실제 모든 학생이 반드시 10점 오르는 인과관계를 의미하지는 않는다.

`b=35`는 x가 0일 때 직선이 y축과 만나는 위치이다. **절편(Intercept)**이라는 용어는 축과 만나는 점의 좌표에서 나온다. 머신러닝에서는 이 상수항을 Bias(편향)라고 부르기도 한다. 입력이 0이어도 모델이 기본적으로 35를 더한다. 관측 데이터에 0시간 학생이 없으므로 35점은 모델의 계산이지 실제 관측 점수는 아니다.

`Weight`는 입력에 곱하는 값이라는 점이 중요하다. 입력이 하나면 회귀직선의 기울기와 같다. 여러 입력이 있으면 입력마다 가중치가 따로 존재한다.

예측값 위에 모자처럼 붙이는 기호 `ŷ`(y-hat)는 실제 정답 y와 모델이 계산한 값을 구별하기 위한 표기이다. Python에서는 보통 `y_pred`라는 변수명으로 표현한다.

```python
import pandas as pd

data = {

    "scores": [47, 53, 65, 73, 87],
}

df = pd.DataFrame(data)
df
```

| hours | scores |
|---:|---:|
| 1 | 47 |
| 2 | 53 |
| 3 | 65 |
| 4 | 73 |
| 5 | 87 |

scikit-learn의 `LinearRegression` 클래스를 가져와 모델을 만들 준비를 한다. `plt.rcParams["font.family"]`는 그래프 글꼴 설정이다.

### 2-2. Feature와 Target 분리

```python
X = df[["hours"]]
y = df["scores"]
```

| 코드 | 반환 형식 | shape | 역할 |
|---|---|---|---|
| `df[["hours"]]` | DataFrame, 2차원 | (5, 1) | 입력 데이터 |
| `df["scores"]` | Series, 1차원 | (5,) | 정답 데이터 |

`X`는 행이 학생, 열이 특성이 되는 표 구조를 유지한다. 입력 특성이 한 개라도 scikit-learn의 일반적인 입력 형식은 2차원이다. `y`는 학생마다 정답 하나가 있으므로 1차원으로 사용한다. `X`의 대문자, `y`의 소문자는 관례이며 문법적 강제는 아니다.

#### 대괄호를 한 번, 두 번 쓰는 이유를 분해해서 읽기

`df[["hours"]]`에서 안쪽 `["hours"]`는 선택할 컬럼 이름을 원소로 가진 Python 리스트다. 바깥쪽 `df[...]`는 DataFrame에서 값을 선택하는 문법이다. 즉 **컬럼 하나를 담은 리스트를 DataFrame에 전달한다**는 뜻이다.

`df["scores"]`에서는 리스트 대신 문자열 하나를 전달하므로 Series가 반환된다. 두 방법 모두 값의 개수는 5개지만 데이터의 구조가 다르다.

```python
print(X.shape)  # (5, 1): 5행 1열
print(y.shape)  # (5,): 원소 5개인 1차원 구조
```

| 기호 | 읽는 방법 |
|---|---|
| `shape` | 데이터의 차원별 크기를 담은 속성. 괄호 없이 조회 |
| `(5, 1)` | 행 5개, 컬럼 1개인 2차원 구조 |
| `(5,)` | 원소 5개의 1차원 구조. 쉼표는 원소 하나인 튜플 표기 |

X를 2차원으로 유지하면 다음 수업에서 `df[["study_hours", "sleep_hours", "practice_count"]]`처럼 특성을 늘려도 동일한 방식으로 모델을 학습할 수 있다. X와 y의 각 행은 서로 대응해야 한다. 학생 한 명의 공부 시간과 다른 학생의 점수를 잘못 연결하면 모델이 엉뚱한 관계를 학습한다.

### 2-3. 모델 생성 및 학습

```python
model = LinearRegression()
model.fit(X, y)

print(f"기울기: {model.coef_[0]:.2f}")
print(f"절편: {model.intercept_:.2f}")
```

```text
기울기: 10.00
절편: 35.00
```

- `LinearRegression()`: 모델 객체를 생성한다. 아직 데이터에 맞게 학습하지 않은 상태다.
- `model.fit(X, y)`: 입력값과 정답을 전달하여 가장 잘 맞는 회귀계수 및 절편을 구한다. 학습한 모델 자신을 반환한다.
- `model.coef_`: 학습한 회귀계수 배열 `[10.]`을 조회한다.
- `[0]`: 첫 번째 특성에 해당하는 회귀계수를 꺼낸다.
- `model.intercept_`: 단일 타깃 모델의 절편 `35.0`을 조회한다.
- `fit()`은 실행하는 메서드, `coef_`와 `intercept_`는 저장된 값을 조회하는 속성이므로 괄호를 붙이지 않는다.

#### `model = LinearRegression()`과 `model.fit(X, y)`의 차이

| 코드 요소 | 한글 설명 |
|---|---|
| `model` | 내가 정한 변수 이름. 모델 객체를 저장한다. |
| `LinearRegression()` | 클래스의 생성자 호출. 설정값을 가진 새 모델 객체를 만든다. |
| `fit` | 영어로 맞추다라는 뜻. 입력과 정답에 맞게 모델을 학습하는 메서드다. |
| `(X, y)` | 첫 번째 인수 X는 입력, 두 번째 인수 y는 실제 정답이다. |
| 반환값 | 학습이 완료된 모델 자신(self). model 내부의 학습 상태도 변경된다. |

한글 해석: **model이라는 선형회귀 객체에 입력 데이터 X와 실제 정답 y를 전달해서 둘 사이의 관계를 학습시켜라.**

왜 model = model.fit(X, y)로 저장하지 않아도 될까? `fit()`은 기존 model 객체 내부에 학습 결과를 저장하며 모델 자신을 반환하기 때문이다. 이전 객체지향 수업에서 배운 객체의 메서드가 자신의 속성을 바꾸는 것과 연결된다.

#### 학습 결과의 자료형 차이

`model.coef_`는 입력 특성마다 회귀계수를 저장하므로 배열 `[10.]`이다. `model.coef_[0]`은 공부 시간에 해당하는 계수 10을 꺼낸다. `model.intercept_`는 이번 단일 타깃 LinearRegression에서 스칼라 35.0이지만, SGDRegressor에서는 배열이므로 `sgd.intercept_[0]`을 사용한다. 학습 후 생성되는 공개 속성 뒤의 `_`는 scikit-learn의 관례다.

### 2-4. 모델 상세 설정 및 학습 결과

| Parameters | 값 | 설명 |
|---|---|---|
| `fit_intercept` | True | 절편을 함께 학습한다. False면 절편 0으로 고정하고 기울기도 다시 학습한다. |
| `copy_X` | True | 입력을 복사한다. False면 원본이 변경될 수 있다. |
| `tol` | 1e-06 | 수치 계산에 쓰이는 허용 기준. 수업 파일에 포함된 1.9 문서 설명에서는 밀집 입력에도 적용된다. |
| `n_jobs` | None | 병렬 작업 수. 기본적으로 1이며 특정 조건에서만 속도 향상이 가능하다. |
| `positive` | False | 음수 회귀계수도 허용한다. True는 회귀계수를 0 이상으로 제한한다. |

| Fitted attributes | 값 | 설명 |
|---|---|---|
| `coef_` | [10.] | 회귀계수 배열 |
| `intercept_` | 35 | 절편 |
| `feature_names_in_` | ['hours'] | 학습에 사용한 컬럼명 |
| `n_features_in_` | 1 | 학습에 사용한 특성 개수 |
| `rank_` | 1 | 입력 행렬의 선형 독립 방향 수 |
| `singular_` | [3.16] | 입력 행렬의 특잇값, 수치적 구조를 파악하는 값 |

`ndarray`는 NumPy 배열, `float64`는 64비트 실수형, `int64`는 64비트 정수형이다. `(1,)`은 원소가 하나인 1차원 배열의 shape다. `rank_`와 `singular_`는 정확도나 예측 오차가 아니다.

#### 추가 용어: 모델 설정값과 학습된 속성

- `fit_intercept=True`: 절편까지 함께 구하도록 설정한다. False면 절편이 0인 모델을 새로 학습한다. 기존 기울기를 그대로 유지하고 35만 제거하는 것이 아니다.
- `copy_X=True`: 학습 계산 중 원본 입력의 변경을 방지하도록 복사한다. 메모리 사용과 관련된 설정이다.
- `tol`: tolerance(허용 기준). `1e-06`은 1×10⁻⁶, 즉 0.000001이다. 점수를 0.000001점 오차로 예측한다는 의미가 아니다. 수업 파일에 포함된 1.9 도움말에서는 희소 입력의 반복 계산 기준 및 밀집 입력의 특잇값 판정 기준으로 쓰인다고 설명한다.
- `n_jobs`: number of jobs. 병렬로 처리할 작업 수다. None은 보통 한 작업, -1은 사용 가능한 모든 프로세서 활용을 뜻한다. 모든 회귀 실습에서 속도가 빨라지는 것은 아니다.
- `positive`: 양수라는 뜻. True이면 회귀계수를 음수가 되지 않도록 제한한다. False는 음수도 허용한다. 절편이나 예측값 자체를 항상 양수로 만드는 옵션은 아니다.
- `rank_`: 행렬의 독립적인 정보 방향 수. 예를 들어 두 컬럼이 `hours`와 `hours * 2`라면 서로 독립적인 정보가 아니어서 랭크가 줄어들 수 있다.
- `singular_`: 특잇값. 행렬을 분해할 때 각 독립 방향의 크기를 표현하는 수학 값. 이번에는 X가 평균 3을 중심으로 이동된 값 `[-2, -1, 0, 1, 2]`이고, 한 열의 특잇값은 √(4+1+0+1+4) = √10 ≈ 3.16이다. 모델 오차나 정확도와 다르다. 이 계산은 수업 결과의 이해를 위한 보충이다.

처음 보는 모든 설정을 외울 필요는 없다. 현재는 `fit_intercept`, `coef_`, `intercept_`, `feature_names_in_`, `n_features_in_`을 먼저 이해하고, 나머지는 어떤 종류의 설정/속성인지 알아두면 된다.

### 2-5. 최소제곱법 (보충 설명)

현재 모델의 예측 공식은 `y_pred = 10 * hours + 35`다. 모델은 실제 데이터와 예측값 사이의 잔차 제곱합을 가장 작게 만드는 직선을 찾는다.

수업 데이터로 계산하면 X 평균은 3, y 평균은 65이다.

- X의 평균과의 차이: [-2, -1, 0, 1, 2]
- y의 평균과의 차이: [-18, -12, 0, 8, 22]
- 각각의 차이를 곱해 더한 값: 36 + 12 + 0 + 8 + 44 = 100
- X 차이 제곱합: 4 + 1 + 0 + 1 + 4 = 10
- 기울기 w = 100 / 10 = 10
- 절편 b = y 평균 - w × X 평균 = 65 - 10 × 3 = 35

따라서 공부 시간이 1시간 늘면 모델의 예측 점수는 10점 증가한다. 절편은 0시간일 때 모델이 예측하는 점수이며 실제 관측값은 아니다.

#### 왜 '최소'와 '제곱'인가?

- 잔차(Residual): 실제값 - 예측값. 예를 들어 47 - 45 = 2, 53 - 55 = -2. 모델이 맞히지 못한 정도와 방향을 함께 나타낸다.
- 제곱(Square): 수를 자기 자신과 곱하는 연산. Python에서는 `** 2`이다. -2도 제곱하면 4가 되어 양수와 음수의 잔차가 상쇄되지 않는다.
- 최소(Minimum): 여러 가능한 직선 중 잔차 제곱합이 가장 작은 것을 선택한다.

| 후보 직선 | 예측값(1~5시간) | 잔차 제곱합 |
|---|---|---:|
| 10x + 30 | 40, 50, 60, 70, 80 | 141 |
| 10x + 35 | 45, 55, 65, 75, 85 | 16 |
| 10x + 40 | 50, 60, 70, 80, 90 | 141 |

위 표는 이해를 위한 후보 비교다. 실제 모델은 기울기와 절편을 모두 고려하여 전체 후보 중 최적해를 수학적으로 구한다. `LinearRegression()`은 오늘의 데이터에서는 경사하강법을 1000번 실행해서 답을 찾는 방식이 아니라 최소제곱 문제를 수치 선형대수 계산으로 푼다. 다음 SGD 실습은 같은 형태의 예측 공식에 다른 최적화 방법을 적용해 보는 과정이다.

### 2-6. 새로운 데이터 예측

```python

```

| 공부 시간 | 예측 공식 | 예측 점수 |
|---:|---|---:|
| 6 | 10 × 6 + 35 | 95 |
| 7 | 10 × 7 + 35 | 105 |
| 8 | 10 × 8 + 35 | 115 |

수업 출력은 95점만 표시했다. 105점과 115점은 나머지 입력에 대한 공식 계산 결과다. 시험 점수가 100점 만점이라면 선형회귀는 범위 제한을 자동으로 적용하지 않는다는 점에 주의한다. 특히 6~8시간은 학습 범위 1~5시간 바깥에 대한 외삽이다.

#### `predicted_score = model.predict(new_data)` 코드 해석

| 요소 | 종류 | 의미 |
|---|---|---|
| `new_data` | DataFrame 변수 | 정답을 아직 모르는 학생들의 입력값을 담은 표 |
| `pd.DataFrame({"hours": [6, 7, 8]})` | 생성자 | hours 컬럼에 6, 7, 8을 넣은 3행 1열 표를 생성 |

| `predicted_score` | 변수 | 반환된 1차원 NumPy 배열을 저장 |
| `[0]` | 인덱싱 | 입력의 첫 번째 행인 6시간의 결과 선택 |

한글 해석: **이미 학습된 model에게 new_data의 모든 행을 예측하도록 요청하고, 반환된 성적 배열을 predicted_score에 저장한다.**

```python
# 원본 수업은 첫 번째 값만 출력했다. 아래는 반환 형태를 확인하기 위한 보충 코드다.
print(predicted_score)     # [ 95. 105. 115.]
print(predicted_score[0])  # 95.0
print(predicted_score[1])  # 105.0
```

## 3. 모델 평가 (Model Evaluation)

| 시간 | 실제값 y | 예측값 y_pred | 잔차 y - y_pred | 절댓값 | 제곱 |
|---:|---:|---:|---:|---:|---:|
| 1 | 47 | 45 | 2 | 2 | 4 |
| 2 | 53 | 55 | -2 | 2 | 4 |
| 3 | 65 | 65 | 0 | 0 | 0 |
| 4 | 73 | 75 | -2 | 2 | 4 |
| 5 | 87 | 85 | 2 | 2 | 4 |
| 합계 | | | 0 | 8 | 16 |

오차를 그대로 평균 내면 양수와 음수가 상쇄되어 실제로 틀린 예측도 오차 0으로 보일 수 있다.

### 3-0. 평가 지표를 이해하기 위한 수학 용어

| 단어 | 뜻 | 예시 |
|---|---|---|
| Error | 오차 | 실제값과 예측값 사이의 차이 |
| Residual | 잔차 | 관측값에서 모델 예측값을 뺀 차이, 여기서는 `y - y_pred` |
| Mean | 평균 | 값을 모두 더하고 개수로 나눈 것 |
| Absolute | 절대값 | 부호를 없앤 거리의 크기. `abs(-2)`는 2 |
| Squared | 제곱 | 수를 두 번 곱함. `(-2) ** 2`는 4 |
| Metric | 평가 지표 | 모델의 성능을 비교할 때 사용하는 숫자 |
| Loss | 손실 | 모델이 학습할 때 줄이려는 오차 기반의 목적값 |
| Deviation | 편차 | 각 실제값과 실제값 평균 사이의 차이 |
| Sum of Squares | 제곱합 | 각 차이를 제곱한 뒤 모두 더한 값 |

수학 기호 `Σ`(시그마)는 합계라는 뜻이며 Python의 `sum()`과 연결하여 생각할 수 있다. 아래첨자 i는 각 행을 가리키고, n은 전체 행 수이다. `ȳ`(y-bar)는 실제값 y의 평균을 의미한다. `ŷ`는 예측값이므로 서로 다르다.

예측 오차를 비교할 때 절댓값을 사용하면 크기 그대로, 제곱하면 큰 오차를 더욱 강조한다. `Loss`와 `Metric`은 같은 식을 사용할 수도 있으나 목적이 다르다. SGDRegressor는 제곱 오차 기반 손실의 기울기를 이용해 학습하고, `mean_squared_error()`는 학습 이후 현재 오차를 계산해서 기록한다. 평가 함수를 호출하는 것만으로 가중치가 수정되지는 않는다.

### 3-1. MAE (Mean Absolute Error, 평균 절대 오차)

`MAE = 오차 절댓값의 합 / 데이터 수`

`(2 + 2 + 0 + 2 + 2) / 5 = 1.6`

실제 점수와 예측 점수 사이의 차이 크기가 평균 1.6점이라는 의미다. 원래 데이터와 단위가 동일하여 직관적이다. 작을수록 좋다.

### 3-2. MSE (Mean Squared Error, 평균 제곱 오차)

`MSE = 오차 제곱의 합 / 데이터 수`

`(4 + 4 + 0 + 4 + 4) / 5 = 3.2`

오차를 제곱하면 큰 오차에 더 큰 벌점을 줄 수 있다. 예를 들어 오차 2는 4, 오차 10은 100이 된다. 단위는 점수의 제곱이므로 평균 3.2점 틀렸다는 뜻은 아니다. 작을수록 좋다.

### 3-3. R² (R-squared, 결정계수)

`R² = 1 - (잔차 제곱합 / 실제값의 평균으로부터의 편차 제곱합)`

실제 점수 평균은 `(47 + 53 + 65 + 73 + 87) / 5 = 65`다.

- 평균 65를 모든 학생에게 예측할 경우 제곱 오차 합: 324 + 144 + 0 + 64 + 484 = 1016
- 회귀 모델의 제곱 오차 합: 16
- R² = 1 - 16 / 1016 = 약 0.98425 (출력 0.98)

평균을 예측하는 기준보다 제곱 오차를 약 98.4% 줄인 모델이라는 뜻이다. 정답을 98% 맞혔다는 분류 정확도 개념과 다르다.

| R² | 해석 |
|---|---|
| 1 | 완벽한 예측 |
| 0 | 실제값 평균을 예측하는 기준과 동일한 제곱 오차 |
| 음수 | 평균을 예측하는 기준보다 제곱 오차가 큼 |

수업 주석의 0~1 범위는 일반적인 설명이며 R²는 음수가 될 수 있다.

### 3-4. 평가 코드

```python
from sklearn.metrics import mean_absolute_error
from sklearn.metrics import mean_squared_error
from sklearn.metrics import r2_score

mae = mean_absolute_error(y, y_pred)
mse = mean_squared_error(y, y_pred)
r2 = r2_score(y, y_pred)

print(f"MAE: {mae:.2f}")
print(f"MSE: {mse:.2f}")
print(f"R²: {r2:.2f}")
```

```text
MAE: 1.60
MSE: 3.20
R²: 0.98
```

모두 실제값 `y`와 예측값 `y_pred`를 전달하는 평가 함수다. 이번 실습은 학습 데이터 자체에 대한 평가로, 새로운 데이터에 대한 일반화 성능을 검증한 것은 아니다.

#### 평가 함수의 인수, 반환값, 코드 전체 해석

| 코드 요소 | 의미 |
|---|---|
| `sklearn.metrics` | 모델 평가에 쓰이는 함수가 모여 있는 모듈 |
| `mean_absolute_error` | mean(평균) + absolute(절대) + error(오차) |
| `mean_squared_error` | mean(평균) + squared(제곱) + error(오차) |
| `r2_score` | R-squared(결정계수)를 계산하는 함수 |
| `y` | 첫 번째 인수. 실제 정답 배열/Series |
| `y_pred` | 두 번째 인수. 모델이 예측한 결과 배열 |
| `mae`, `mse`, `r2` | 각각 반환된 실수형 수치를 저장하는 변수 |

`mae = mean_absolute_error(y, y_pred)`를 한글로 읽으면 **실제 점수와 예측 점수의 절대 오차를 평균 내어 mae라는 변수에 저장해라**는 뜻이다. MSE와 R²도 동일한 두 인수를 전달하지만 내부 계산식이 다르다. 특히 R²는 실제값으로부터 기준 평균을 계산하므로 인수 순서를 반대로 쓰지 않는다.

#### 라이브러리 없이 계산 구조 확인하기 (보충 예제)

```python
actual = [47, 53, 65, 73, 87]
pred = [45, 55, 65, 75, 85]
absolute_errors = []
squared_errors = []
for i in range(len(actual)):
    error = actual[i] - pred[i]
    absolute_errors.append(abs(error))
    squared_errors.append(error ** 2)
print(sum(absolute_errors) / len(actual))  # 1.6
print(sum(squared_errors) / len(actual))   # 3.2
```

`len(actual)`은 데이터 개수 5를 반환한다. `range(5)`는 0부터 4까지 순차적으로 반복하도록 한다. 인덱스 i로 동일 학생의 정답과 예측값을 꺼내고, `abs()`와 `** 2`로 각각 절대값과 제곱을 계산한 다음 리스트에 쌓는다. `sum()`으로 합하고 전체 데이터 개수로 나누면 된다. scikit-learn 함수는 이 과정에 해당하는 계산을 대신 수행한다.

R²의 분자와 분모를 이해하는 것이 중요하다. 분자는 현재 모델이 틀린 정도, 분모는 아무 특성도 사용하지 않고 평균 65만 예측했을 때 틀린 정도이다. 둘의 비율은 현재 모델에 남은 제곱 오차의 상대적 크기이며 1에서 빼면 기준 대비 줄어든 비율이다. 완벽한 예측이면 분자 0이 되어 R²=1이다. 평균만 예측하면 두 제곱합이 같아 R²=0이다. 평균보다 더 못 맞히면 분자가 분모보다 커져 R²가 음수가 된다. 이는 성능에 관한 설명이지 곧바로 프로그램 오류나 학습 실패가 발생했다는 뜻은 아니다.

| 지표 | 단위 | 값이 작을수록 좋은가? | 읽는 방법 |
|---|---|---|---|
| MAE | 점 | 예 | 평균적으로 차이의 크기가 1.6점 |
| MSE | 점² | 예 | 큰 오차에 더 민감한 평균 3.2 |
| R² | 단위 없음 | 아니오, 1에 가까울수록 좋음 | 평균 기준보다 제곱 오차 약 98.4% 감소 |

모델 평가 수치가 좋은지 판단하려면 데이터 자체의 범위와 목적을 함께 고려해야 한다. 시험 성적은 보통 0~100 범위라 1.6점은 직관적으로 작아 보이지만, 이번 결과는 학습에 사용한 데이터 5개에서 측정했다. 새로운 학생에 대한 성능은 별도 검증이 필요하다.

## 4. 손실 함수와 경사하강법 (Gradient Descent)

- 손실 함수(Loss Function): 모델 예측이 정답에서 얼마나 벗어났는지를 수치화한다. 제곱 오차가 대표적이다.
- 경사하강법: 손실 함수의 값이 감소하는 방향으로 가중치와 절편을 반복 조정하는 최적화 방법이다.
- 회귀직선의 기울기 `w`와 손실 함수의 기울기(Gradient)는 서로 다른 개념이다. 전자는 X가 변할 때 예측이 얼마나 변하는지, 후자는 파라미터가 변할 때 손실이 얼마나 변하는지를 의미한다.

### 4-0. 경사하강법에 등장하는 새로운 용어 (기초 보충)

| 용어 | 한글 뜻 | 이번 수업에서 이해할 내용 |
|---|---|---|
| Optimization | 최적화 | 모델이 가장 작은 손실을 갖도록 내부 파라미터를 찾는 과정 |
| Objective Function | 목적 함수 | 학습이 최소화하려는 수학 함수. 손실과 규제를 함께 포함할 수도 있음 |
| Gradient | 경사, 그래디언트 | 파라미터를 바꿀 때 손실이 어느 방향으로 얼마나 변하는지 나타냄 |
| Descent | 하강 | 손실 함수의 값이 작아지는 방향으로 이동 |
| Derivative | 미분값 | 한 값이 아주 조금 변할 때 다른 값이 얼마나 빠르게 변하는지 나타내는 수 |
| Partial Derivative | 편미분 | 여러 변수 가운데 하나만 변화시켰을 때의 미분값 |
| Learning Rate | 학습률 | 경사에 곱하여 파라미터를 수정하는 크기를 조절하는 값 |
| Update | 갱신 | 기존 가중치 또는 절편을 새 값으로 바꾸는 한 번의 동작 |
| Iteration | 반복 단계 | 문맥에 따라 한 번의 업데이트 등을 뜻함. epoch와 반드시 같은 뜻이 아님 |
| Epoch | 에포크 | 전체 학습 데이터를 한 번 처리하는 단위 |
| Batch | 배치 | 한 번의 업데이트를 계산하는 데 사용되는 데이터 묶음 |
| Convergence | 수렴 | 학습이 진행되면서 값이 안정적인 지점에 가까워지는 것 |
| Divergence | 발산 | 학습값 또는 손실이 안정되지 않고 크게 벗어나는 현상 |
| Stochastic | 확률적 | 개별 샘플 기반으로 갱신하여 전체 경사를 근사하는 방식 |
| Regularization | 규제 | 가중치가 과도하게 커지는 것을 억제하는 장치 |

산을 내려간다고 생각하면 위치가 모델 파라미터이고 높이가 손실이다. 높은 곳에서 시작하여 가장 가파르게 내려갈 방향으로 조금 이동하고, 새 위치에서 다시 경사를 계산한다. 낮은 곳으로 이동한다는 말은 **가중치 숫자 자체가 항상 감소한다는 뜻이 아니라 손실이 감소하도록 조정한다**는 뜻이다.

회귀직선에서는 x축이 공부 시간, y축이 예측 점수이다. 손실 함수 그래프에서는 가로축이 가중치 등의 파라미터, 세로축이 손실이다. 예측 직선이 우상향한다고 해서 손실을 증가시키는 방향으로 학습한다는 뜻은 아니다.

### 4-1. 경사하강법의 원리 (보충 설명)

`새 파라미터 = 기존 파라미터 - 학습률 × 손실 함수의 기울기`

Gradient가 양수면 파라미터를 감소시키고, 음수면 증가시킨다.

작은 예시: 손실 함수가 `L(w) = (w - 10)^2`라면 `w=0`에서 기울기는 `2 × (0 - 10) = -20`이다. 학습률 0.01을 적용하면 새로운 w는 `0 - 0.01 × (-20) = 0.2`가 된다. 정답인 10에 가까워진다. 이는 원리 설명용 예시이며 실제 SGDRegressor의 첫 업데이트 결과는 아니다.

#### 미분을 아직 배우지 않았을 때 이해하는 방법

`L(w) = (w - 10)^2`라는 설명용 손실 함수는 w=10일 때 0으로 가장 낮다. w=0이면 손실 100, w=5이면 25, w=10이면 0, w=15이면 25이다. 미분값은 `2 * (w - 10)`으로 표현된다. 이 값이 양수면 w를 줄이고, 음수면 w를 늘리는 쪽이 손실을 줄이는 방향이다.

학습률을 0.1로 설정한 별도의 예시:

| 단계 | 기존 w | 손실의 기울기 | 새로운 w = 기존 w - 0.1 × 기울기 | 갱신 후 손실 |
|---:|---:|---:|---:|---:|
| 1 | 0 | -20 | 2 | 64 |
| 2 | 2 | -16 | 3.6 | 40.96 |
| 3 | 3.6 | -12.8 | 4.88 | 26.2144 |

손실의 기울기가 -20이기 때문에 빼기와 음수가 만나 w가 증가한다. `-` 기호가 있는데도 가중치가 커질 수 있는 이유다. 10에 접근할수록 경사 크기도 작아지고 이동량도 작아진다.

#### 실제 선형회귀에서 왜 w와 b를 둘 다 수정하는가? (보충)

예측값은 `w*x+b`이므로 w 또는 b가 바뀌면 예측값이 변하고 손실도 달라진다. 따라서 두 값 각각의 변화가 손실에 미치는 영향을 계산한다. 수학적으로는 각각에 대한 편미분을 구해 `w = w - 학습률 * w에 대한 경사`, `b = b - 학습률 * b에 대한 경사`를 실행한다.

수업의 첫 번째 학생(x=1, y=47) 한 명만 고려하고 w=b=0에서 시작하는 **규제 없는 제곱 오차 기반의 설명용 단순 예시**를 만들어 보자. 손실을 `0.5*(예측-실제)**2`로 정의하면 예측 0, 차이 -47이다. w의 경사는 -47×1=-47, b의 경사는 -47이다. 학습률 0.01을 곱하고 빼면 두 값 모두 0.47이 된다. 다음 예측은 0.47×1+0.47=0.94로 이전의 0보다 47에 가까워졌다. 이 예시는 한 샘플 업데이트 원리를 보여 주는 것이며 수업의 1 epoch 기록(Weight 8.455225, Bias 2.731163)은 다섯 샘플을 모두 처리한 뒤의 값이다.

일반적인 MSE의 미분과 위의 절반 제곱 오차의 미분에는 상수 배수 차이가 있다. SGDRegressor의 squared_error는 내부적으로 절반 제곱 오차 형태를 사용하므로 평가에 기록하는 MSE 수치와 내부 목적 함수가 항상 수치적으로 같지는 않다.

### 4-2. 학습률 (Learning Rate)

| 학습률 | 특징 |
|---|---|
| 너무 작음 | 이동 폭이 작아 최적값 도달이 느릴 수 있다. |
| 적절함 | 손실을 줄이는 방향으로 효율적으로 이동한다. |
| 너무 큼 | 최적값을 지나치거나 진동·발산할 수 있다. |

#### 학습률이 크면 무조건 빠른가?

위 예시 손실 함수에서 w=0으로 시작한다고 가정하면 학습률 0.01일 때 첫 이동은 0.2, 0.1일 때 2, 0.7일 때 14이다. 0.7은 최저점인 10을 지나 반대편으로 이동한다. 이 예시에서 0.7로 반복하면 10 주변을 오가며 가까워지지만, 1.05로 설정하면 오히려 10에서 멀어질 수 있다. 즉 적정 학습률은 손실 함수의 형태와 데이터의 스케일에 따라 달라진다. 모든 데이터에 0.01이 최선이라는 뜻은 아니다.

### 4-3. BGD와 SGD

| 구분 | BGD (Batch Gradient Descent) | SGD (Stochastic Gradient Descent) |
|---|---|---|
| 업데이트 기준 | 전체 데이터의 기울기 | 개별 샘플의 기울기 |
| 특징 | 비교적 안정적인 업데이트 | 자주 업데이트하며 변동이 생길 수 있음 |
| 데이터 5개, 1 epoch | 보통 1회 업데이트 | 5회 업데이트 |

이번 실습에서는 `shuffle=False`를 설정했으므로 5개 샘플을 순서대로 처리한다. 매 epoch마다 무작위로 하나만 골라 학습하는 코드가 아니다.

#### 데이터 다섯 개를 처리하는 과정 비교

```text
BGD (한 epoch)
학생1 + 학생2 + 학생3 + 학생4 + 학생5의 경사 계산
→ 전체 경사를 합쳐 한 번 w, b 갱신

SGD (한 epoch, 수업의 shuffle=False)
학생1 계산 → w, b 갱신
학생2 계산 → 수정된 w, b 다시 갱신
학생3 계산 → 다시 갱신
학생4 계산 → 다시 갱신
학생5 계산 → 다시 갱신
```

다섯 명을 모두 학습했다는 점은 같지만 업데이트 횟수가 다르다. 오늘의 SGD 실습은 epoch 1000번 × 학생 5명 = 5000번의 샘플 처리 및 갱신 단계에 해당한다. `history`에는 개별 학생의 업데이트가 아닌 전체 5명 처리 후 결과를 기록하므로 1000행만 만들어진다.

보충으로 Mini-batch Gradient Descent(미니배치 경사하강법)는 몇 개의 샘플을 묶어서 한 번 업데이트하는 중간 방식이다. 오늘의 코드에서는 직접 사용하지 않았다.

## 5. SGDRegressor 모델 생성 및 학습

수업의 비교 기준인 LinearRegression 결과는 Weight 10, Bias 35, MSE 3.2다.

```python
from sklearn.linear_model import SGDRegressor

sgd = SGDRegressor(
    loss="squared_error",
    learning_rate="constant",
    eta0=0.01,
    max_iter=1000,
    shuffle=False,
    random_state=42
)
```

| 파라미터 | 의미 |
|---|---|
| `loss="squared_error"` | 제곱 오차 기반 손실 사용 |
| `learning_rate="constant"` | 학습률을 일정하게 유지 |
| `eta0=0.01` | 초기 학습률, 이 설정에서는 계속 0.01 |
| `max_iter=1000` | fit 호출 시 최대 epoch 수. partial_fit 반복 횟수는 별도 지정 |
| `shuffle=False` | 샘플 순서를 섞지 않음 |
| `random_state=42` | 난수가 사용되는 과정의 재현성을 위한 시드. 42 자체에 특별한 의미는 없음 |

보충: SGDRegressor는 별도로 지정하지 않으면 L2 규제가 적용되는 모델이고, 일정 학습률과 샘플 순서의 영향도 받는다. 그러므로 단순 최소제곱해와 반드시 완전히 같은 값에 도달하는 것은 아니다.

#### SGDRegressor 생성 코드의 구성 요소

`SGDRegressor`는 Stochastic Gradient Descent + Regressor(회귀 추정기)의 결합 명칭이다. 즉 숫자 예측용 선형 모델을 SGD 방식으로 학습하는 클래스이다. `sgd = SGDRegressor(...)`는 학습 설정을 가진 새 객체를 만드는 것이며, 이 줄만 실행한 상태에서는 아직 X와 y를 전달하지 않았다.

| 인수 | 영어 표현 | 값을 전달한 이유 | 이 실습에 미치는 효과 |
|---|---|---|---|
| `loss="squared_error"` | squared error | 큰 예측 오차에 벌점을 부여하는 손실 | 제곱 오차 기반으로 경사를 구함 |
| `learning_rate="constant"` | constant = 일정한 | 학습 중 학습률을 바꾸지 않기 위해 | 모든 업데이트에서 같은 학습률 사용 |
| `eta0=0.01` | eta = 학습률 기호 η | 갱신 크기를 조절 | 경사에 0.01을 곱함 |
| `max_iter=1000` | maximum iterations | fit의 최대 전체 데이터 반복 횟수 지정 | partial_fit에는 이 제한이 직접 적용되지 않음 |
| `shuffle=False` | shuffle = 섞다 | 학습 순서를 유지하며 변화 비교 | 각 epoch에서 입력 순서를 그대로 사용 |
| `random_state=42` | random state = 난수 상태 | 난수 관련 동작을 재현 가능하게 설정 | 이 실습에서는 shuffle이 꺼져 있어 영향이 제한적 |

**한글 해석:** 제곱 오차를 사용하고 학습률을 0.01로 고정하며, 데이터를 섞지 않는 확률적 경사하강법 회귀 모델을 만들어 sgd 변수에 저장해라.

`loss`, `learning_rate` 등은 생성자가 받는 매개변수 이름이고, `"squared_error"`, `"constant"`, `0.01` 등은 전달한 인수다. 42는 임의로 정한 정수이며 숫자 42 자체가 특별히 성능을 높여 주지는 않는다.

기본 L2 규제는 모델이 큰 가중치를 사용하는 것을 억제하는 항을 학습 목적에 더하는 방법이다. 이 내용은 이번 모델과 LinearRegression의 수치 차이를 이해하기 위한 보충이다. `penalty=None`은 규제를 끄는 별도 설정이지만 수업 코드는 기본 규제를 변경하지 않았다.

### 5-1. fit과 partial_fit

| 메서드 | 역할 |
|---|---|
| `model.fit(X, y)` | 모델의 학습 절차를 수행 |
| `sgd.partial_fit(X, y)` | 현재 모델 상태를 유지하며 전달된 데이터를 한 epoch 추가 학습 |
| `sgd.predict(X)` | 현재 가중치와 절편으로 예측 |

Epoch는 전체 학습 데이터를 한 번 사용하는 단위다. `partial_fit(X, y)`에 데이터 5개를 모두 전달하므로 한 번 호출하면 1 epoch, 이를 1000번 호출하면 1000 epoch가 된다. `max_iter=1000` 때문에 한 번에 1000 epoch가 실행되는 것은 아니다.

#### 학습 메서드와 예측 메서드의 상태 변화

| 호출 | 필요 인수 | 반환값 | 모델 내부 가중치 변경 여부 |
|---|---|---|---|
| `LinearRegression().fit(X, y)` | X, y | 학습된 모델 객체 | 예 |
| `sgd.fit(X, y)` | X, y | 학습된 SGD 모델 자신 | 예, 기본 설정에서는 새 학습 수행 |
| `sgd.partial_fit(X, y)` | X, y | 추가 학습된 SGD 모델 자신 | 예, 기존 학습 상태를 이어감 |
| `sgd.predict(X)` | X만 | 예측값 배열 | 아니오 |
| `mean_squared_error(y, y_pred)` | 실제값, 예측값 | 평균 제곱 오차 수치 | 아니오 |

왜 `sgd.fit(X, y)`를 1000번 호출하지 않았을까? 매 호출마다 일반적인 fit 절차를 수행하므로 원하는 한 epoch 단위의 연속 학습 기록을 정확히 얻기 어렵다. `partial_fit`을 사용하면 호출할 때마다 한 epoch만 수행하고 그 직후 예측과 평가를 할 수 있다. 별도의 변수 `epochs`는 외부 반복문 횟수를 결정하며 `max_iter`와는 독립적이다.

### 5-2. 학습 기록 저장

```python
epochs = 1000
history = []

for epoch in range(epochs):
    sgd.partial_fit(X, y)
    y_pred = sgd.predict(X)
    mse = mean_squared_error(y, y_pred)

    history.append({
        "epoch": epoch + 1,
        "weight": sgd.coef_[0],
        "bias": sgd.intercept_[0],
        "mse": mse
    })

history_df = pd.DataFrame(history)
history_df
```

| 코드 | 사용 이유 |
|---|---|
| `epochs = 1000` | 반복 학습 횟수 지정 |
| `partial_fit(X, y)` | 이전 모델 상태에서 추가 학습 |
| `predict(X)` | 현재 모델의 학습 데이터 예측값 생성 |
| `mean_squared_error(y, y_pred)` | 현재 모델의 MSE 확인 |
| `history.append({...})` | 현재 epoch의 기록 딕셔너리를 리스트에 추가 |
| `epoch + 1` | 기록을 0회가 아닌 1회부터 표시 |
| `sgd.coef_[0]` | 첫 입력 변수의 회귀계수 |
| `sgd.intercept_[0]` | SGD 모델의 절편 배열에서 첫 값 추출 |
| `pd.DataFrame(history)` | 딕셔너리 리스트를 표로 변환 |

`history_df`가 반복문 밖에 있어야 반복이 모두 끝난 뒤 기록 전체를 표로 바꾼다. 수업 최종 결과는 1000행, 4열이다. Jupyter에서 반복문 셀만 재실행하면 기존 sgd가 이어서 학습할 수 있으므로 처음부터 재현하려면 모델 생성 셀도 다시 실행한다.

#### 반복문의 처음 두 바퀴를 직접 따라가기

이 코드에서 모델은 반복문 밖에서 한 번만 생성한다. 만약 반복문 안에서 `sgd = SGDRegressor(...)`를 매번 실행하면 새 모델을 계속 만들게 되어 이전 학습을 이어가는 실습의 목적이 깨진다. `history = []` 역시 밖에 두어야 이전 기록이 남는다.

첫 번째 반복이 끝나면 학습을 한 번 마친 상태이므로 기록의 epoch는 1로 표시한다.

첫 번째 반복에서 실제 저장된 수업 출력(설명을 위해 반올림):

```python
# epoch = 0, partial_fit 1회 수행 후
history = [
    {"epoch": 1, "weight": 8.455225, "bias": 2.731163,
     "mse": 1369.816039}
]
```

두 번째 반복이 끝나면:

```python
# epoch = 1, 기존 모델에 partial_fit 1회 추가
history = [
    {"epoch": 1, "weight": 8.455225, "bias": 2.731163,
     "mse": 1369.816039},
    {"epoch": 2, "weight": 12.813586, "bias": 4.270770,
     "mse": 515.808449}
]
```

실제로 코드는 history에 직접 값을 할당하지 않고 `append()`를 호출한다. 위 예시는 각 시점의 리스트 상태를 보여 준 것이다.


한글 해석: **현재 학습 횟수, 기울기, 절편, 오차를 하나의 딕셔너리로 묶어서 history의 마지막에 추가해라.** 리스트에 각 시점의 수치가 별도로 저장되므로 1000번 학습 후에도 1회차에 얻었던 값을 다시 조회할 수 있다.

마지막 줄의 `history_df = pd.DataFrame(history)`는 1000개의 딕셔너리를 각 행으로 만드는 과정이다. 4개의 키가 각각 열 이름이므로 `(1000, 4)` 형태가 된다. 원본 파일의 출력은 앞뒤 일부 행과 `[1000 rows x 4 columns]`를 표시한다.

**변수 흐름에 주의:** `y_pred`는 앞의 LinearRegression 예측값을 담았지만 SGD 반복문 안에서는 현재 sgd의 예측값으로 덮어쓴다. 이전 모델의 평가를 나중에 다시 하려면 `model.predict(X)`를 새로 호출하거나 `linear_pred`, `sgd_pred`처럼 서로 다른 변수명을 사용하는 것이 좋다(보충 개선).

### 5-3. 원하는 epoch만 조회

```python
history_df[history_df["epoch"].isin([1, 5, 10, 50, 100, 300, 500, 1000])]
```

안쪽 `history_df["epoch"]`는 Series를 반환한다. `isin([...])`은 각 값이 리스트에 포함되는지 True/False로 반환한다. 바깥쪽 `history_df[...]`는 True에 해당하는 행만 남긴다.

초기에는 기울기가 17 이상으로 올라가기도 하지만 이후 다시 10 부근으로 내려온다. 각 파라미터가 항상 정답으로 단조롭게 접근할 필요는 없다. 중요한 것은 손실이 줄어들도록 전체 파라미터가 조정되는 것이다.

#### `isin()`을 한 줄씩 분해해 보기

```python
selected_epochs = [1, 5, 10, 50, 100, 300, 500, 1000]
epoch_series = history_df["epoch"]
mask = epoch_series.isin(selected_epochs)
selected_history = history_df[mask]
selected_history
```

이것은 수업의 한 줄짜리 코드를 이해하기 쉽도록 나눈 동일한 필터링 예제다.

| 코드 요소 | 의미 | 결과 |
|---|---|---|
| `history_df["epoch"]` | epoch 컬럼만 추출 | 길이 1000의 Series |
| `.isin(...)` | is in = 안에 포함되는가 | 원래 인덱스를 가진 Boolean Series |
| `[1,5,...]` | 찾고 싶은 epoch 번호 목록 | 리스트 |
| `mask` | True/False 여부를 저장하는 변수명 | True는 선택, False는 제외 |
| `history_df[mask]` | Boolean indexing | True인 8개 행 전체를 담은 DataFrame |

예를 들어 epoch가 1, 2, 3, 4, 5라면 `isin([1,5])` 결과는 `[True, False, False, False, True]`에 해당한다. 바깥의 `history_df[...]`가 이 조건을 행 선택에 이용한다. `isin()` 자체가 행을 삭제하거나 DataFrame을 직접 반환하는 것이 아니다.

또한 필터링 후 인덱스는 원래 행 번호(0, 4, 9, …) 그대로 유지된다. epoch는 1부터 기록했기 때문에 원래 인덱스보다 1만큼 크다. 그래프를 그릴 때는 인덱스 대신 실제 `epoch` 열을 쓰는 것이 올바른 학습 횟수를 표시한다.

```python
fig, axes = plt.subplots(1, 2, figsize=(12, 5))
```

- `fig`: 전체 그림(Figure)
- `axes`: 개별 그래프 영역(Axes)을 담은 배열
- `1, 2`: 한 행에 그래프 두 개 생성
- `axes[0]`: 첫 번째 그래프, Weight
- `axes[1]`: 두 번째 그래프, Bias
- `set_ylabel()`: 특정 Axes에 y축 이름 지정

`fig, axes = ...`는 반환받은 두 객체를 각 변수에 저장하는 언패킹이다.

#### Figure, Axes, Axis를 구분하기

| 용어 | 의미 |
|---|---|
| Figure | 그래프 전체가 담기는 도화지 |
| Axes | 실제 데이터가 그려지는 개별 그래프 영역. 여러 개면 axes 배열에 저장할 수 있음 |
| Axis | 개별 그래프의 x축 또는 y축 |
| Subplot | 한 Figure 안에 배치된 개별 그래프 |

`plt.subplots(1, 2, figsize=(12, 5))`의 위치 인수 1과 2는 `nrows=1`, `ncols=2`를 뜻한다. 반환값은 `(Figure 객체, Axes 객체들의 배열)`이다. `fig, axes = ...`는 이전 함수 수업에서 배운 튜플 언패킹과 같은 방식이다. `axes[0]`으로 첫 번째 영역, `axes[1]`로 두 번째 영역을 선택한다.

```text
fig (전체 그림)
┌───────────────────────────────────────────┐
│ axes[0] (Weight)     axes[1] (Bias)        │
│ 가중치 변화 그래프     절편 변화 그래프      │
└───────────────────────────────────────────┘
```

| 코드 | 반환값 또는 효과 |
|---|---|
| `axes[0].plot(...)` | 첫 번째 Axes에 Line2D 객체를 추가하고 리스트 반환 |
| `axes[0].grid(alpha=0.3)` | 첫 번째 영역에 연한 격자선 표시 |
| `axes[0].set_ylabel("Weight")` | 첫 번째 영역의 y축 이름을 설정하고 Text 객체 반환 |
| `axes[1].plot(...)` | 두 번째 영역에 Bias 선 그래프 추가 |
| `axes[1].set_ylabel("bias")` | 두 번째 영역의 y축 이름 지정 |

왜 `plt.ylabel()`이 아니라 `axes[0].set_ylabel()`을 사용했을까? 그래프가 여러 개이므로 어느 영역의 축 이름을 변경할지 명시하기 위해서다. `plt` 방식은 현재 활성화된 그래프를 대상으로 하고, Axes 객체의 메서드는 특정 영역을 직접 대상으로 한다.

### 5-6. 최종 모델 예측 및 비교

```python
print(f"기울기(w): {sgd.coef_[0]:.2f}")
print(f"절편(b): {sgd.intercept_[0]:.2f}")

new_data = pd.DataFrame({"hours": [6]})
prediction = sgd.predict(new_data)
print(f"예측 성적: {prediction[0]:.2f}점")
```

| 항목 | LinearRegression | SGDRegressor (1000 epoch) |
|---|---:|---:|
| Weight | 10.00 | 10.13 |
| Bias | 35.00 | 34.74 |
| MSE | 3.20 | 3.250159 |
| 6시간 예측 | 95.00 | 95.52 |

두 모델 모두 직선으로 예측하되 학습 방식이 다르다. 예측 시에는 학습된 회귀계수와 절편을 사용하는 원리는 동일하다.

#### 최종 예측값 계산과 반올림의 차이

`prediction = sgd.predict(new_data)`는 최종 학습 상태의 모델을 사용한다. 마지막 epoch 기록에 있는 실제 저장값으로 계산하면 `10.129335 * 6 + 34.741238 = 95.517248`, 소수점 두 자리 표시 시 95.52점이다. 출력된 10.13과 34.74는 이미 반올림한 숫자이므로 이를 이용한 수동 계산과는 마지막 자리에서 차이가 날 수 있다.

**왜 MSE가 3.2에서 정확히 멈추지 않았나?** SGD는 개별 샘플마다 갱신하고 일정한 학습률을 유지하므로 최적점 근처에서도 이동할 수 있다. 또한 수업의 기본 L2 규제도 목적 함수에 영향을 준다. 모든 경우에 반복 횟수를 늘리기만 하면 오차가 무조건 줄어든다고 단정할 수 없다. 오늘 결과는 처음 1369.816039에서 3.250159로 크게 낮아졌다는 사실이 핵심이다.

## 6. 다중선형회귀 (Multiple Linear Regression)

단순선형회귀는 입력 특성 하나를 사용하지만 다중선형회귀는 여러 입력 특성을 함께 사용해 하나의 결과를 예측한다.

`score_pred = w1 * study_hours + w2 * sleep_hours + w3 * practice_count + b`

각 회귀계수는 다른 특성을 고정했을 때 해당 특성이 1단위 증가할 경우 예측값이 얼마나 달라지는지를 의미한다. 이번 파일에서는 모델 학습에 앞서 데이터 준비 및 상관관계 확인까지만 실습했다.

#### Multiple Linear Regression의 이름 이해하기

Multiple은 여러 개, Linear는 입력의 가중합을 이용하는 선형 관계, Regression은 수치 예측을 뜻한다. 정답 컬럼이 여러 개라는 뜻이 아니라 이번 사례에서는 **하나의 성적을 여러 입력 특성으로 예측**한다는 뜻이다.

예시 식 `score_pred = 5*study_hours + 2*sleep_hours + 0.5*practice_count + 20`을 가정해 보자. 공부 3시간, 수면 7시간, 문제풀이 20개라면 `5*3 + 2*7 + 0.5*20 + 20 = 59`점이다. 이 수치는 실제 수업에서 학습한 회귀계수가 아니라 구조를 이해하기 위한 임의의 예시다. 수면 시간과 문제풀이 개수를 그대로 고정한 상태에서 공부 시간만 1시간 늘리면 모델 예측이 5점 증가한다.

세 특성의 단위가 각각 시간, 시간, 문제 개수이므로 회귀계수의 숫자 크기만 비교해 중요도를 확정할 수는 없다. 데이터의 스케일과 특성 간 관계를 함께 보아야 한다.

### 6-1. 데이터 준비

### 6-2. 산점도 비교

`data=df`: 데이터를 가져올 표 지정. `x`, `y`: 각 축에 사용할 컬럼명. `ax=axes[0]`: 생성된 그래프 영역 중 첫 번째 영역에 출력한다.

이전에 배운 `ax=ax`와 같은 구조다. 왼쪽 `ax`는 함수의 매개변수 이름이고 오른쪽 `axes[0]` 또는 `ax`는 실제 전달하는 Axes 객체다.

#### `sns.scatterplot(data=df, x="study_hours", y="score", ax=axes[0])` 상세 분석

| 코드 요소 | 뜻 | 사용 이유 |
|---|---|---|
| `sns` | Seaborn 라이브러리의 별칭 | 짧은 이름으로 기능 호출 |
| `.scatterplot()` | scatter(흩어짐) + plot(그래프) | 두 수치형 변수의 관계를 점으로 표현 |
| `data=df` | data라는 매개변수에 DataFrame df를 전달 | 컬럼 이름을 기준으로 데이터를 찾도록 지정 |
| `x="study_hours"` | x축에 사용할 컬럼 이름 | 공부 시간을 가로축에 표시 |
| `y="score"` | y축에 사용할 컬럼 이름 | 성적을 세로축에 표시 |
| `ax=axes[0]` | ax라는 매개변수에 첫 번째 Axes 객체 전달 | 첫 번째 그래프 영역을 지정 |
| 반환값 | Axes 객체 | 이후 해당 영역을 추가 수정할 수 있음 |

한글 해석: **df에서 공부 시간 컬럼과 성적 컬럼을 가져와 첫 번째 그래프 영역에 산점도를 그려라.** 두 번째와 세 번째 호출은 x 컬럼과 영역만 변경하여 수면 시간, 문제풀이 개수의 관계를 각각 그린다.

`ax=axes[0]`의 등호는 이 문맥에서 변수 대입문이 아니라 키워드 인수를 전달하는 문법이다. 다음 두 코드에서 왼쪽 매개변수 이름은 같지만 전달하는 객체가 다르다.

```python
# 한 개의 영역일 때
fig, ax = plt.subplots(figsize=(6, 4))
sns.scatterplot(data=df, x="study_hours", y="score", ax=ax)

# 여러 영역일 때(수업 코드의 방식)
fig, axes = plt.subplots(1, 3, figsize=(16, 5))
sns.scatterplot(data=df, x="study_hours", y="score", ax=axes[0])
```

첫 번째 예제의 오른쪽 ax는 Axes 객체 변수다. 두 번째 예제의 axes는 영역 배열이라 개별 객체를 인덱싱한다. 함수의 `ax`라는 인수 이름은 변경하지 않아야 한다.

### 6-3. 상관계수 및 Heatmap

```python
corr = df.corr()

sns.heatmap(corr, annot=True, vmin=-1, vmax=1, fmt=".2f")
plt.show()
```

- `df.corr()`: 숫자 컬럼 간의 피어슨 상관계수를 계산하여 DataFrame으로 반환한다.
- `sns.heatmap(corr)`: 계산한 상관계수 행렬을 색으로 표현한다.
- `annot=True`: 각 칸에 수치 표시.
- `vmin=-1`, `vmax=1`: 색상 범위를 상관계수 범위에 맞춰 고정한다. 데이터 값을 바꾸는 설정이 아니다.
- `fmt=".2f"`: 표시되는 수치를 소수점 두 자리까지 표현한다.

수업 데이터로 재계산한 결과(heatmap에 대응):

| 변수 | study_hours | sleep_hours | practice_count | score |
|---|---:|---:|---:|---:|
| study_hours | 1.00 | 0.00 | 0.85 | 0.93 |
| sleep_hours | 0.00 | 1.00 | 0.14 | 0.29 |
| practice_count | 0.85 | 0.14 | 1.00 | 0.93 |
| score | 0.93 | 0.29 | 0.93 | 1.00 |

성적과의 상관계수는 공부 시간 0.9315, 문제풀이 개수 0.9301, 수면 시간 0.2892다. 공부 시간과 문제풀이 개수는 서로도 0.8468로 높은 상관관계를 가진다.

- 양수: 한 변수가 증가할 때 다른 변수도 증가하는 선형 경향.
- 음수: 반대 방향으로 변화하는 선형 경향.
- 0에 가까움: 선형 관계가 약함(비선형 관계는 존재할 수 있음).
- 상관계수는 기울기 자체가 아니며 인과관계를 증명하지 않는다.
- 높은 상관계수만으로 다중회귀의 변수 선택이나 예측 성능을 확정할 수 없다. 특성끼리 높은 상관관계는 회귀계수 해석에 영향을 줄 수 있다.

#### Correlation과 Correlation Coefficient의 차이

Correlation은 상관관계(두 변수의 변화 경향이 서로 관련되는 현상)이고 Correlation Coefficient는 상관계수(그 관계의 방향과 강도를 숫자로 나타낸 값)이다. `df.corr()`의 기본값은 Pearson(피어슨) 상관계수이며 두 수치형 변수의 선형 관계를 측정한다.

기초 수학 보충: 각 변수에서 자신의 평균을 뺀 편차를 만들고, 함께 움직이는 정도를 비교한다. 편차 곱이 양수면 둘이 같은 방향으로 움직이는 경우에 해당하고, 음수면 서로 반대 방향에 해당한다. 단위의 영향을 없애기 위해 각 변수의 변화 크기로 나누어 -1에서 1 사이의 숫자로 표현한다. 표준편차나 공분산은 이 계산을 더 깊게 이해하는 데 필요한 통계 개념으로, 오늘 수업에서는 직접 구현하지 않았다.

| 예시 데이터 | 상관계수 | 해석 |
|---|---:|---|
| x=[1,2,3], y=[10,20,30] | 1 | 완전한 양의 선형 관계 |
| x=[1,2,3], y=[30,20,10] | -1 | 완전한 음의 선형 관계 |
| x=[-1,0,1], y=[1,0,1] | 0 | 직선 형태의 관계는 없지만 U자 관계는 존재 |

이 예시는 상관계수의 0이 모든 종류의 관계가 없다는 뜻이 아님을 보여 준다. 상관계수 0.93과 회귀계수 10은 서로 다른 숫자이다. 상관계수에는 단위가 없고 회귀계수는 입력 1단위당 예측값의 변화량이다.

#### `corr = df.corr()`부터 heatmap까지 코드 분해

| 요소 | 종류 / 뜻 | 반환값 또는 효과 |
|---|---|---|
| `df` | 원본 10행 4열 DataFrame | 공부, 수면, 문제풀이, 성적 |
| `.corr()` | correlation의 줄임말인 DataFrame 메서드 | 4행 4열의 상관계수 행렬(DataFrame) |
| `corr` | 내가 만든 변수 이름 | 계산된 결과를 저장 |
| `sns.heatmap(corr, ...)` | heat(열/색상) + map(지도) | 행렬을 색으로 표현한 Axes 반환 |
| `annot=True` | annotate(주석 달다)의 줄임말 | 칸에 실제 수치 표시 |
| `vmin=-1` | value minimum(색상 범위 최솟값) | -1을 색상 척도 하한으로 지정 |
| `vmax=1` | value maximum(색상 범위 최댓값) | 1을 색상 척도 상한으로 지정 |
| `fmt=".2f"` | format(표시 형식) | 주석을 소수점 두 자리로 표시 |

한글 해석: **df의 모든 컬럼 조합에 대해 상관계수를 계산하고, 그 결과를 -1부터 1까지의 색상 척도로 표현하면서 각 칸에 소수점 두 자리 숫자를 적어라.**

`df.corr()`은 원본 df를 수정하는 것이 아니라 새 표를 반환한다. `corr`는 함수 이름이 아니라 우리가 결과를 담기 위해 만든 변수다. 각 행과 열의 이름이 동일하므로 공부시간-성적과 성적-공부시간은 같은 값이며 대각선은 자기 자신과의 상관계수 1이다. 이 데이터에서 `corr.loc["study_hours", "score"]`를 조회하면 약 0.93154146이 나온다(보충 확인 코드). `vmin/vmax/fmt`는 화면의 표시 범위와 형식을 바꿀 뿐 실제 값 자체를 변경하지 않는다.

#### 왜 다중회귀를 학습하기 전에 상관관계를 확인할까?

성적과 관련이 있는 입력 후보를 살펴보고 입력 변수끼리 서로 비슷한 정보를 담고 있는지도 확인하기 위해서다. 공부 시간과 문제풀이 횟수 사이의 상관계수는 약 0.84684이므로 서로 비슷하게 움직이는 경향이 강하다. 입력끼리 높은 선형 관계가 있으면 각각의 회귀계수를 안정적으로 추정하고 해석하기 어려워지는 **다중공선성(multicollinearity)** 문제가 생길 수 있다. 이것은 보충 개념이며 이번 데이터에서 반드시 특정 변수를 삭제해야 한다는 결론은 아니다.

상관계수가 수면 시간과 성적 사이에서 상대적으로 낮더라도 다른 특성을 통제했을 때 도움이 될 수 있다. 다중회귀는 여러 입력을 동시에 고려하므로 단순 상관계수만으로 입력의 최종 가치를 판정하지 않는다.

### 6-5. 실제 수업 범위와 다음 단계 구분

수업의 마지막 실행 셀은 상관계수 히트맵이다. 아래는 기존 단순선형회귀와의 연결을 보여 주기 위한 복습용 예시이며 오늘 실제 실행 결과는 아니다.

```python
# 보충 예시: 다중선형회귀를 실제 학습하려면
X = df[["study_hours", "sleep_hours", "practice_count"]]
y = df["score"]
model = LinearRegression()
model.fit(X, y)
print(model.coef_)      # 각 입력 특성에 대응하는 가중치 세 개
print(model.intercept_) # 단일 예측 대상의 절편
```

입력 X의 열을 세 개로 늘렸다는 점을 제외하면 오전에 배운 모델 생성과 학습 흐름이 그대로 사용된다. 이 보충 코드의 수치 결과는 실행하지 않았으며 수업에서 얻은 결과로 기록하지 않는다.

## 10. 오늘의 핵심 정리

머신러닝 학습의 기본 흐름은 데이터 준비 → 입력·정답 분리 → 모델 생성 → 학습 → 예측 → 오차 평가다.

선형회귀는 입력값에 가중치를 곱하고 절편을 더하여 결과를 예측한다. 경사하강법은 손실 함수의 기울기를 이용해 가중치와 절편을 반복 수정한다. 여러 입력 변수를 이용하는 다중선형회귀를 준비하면서 산점도와 상관계수 행렬로 데이터 관계를 확인했다.
