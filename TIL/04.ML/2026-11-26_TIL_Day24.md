## 3. 다중 선형회귀 (Multiple Linear Regression)

단순 선형회귀는 하나의 입력 변수를 이용하여 결과를
예측하지만, 다중 선형회귀는 여러 입력 변수를 이용하여
하나의 결과를 예측한다.

| 구분 | 단순 선형회귀 | 다중 선형회귀 |
| --- | --- | --- |
| 입력 변수 | 1개 | 2개 이상 |
| 가중치 | 1개 | 입력 변수 개수만큼 |
| 절편 | 1개 | 1개 |
| 모델 | LinearRegression() | LinearRegression() |

※ 출력 변수가 1개인 경우 기준

### 다중 선형회귀 공식

y_pred = w1 × x1 + w2 × x2 + w3 × x3 + b

- x1, x2, x3 : 입력 변수
- w1, w2, w3 : 각각의 입력 변수에 대한 가중치
- b : 절편
- y_pred : 모델이 계산한 예측값

### 입력 데이터(X)와 정답 데이터(y) 분리

```python
features = [
    "study_hours",
    "sleep_hours",
    "practice_count"
]

X = df[features]
y = df["score"]

print(X.shape)
print(y.shape)
```

실행 결과

```text
(10, 3)
(10,)
```

| 변수 | 의미 |
| --- | --- |
| features | 입력 변수의 컬럼명 리스트 |
| study_hours | 공부 시간 |
| sleep_hours | 수면 시간 |
| practice_count | 연습 횟수 |
| score | 시험 점수 |
| X | 2차원 입력 데이터 |
| y | 1차원 정답 데이터 |

X는 10개의 행과 3개의 열을 가진 DataFrame이며,
y는 10개의 정답값을 가진 Series이다.

### 모델 객체 생성 및 학습

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X, y)
```

- LinearRegression() : 선형회귀 모델 객체 생성
- fit(X, y) : 입력 데이터와 정답 데이터를 이용하여
  예측 오차의 제곱합을 최소화하는 가중치와 절편을 계산한다.

단순 선형회귀와 다중 선형회귀는 동일한 클래스를 사용하며,
입력 변수의 개수에 따라 구분된다.

## 4. 가중치(Weight)와 절편(Bias) ★ 중요

### 학습된 가중치와 절편 확인

```python
model.coef_
model.intercept_
```

| 속성 | 의미 |
| --- | --- |
| coef_ | 학습된 가중치 |
| intercept_ | 학습된 절편 |

- coef_가 1개 : 단순 선형회귀
- coef_가 2개 이상 : 다중 선형회귀
- 출력 변수가 1개라면 절편은 1개이다.

### 가중치란?

다른 입력 변수가 일정할 때 특정 입력 변수가
1단위 증가하면 예측값이 얼마나 변하는지를 나타내는 값이다.

단순 선형회귀에서는 직선의 기울기를 의미한다.

예를 들어 사무실 가격 예측 공식이 다음과 같다면,

가격 = 면적 × 200 + 1000

가중치는 200이다.

면적이 1평 증가할 때마다 예측 가격이
200만 원씩 증가한다는 의미이다.

가로축의 눈금이 1, 10, 100 단위로 표시되는 것과는
관계없이 실제 입력값의 1단위를 기준으로 해석한다.

### 절편이란?

모든 입력 변수가 0일 때의 예측값이다.

예측 공식의 기준값으로 사용되며,
단순 선형회귀에서는 직선과 Y축이 만나는 지점이다.

절편을 변경하면 기울기는 그대로 유지되면서
직선 전체가 위아래로 이동한다.

단, 입력값이 모두 0인 상황이 실제로 존재하지 않는다면
절편을 현실적인 결과로 해석하기는 어렵다.

### 오늘 실습의 학습 결과 (반올림)

| 구분 | 값 | 의미 |
| --- | --- | --- |
| w1 | 5.80 | 공부 시간 1시간당 예측 점수 변화량 |
| w2 | 2.68 | 수면 시간 1시간당 예측 점수 변화량 |
| w3 | 0.63 | 연습 횟수 1회당 예측 점수 변화량 |
| bias | 17.66 | 모든 입력값이 0일 때의 예측 점수 |

예측 공식

score = 5.80 × study_hours
      + 2.68 × sleep_hours
      + 0.63 × practice_count
      + 17.66

가중치는 양수와 음수 모두 가능하다.

- 양수 : 입력값이 증가하면 예측값 증가
- 음수 : 입력값이 증가하면 예측값 감소
- 0 : 해당 입력값의 변화가 예측값에 반영되지 않음

### 머신러닝의 학습이란?

- fit() : 적합한 가중치와 절편을 찾는 과정
- coef_, intercept_ : 학습을 통해 찾은 값
- predict() : 학습된 값으로 예측 결과를 계산하는 과정

## 5. 학습 데이터와 테스트 데이터 분리

모델의 학습과 성능 평가에 동일한 데이터만 사용하면
새로운 데이터에 대한 예측 성능을 확인하기 어렵다.

따라서 데이터를 학습용과 테스트용으로 분리한다.

```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=42
)
```

| 변수 | 의미 |
| --- | --- |
| X_train | 학습용 입력 데이터 |
| y_train | 학습용 정답 데이터 |
| X_test | 테스트용 입력 데이터 |
| y_test | 테스트용 정답 데이터 |

| 매개변수 | 의미 |
| --- | --- |
| test_size=0.3 | 전체 데이터의 30%를 테스트에 사용 |
| random_state=42 | 동일한 난수 기준으로 데이터 분리 |

전체 데이터가 10개이므로 다음과 같이 분리된다.

- Train : 7개
- Test : 3개

Train은 모델 학습 및 학습 과정 확인에 사용하고,
Test는 학습이 완료된 모델의 최종 성능 평가에 사용한다.

## 6. 표준화 (Standardization) ★ 중요

입력 변수마다 사용하는 단위와 값의 범위가 다르면
경사하강법이나 거리 계산에 영향을 줄 수 있다.

표준화는 서로 다른 입력 변수들을
공통된 척도로 변환하는 작업이다.

일반적으로 학습 데이터의 각 변수의 평균이 0,
표준편차가 1이 되도록 변환한다.

단, 모든 값이 동일한 변수는 표준편차가 0이다.

### 표준화 공식

z = (x - 평균) / 표준편차

| 기호 | 의미 |
| --- | --- |
| x | 원본 데이터 |
| μ (뮤) | 평균 |
| σ (시그마) | 표준편차 |
| z | 표준화된 값 (Z-score) |

### 표준편차 (Standard Deviation)

데이터가 평균을 기준으로 얼마나 흩어져 있는지를
나타내는 수치이다.

- 표준편차가 작다 : 데이터가 평균 근처에 모여 있음
- 표준편차가 크다 : 데이터가 넓게 퍼져 있음

### 표준화 예시

공부 시간의 평균이 5시간,
표준편차가 2시간이라고 가정한다.

| 공부 시간 | 계산 | 표준화 결과 |
| --- | --- | --- |
| 1시간 | (1 - 5) / 2 | -2 |
| 3시간 | (3 - 5) / 2 | -1 |
| 5시간 | (5 - 5) / 2 | 0 |
| 7시간 | (7 - 5) / 2 | 1 |
| 9시간 | (9 - 5) / 2 | 2 |

- 표준화 결과가 0 : 평균과 동일
- 표준화 결과가 1 : 평균보다 표준편차 1배만큼 큼
- 표준화 결과가 -1 : 평균보다 표준편차 1배만큼 작음

주의 : 표준화는 데이터를 -1부터 +1 사이로
제한하는 작업이 아니다.

### StandardScaler 사용

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

scaled_df = pd.DataFrame(
    X_train_scaled,
    columns=features
)

scaled_df.round(2)
```

### 새롭게 사용한 함수와 메서드

| 코드 | 의미 |
| --- | --- |
| preprocessing | 데이터 전처리 관련 모듈 |
| StandardScaler() | 표준화 객체 생성 |
| fit() | 평균과 표준편차 계산 및 저장 |
| transform() | 저장된 기준으로 데이터 변환 |
| fit_transform() | 기준 계산과 데이터 변환을 동시에 수행 |

### fit_transform()과 transform()의 차이

```python
X_train_scaled = scaler.fit_transform(X_train)
```

학습 데이터의 평균과 표준편차를 계산하고,
계산된 값을 이용하여 학습 데이터를 표준화한다.

```python
X_test_scaled = scaler.transform(X_test)
```

테스트 데이터의 평균과 표준편차를 새롭게 계산하지 않고,
학습 데이터에서 계산한 평균과 표준편차를 사용한다.

### 데이터 누수 (Data Leakage)

모델 학습 과정에서 사용하면 안 되는 정보가
학습이나 전처리 과정에 반영되는 현상이다.

테스트 데이터에 fit_transform()을 사용하면
테스트 데이터의 정보로 표준화 기준을 새로 계산하게 된다.

따라서 학습 데이터와 테스트 데이터에는
동일한 표준화 기준을 사용해야 한다.

- Train : fit_transform()
- Test : transform()

### 표준화 이후의 가중치 해석

표준화된 입력 데이터로 학습한 모델의 가중치는
원본 데이터가 1단위 증가할 때의 변화량이 아니다.

원본 입력값이 표준편차 1배만큼 증가할 때
예측값이 얼마나 변하는지를 나타낸다.

## 7. SGDRegressor (확률적 경사하강법)

SGD : Stochastic Gradient Descent

개별 학습 데이터를 이용하여 가중치와 절편을 반복적으로
수정하면서 손실함수를 최소화하는 학습 방법이다.

### LinearRegression과 SGDRegressor의 차이

| 구분 | LinearRegression | SGDRegressor |
| --- | --- | --- |
| 학습 방식 | 최소제곱 문제를 수치적으로 풀이 | 반복적으로 매개변수 수정 |
| 학습률 | 별도 설정 없음 | 설정 가능 |
| Epoch별 학습 | 직접 확인하기 어려움 | partial_fit()으로 확인 가능 |
| 예측 목적 | 회귀 | 회귀 |

### SGD 모델 생성

```python
from sklearn.linear_model import SGDRegressor

sgd = SGDRegressor(
    loss="squared_error",
    learning_rate="constant",
    eta0=0.01,
    max_iter=30000,
    random_state=42
)
```

### 매개변수 분석

| 매개변수 | 의미 |
| --- | --- |
| loss | 학습 시 사용하는 손실함수 |
| squared_error | 제곱오차 기반 손실함수 |
| learning_rate | 학습률을 변경하는 방식 |
| constant | 학습률을 일정하게 유지 |
| eta0 | 초기 학습률 |
| max_iter | fit()의 최대 Epoch 횟수 |
| random_state | 난수 발생 기준 |

### 학습률 (Learning Rate)

가중치와 절편을 한 번 수정할 때
얼마나 큰 폭으로 이동할지 결정하는 값이다.

- 학습률이 너무 작으면 : 학습 속도가 느려짐
- 학습률이 적절하면 : 손실함수의 최솟값에 접근
- 학습률이 너무 크면 : 최솟값을 지나치거나 발산할 수 있음

eta0=0.01은 가중치 갱신 과정에서 사용하는
학습률을 0.01로 설정한다는 의미이다.

learning_rate="constant"이므로
학습 중에도 동일한 학습률을 유지한다.

### Epoch (에포크)

전체 학습 데이터를 한 번 학습하는 단위이다.

학습 데이터가 7개라면 해당 데이터 7개를
한 차례 학습하는 것이 1 Epoch이다.

### 수렴과 발산

| 용어 | 의미 |
| --- | --- |
| Convergence (수렴) | 값이 일정한 값에 가까워지는 현상 |
| Divergence (발산) | 값이 커지면서 안정되지 않는 현상 |

## 8. Epoch별 학습 기록 저장

```python
history = []

# 500 Epoch 학습
for epoch in range(500):

    # 1 Epoch 학습
    sgd.partial_fit(X_train_scaled, y_train)

    # 학습 데이터 예측
    pred = sgd.predict(X_train_scaled)

    history.append({
        "epoch": epoch + 1,
        "w1": sgd.coef_[0],
        "w2": sgd.coef_[1],
        "w3": sgd.coef_[2],
        "bias": sgd.intercept_[0],
        "mse": mean_squared_error(y_train, pred)
    })

history_df = pd.DataFrame(history)
history_df.tail()
```

### partial_fit()

기존 학습 상태를 유지하면서 추가 학습을 수행하는
메서드이다.

SGDRegressor의 partial_fit()은 호출할 때마다
1 Epoch의 학습을 수행한다.

따라서 for문으로 500번 반복하면
총 500 Epoch를 학습할 수 있다.

현재 실습에서 학습 횟수를 결정하는 것은
max_iter=30000이 아니라 range(500)이다.

### 학습 기록을 저장하는 이유

최종 학습 결과뿐 아니라 학습을 반복하는 과정에서
가중치, 절편, 오차가 어떻게 변하는지 확인하기 위함이다.

| 컬럼 | 의미 |
| --- | --- |
| epoch | 학습 횟수 |
| w1 | 공부 시간의 가중치 |
| w2 | 수면 시간의 가중치 |
| w3 | 연습 횟수의 가중치 |
| bias | 절편 |
| mse | 평균제곱오차 |

### MSE (Mean Squared Error)

평균제곱오차를 의미한다.

실제값과 예측값의 차이를 각각 제곱한 후
평균을 계산한 값이다.

예시

| 실제값 | 예측값 | 오차 | 제곱오차 |
| --- | --- | --- | --- |
| 80 | 78 | 2 | 4 |
| 90 | 93 | -3 | 9 |
| 70 | 69 | 1 | 1 |

MSE = (4 + 9 + 1) / 3 = 약 4.67

MSE가 작을수록 해당 데이터에 대한
모델의 예측 오차가 작다는 의미이다.

### 학습 반복문의 전체 흐름

1. partial_fit()으로 가중치와 절편 갱신
2. predict()로 학습 데이터 예측
3. mean_squared_error()로 오차 계산
4. history에 학습 결과 저장
5. 위 과정을 500회 반복
6. DataFrame으로 학습 기록 변환

## 11. KNN (K-Nearest Neighbors) ★ 중요

KNN은 K-최근접 이웃 알고리즘이다.

새로운 데이터가 주어졌을 때 기존 데이터 중
가장 가까운 K개의 데이터를 찾아 결과를 예측한다.

### 용어 분석

| 용어 | 의미 |
| --- | --- |
| K | 참고할 이웃 데이터의 개수 |
| Nearest | 가장 가까운 |
| Neighbors | 이웃 데이터 |
| Distance | 데이터 사이의 거리 |
| Classification | 분류 |
| Regression | 회귀 |

### KNN의 작동 원리

1. 새로운 데이터 입력
2. 기존 데이터와 새로운 데이터의 거리 계산
3. 가장 가까운 K개의 데이터 선택
4. 이웃 데이터의 정답을 참고하여 결과 예측

예를 들어 K=5인 경우 가까운 데이터 5개를 선택한다.

- A 그룹 : 3개
- B 그룹 : 2개

분류에서는 일반적으로 다수결에 따라
새로운 데이터를 A 그룹으로 예측한다.

회귀에서는 가까운 데이터들의 정답값을 평균 내어
결과를 예측할 수 있다.

### 선형회귀와 KNN의 차이

| 구분 | 선형회귀 | KNN |
| --- | --- | --- |
| 예측 방식 | 학습된 예측 공식 사용 | 가까운 데이터 참고 |
| 가중치와 절편 | 사용 | 회귀계수로 사용하지 않음 |
| 경사하강법 | 학습 방식에 따라 사용 | 사용하지 않음 |
| 거리 계산 | 핵심 방식이 아님 | 핵심 방식 |
| 활용 | 회귀 | 분류 및 회귀 |

KNN은 데이터 사이의 거리를 비교하기 때문에
입력 변수의 단위와 범위가 다를 경우 표준화가 중요하다.

오늘 실습에서는 KNN 모델을 직접 학습시키기 전,
이미지 데이터가 어떻게 구성되어 있는지 확인했다.

## 14. Pixel과 Grayscale ★ 중요

### Pixel (픽셀)

이미지를 구성하는 가장 작은 단위이다.

컴퓨터는 사진을 사람의 얼굴이나 사물 자체로

흑백 이미지에서는 각각의 숫자가
픽셀의 밝기를 나타낸다.

### Grayscale (회색조)

색상이 아닌 밝기의 차이로 이미지를 표현하는 방식이다.

오늘 사용한 이미지 데이터의 픽셀값 범위는 0~1이다.

| 픽셀값 | 밝기 |
| --- | --- |
| 0.0 | 검은색 |
| 0.25 | 어두운 회색 |
| 0.5 | 중간 회색 |
| 0.75 | 밝은 회색 |
| 1.0 | 흰색 |

64 × 64 이미지 한 장은
총 4,096개의 픽셀값으로 구성되어 있다.

즉, 사진 한 장은 4,096개의 숫자로 표현할 수 있다.

### zip() 함수 ★ 중요

여러 리스트 또는 배열에서 동일한 순서에 있는 값을
하나씩 묶어 반복할 수 있도록 하는 함수이다.

```python
names = ["철수", "영희", "민수"]
scores = [80, 90, 100]

for name, score in zip(names, scores):
    print(name, score)
```

실행 결과

```text
철수 80
영희 90
민수 100
```

zip()은 묶인 값을 순서대로 제공하는
이터레이터(iterator)를 반환한다.

기본적으로 가장 짧은 반복 가능한 데이터의 길이를
기준으로 반복이 종료된다.

### 오늘 실습에서 zip()을 사용한 이유

```python
for ax, img in zip(axes, pics):
```

axes에는 그래프 공간 10개가 존재하고,
pics에는 해당 사람의 사진 10장이 존재한다.

zip()으로 그래프 공간과 사진을 하나씩 연결한다.

| 반복 | ax | img |
| --- | --- | --- |
| 1 | axes[0] | pics[0] |
| 2 | axes[1] | pics[1] |
| 3 | axes[2] | pics[2] |
| ... | ... | ... |
| 10 | axes[9] | pics[9] |

따라서 반복문을 이용하여 10개의 공간에
각각 다른 사진을 표시할 수 있다.

## 20. KNN 이미지 분류의 원리 (보충 학습)

※ 아래 내용은 오늘 실습 이후의 KNN 학습을
이해하기 위한 보충 내용이다.

### Flatten (평탄화)

다차원 배열을 1차원 배열로 펼치는 작업이다.

예를 들어 다음과 같은 2차원 배열이 있다.

```python
arr = np.array([
    [1, 2],
    [3, 4]
])

arr.flatten()
```

실행 결과

```text
array([1, 2, 3, 4])
```

(2, 2) 형태의 배열이 (4,) 형태로 변경된다.

이미지 한 장을 펼치면 다음과 같다.

(64, 64) → (4096,)

전체 이미지 400장을 각각 펼치면

(400, 64, 64) → (400, 4096)

Olivetti Faces 데이터셋에는 펼쳐진 형태의 데이터인
faces.data도 존재한다.

### 유클리드 거리 (Euclidean Distance)

두 데이터 사이의 직선거리를 계산하는 방법이다.

A = (1, 1)
B = (4, 5)

두 데이터의 X좌표 차이는 3이고,
Y좌표 차이는 4이다.

거리 = √(3² + 4²) = 5

거리값이 작을수록 두 데이터가
해당 거리 기준에서 비슷하다고 판단할 수 있다.

KNN에서는 여러 입력 변수의 차이를 이용하여
데이터 사이의 거리를 계산할 수 있다.

이미지 분류에서는 각각의 픽셀값을 비교하여
비슷한 이미지들을 찾는 데 활용할 수 있다.

단, 단순한 픽셀 비교는 조명, 얼굴 방향,
사진 위치 등의 변화에 영향을 받을 수 있다.

## 21. 오늘 발생한 오류 및 해결 방법

### 오류 1. LinearRegression 객체 생성 오류

잘못된 코드

```python
model = LinearRegression
model.fit(X, y)
```

오류 메시지

```text
AttributeError: 'DataFrame' object has no attribute
'_validate_params'
```

원인 : 클래스를 변수에 할당했지만
실제 모델 객체를 생성하지 않았다.

수정 코드

```python
model = LinearRegression()
model.fit(X, y)
```

### 오류 2. StandardScaler 객체 생성 오류

잘못된 코드

```python
scaler = StandardScaler

X_train_scaled = scaler.fit_transform(X_train)
```

오류 메시지

```text
TypeError: TransformerMixin.fit_transform()
missing 1 required positional argument: 'X'
```

원인 : StandardScaler 뒤의 소괄호가 빠져
표준화 객체가 생성되지 않았다.

수정 코드

```python
scaler = StandardScaler()

X_train_scaled = scaler.fit_transform(X_train)
```

### 클래스와 객체의 차이

| 코드 | 의미 |
| --- | --- |
| LinearRegression | 클래스 자체 |
| LinearRegression() | 클래스의 객체 생성 |
| StandardScaler | 클래스 자체 |
| StandardScaler() | 표준화 객체 생성 |

클래스는 설계도이고,
인스턴스는 설계도를 이용하여 생성한 실제 객체이다.

### 오류 3. Train과 Test 데이터 불일치

잘못된 코드

```python
pred = sgd.predict(X_test_scaled)

mean_squared_error(y_train, pred)
```

오류 메시지

```text
ValueError: Found input variables with inconsistent
numbers of samples: [7, 3]
```

원인 : 학습 데이터의 정답 7개와
테스트 데이터의 예측값 3개를 비교하였다.

수정 코드

```python
pred = sgd.predict(X_train_scaled)

mean_squared_error(y_train, pred)
```

오늘 실습의 목적은 학습 과정의 오차를 기록하는 것이므로
Train 데이터를 예측하고 Train 정답과 비교해야 한다.

| 예측 데이터 | 비교할 정답 |
| --- | --- |
| X_train_scaled | y_train |
| X_test_scaled | y_test |

한다는 것을 배웠다.

SGDRegressor의 partial_fit()을 이용하여
Epoch별 가중치와 절편, MSE를 기록하고
