## 2. SQL 데이터 조작 복습

### 2-1. INSERT와 RETURNING

`INSERT`는 테이블에 새로운 행을 추가하는 명령어다.

```sql
INSERT INTO sports (sport_name)
VALUES ('필라테스')
RETURNING *;
```

- `INSERT INTO` : 데이터를 추가할 테이블 지정
- `VALUES` : 추가할 데이터 입력
- `RETURNING *` : 추가된 행을 바로 반환

`RETURNING`은 데이터 변경 결과를 확인할 때 활용할 수 있다.

### 2-2. UPDATE

기존 데이터를 수정하는 명령어다.

```sql
UPDATE courses
SET fee = fee * 1.05
WHERE sport_id = 1;
```

기존 수강료에 1.05를 곱해 5% 인상한다.

`WHERE`가 없으면 모든 행이 수정될 수 있으므로 주의해야 한다.

### 2-3. DELETE

조건에 해당하는 행을 삭제한다.

```sql
DELETE FROM lockers
WHERE member_id = 38
RETURNING *;
```

삭제된 데이터를 `RETURNING`으로 확인할 수 있다.

### 2-4. TRUNCATE와 DROP TABLE

| 명령어 | 의미 |
|---|---|
| `DELETE` | 조건에 맞는 행 삭제 |
| `TRUNCATE` | 테이블의 데이터를 비움 |
| `DROP TABLE` | 테이블 자체 삭제 |

### 2-5. CAST와 날짜 형변환

```sql
CAST('2026-11-19' AS DATE)
```

PostgreSQL에서는 다음 문법도 사용할 수 있다.

```sql
'2026-11-19'::DATE
```

두 코드 모두 문자열을 날짜 자료형으로 변환한다.

### 2-6. 서브쿼리와 NOT EXISTS

SQL 안에 다른 SQL 조회문을 넣는 것을 서브쿼리라고 한다.

오늘은 `IN`, `GROUP BY`, `HAVING`을 조합한 조건부 `UPDATE`와 `NOT EXISTS`를 활용한 `DELETE`도 다뤘다.

`NOT EXISTS`는 내부 조회 결과가 없을 때 참이 되는 조건이다.

## 3. Python과 PostgreSQL 연결

### 3-1. psycopg 라이브러리

Python에서 PostgreSQL에 접속하고 SQL을 실행할 때 사용한다.

```python
import psycopg
from psycopg.rows import dict_row
```

- `psycopg` : PostgreSQL 연결 및 SQL 실행
- `dict_row` : 조회 결과를 딕셔너리 형태로 가져오기

### 3-2. DSN

DSN은 Data Source Name의 약자로, 데이터베이스 연결 정보를 나타낸다.

```python
DSN = "host=localhost port=5432 dbname=sportscenter user=postgres password=postgres"
```

학습용 로컬 DB 접속 정보다. 실제 서비스에서는 비밀번호를 코드에 직접 작성하지 않는 것이 좋다.

### 3-3. 데이터베이스 연결

```python
with psycopg.connect(DSN, row_factory=dict_row) as conn:
    list_courses(conn)
```

`with`는 연결을 관리하는 문법이다.

`row_factory=dict_row`를 지정하면 다음과 같이 조회 결과에 접근할 수 있다.

```python

```

`conn`은 데이터베이스 연결 객체이며, SQL을 실행할 함수에 전달한다.

## 5. 전체 강좌 목록 조회

```python
LIST_SQL = """
SELECT DISTINCT
    c.course_id,
    s.sport_name,
    c.course_name,
    c.class_days,
    c.fee
FROM courses c
JOIN sports s ON c.sport_id = s.sport_id
LEFT JOIN enrollments e ON c.course_id = e.course_id
                       AND e.enroll_month = %s
ORDER BY c.course_id
"""
```

### 사용한 SQL 개념

| 문법 | 설명 |
|---|---|
| `SELECT` | 조회할 컬럼 지정 |
| `DISTINCT` | 중복된 결과 행 제거 |
| `JOIN` | 두 테이블의 데이터를 연결 |
| `LEFT JOIN` | 왼쪽 테이블의 행을 유지하면서 연결 |
| `ON` | 테이블 연결 조건 |
| `ORDER BY` | 결과 정렬 |
| `%s` | Python에서 값을 전달할 자리 |

### 출력 함수

```python
def list_courses(conn):
    for c in conn.execute(LIST_SQL, (MONTH,)):
        print(
            f"{c['course_id']:>3} | "
            f"{c['sport_name']} | "
            f"{c['course_name']} | "
            f"{c['class_days']} | "
            f"{c['fee']:,}원"
        )
```

여기서 `(MONTH,)`는 값 하나를 가진 튜플이다.

`MONTH = "2026-11"`로 정의되어 있으므로 해당 월을 SQL에 전달한다.

**주의:** 현재 SQL은 전체 강좌를 조회하며, 실제 신청 가능 인원이나 정원을 검사하는 로직은 아니다.

## 6. 강좌명 검색 기능

### 6-1. LIKE와 와일드카드

`LIKE`는 문자열 패턴을 검색할 때 사용한다.

```sql
SELECT course_id, course_name, fee
FROM courses
WHERE course_name LIKE '%수영%';
```

와일드카드는 검색할 문자열의 일부가 일치해도 찾을 수 있도록 해주는 기호다.

| 검색 조건 | 의미 |
|---|---|
| `'수영%'` | 수영으로 시작 |
| `'%수영'` | 수영으로 끝남 |
| `'%수영%'` | 수영이 포함됨 |
| `'수영_'` | 수영 다음에 정확히 한 글자 |

`%`는 0개 이상의 임의 문자를 의미하고 `_`는 정확히 한 문자를 의미한다.

### 6-2. Python 검색 함수

```python
def search_courses(conn, name):
    for course in conn.execute(
        "SELECT course_id, course_name, fee "
        "FROM courses "
        "WHERE course_name LIKE %s",
        (f"%{name}%",)
    ):
        print(
            f"강좌명 : {course['course_name']:<15} | "
            f"강좌 번호 : {course['course_id']:>2} | "
            f"가격 : {course['fee']:>8,}원"
        )
```

### 가장 중요했던 문법

```python
(f"%{name}%",)
```

사용자가 `수영`을 입력하면:

```text
name = "수영"
f"%{name}%" → "%수영%"
```

이 검색 패턴이 SQL의 `%s` 자리에 전달된다.

**두 종류의 `%`를 구분해야 한다.**

- `%s` : psycopg에서 전달받을 값의 자리
- `%` : SQL LIKE에서 사용하는 와일드카드

### 오늘 발생했던 오류

처음에는 SQL을 Python 함수 안에 그대로 작성했다.

```python
def search_courses(conn, name):
    SELECT course_id, course_name, fee
    FROM courses
```

Python에서는 SQL을 문자열로 만들고 `conn.execute()`에 전달해야 한다.

또한 SQL 문자열을 나눠 작성할 때 공백이 필요하다.

잘못된 예:

```python
"SELECT course_id FROM courses"
"WHERE course_name LIKE %s"
```

두 문자열이 붙으면서 `coursesWHERE`가 된다.

올바른 예:

```python
"SELECT course_id FROM courses "
"WHERE course_name LIKE %s"
```

## 7. 회원 이름으로 ID 조회

```python
def find_member_id(conn, name):
    for member in conn.execute(
        "SELECT member_id FROM members WHERE name = %s",
        (name,)
    ):
        return member["member_id"]

    return None
```

### 처리 과정

1. 회원 이름을 함수에 전달
2. SQL로 회원 ID 조회
3. 조회된 회원이 있으면 ID 반환
4. 조회 결과가 없으면 `None` 반환

`main()`에서는 다음과 같이 사용했다.

```python
name = input("회원 이름을 입력하세요: ")
member_id = find_member_id(conn, name)

if member_id is None:
    print("등록되지 않은 회원입니다.")
    return
```

### 오늘 이해한 개념

`return`은 함수의 결과를 반환하면서 함수를 종료한다.

`None`은 값이 없음을 나타내는 Python의 특별한 값이다.

다만 현재 함수는 같은 이름의 회원이 여러 명이면 첫 번째 회원 ID만 가져온다는 한계가 있다.

## 8. 수강료 조회 기능

```python
def find_fee(conn, course_id):
    for course in conn.execute(
        "SELECT fee FROM courses WHERE course_id = %s",
        (course_id,)
    ):
        return course["fee"]

    return None
```

선택한 강좌 번호로 실제 수강료를 조회한다.

```python
selected_course = int(input("신청할 강좌의 번호를 입력하세요: "))
fee = find_fee(conn, selected_course)

if fee is None:
    print("존재하지 않는 강좌입니다.")
    return

print(f"수강료는 {fee:,}원 입니다.")
```

### 중요한 개념: None과 0의 차이

- `None` : 수강료 조회 결과가 없음을 나타냄
- `0` : 수강료가 실제로 0원임

현재 `find_fee()`는 강좌를 찾지 못하면 `None`을 반환하도록 작성했다.

### 오늘 고민했던 부분

`main()`에서 수강료를 조회하고 `enroll()`에서도 조회하고 있었다.

두 방식 모두 가능하다.

| 방식 | 특징 |
|---|---|
| `enroll()`에서 다시 조회 | 함수가 직접 수강료를 가져옴 |
| `main()`에서 조회 후 전달 | 중복 조회를 줄일 수 있음 |

오늘은 기존 코드의 구조를 유지해 `enroll()`에서 직접 조회하는 방식을 사용했다.

## 9. 중복 수강신청 확인

### 9-1. 중복을 판단하는 조건

동일한 수강신청을 확인하려면 다음 세 가지가 모두 같아야 한다.

1. `member_id` : 회원 번호
2. `course_id` : 강좌 번호
3. `enroll_month` : 수강 월

```sql
SELECT member_id
FROM enrollments
WHERE member_id = %s
  AND course_id = %s
  AND enroll_month = %s;
```

`AND`는 여러 조건을 모두 만족해야 한다는 의미다.

수강 월을 비교하는 이유는 같은 회원이 같은 강좌를 다른 월에 다시 신청할 수도 있기 때문이다.

### 9-2. 중복 확인 함수

```python
def check_enroll(conn, member_id, selected_course):
    for enrollment in conn.execute(
        "SELECT member_id FROM enrollments "
        "WHERE member_id = %s AND course_id = %s AND enroll_month = %s",
        (member_id, selected_course, MONTH)
    ):
        return True

    return False
```

- 조회된 신청 내역이 있으면 `True`
- 조회된 신청 내역이 없으면 `False`

### 오늘 발생했던 변수 이름 오류

```python
def check_enroll(conn, member_id, selected_course):
    ...
    (member_id, course_id, MONTH)
```

함수에서 `selected_course`를 매개변수로 받았지만 내부에서는 정의되지 않은 `course_id`를 사용해 오류가 발생했다.

올바른 코드:

```python
(member_id, selected_course, MONTH)
```

**함수를 호출할 때 전달하는 변수 이름과 함수의 매개변수 이름은 달라도 되지만, 함수 내부에서는 정의된 매개변수 이름을 사용해야 한다.**

### 9-3. MONTH를 대문자로 작성하는 이유

```python
MONTH = "2026-11"
```

Python에서는 고정된 설정값처럼 사용하는 상수를 대문자로 작성하는 관례가 있다.

하지만 실제로 변경이 금지되는 것은 아니다.

## 10. 수강신청 최종 확인 기능

### 10-1. confirm_enroll 함수

```python
def confirm_enroll():
    answer = input("수강 신청하시겠습니까? (Y/N) ")

    if answer == "Y" or answer == "y":
        return True
    else:
        return False
```

사용자가 `Y` 또는 `y`를 입력하면 `True`를 반환한다.

그 외 입력은 `False`를 반환한다.

### 10-2. AND와 OR의 차이

처음 작성했던 코드:

```python
if answer == "Y" and answer == "y":
```

한 변수의 값이 동시에 `"Y"`이면서 `"y"`일 수 없기 때문에 이 조건은 참이 될 수 없다.

수정한 코드:

```python
if answer == "Y" or answer == "y":
```

| 연산자 | 의미 |
|---|---|
| `and` | 모든 조건이 참이어야 함 |
| `or` | 하나 이상의 조건이 참이면 됨 |
| `not` | 참과 거짓을 반대로 판단 |

### 10-3. 함수를 호출할 때 괄호 사용

잘못된 예:

```python
confirm_enroll
```

올바른 예:

```python
confirm_enroll()
```

함수 이름만 쓰는 것과 실제 함수를 실행하는 것은 다르다.

## 11. main()에서 전체 기능 연결

오늘 가장 중요한 학습은 각 함수의 역할을 구분하고 `main()`에서 실행 순서를 구성하는 것이었다.

최종적으로 다음과 같은 흐름을 만들었다.

```python
def main():
    with psycopg.connect(DSN, row_factory=dict_row) as conn:

        # 전체 강좌 목록
        list_courses(conn)

        # 강좌명 검색
        search_name = input("검색할 강좌명을 입력하세요: ")
        search_courses(conn, search_name)

        # 강좌 선택 및 수강료 조회
        selected_course = int(input("신청할 강좌의 번호를 입력하세요: "))
        fee = find_fee(conn, selected_course)

        if fee is None:
            print("존재하지 않는 강좌입니다.")
            return

        print(f"수강료는 {fee:,}원 입니다.")

        # 회원 ID 조회
        name = input("회원 이름을 입력하세요: ")
        member_id = find_member_id(conn, name)

        if member_id is None:
            print("등록되지 않은 회원입니다.")
            return

        print(f"회원 번호는 {member_id}번 입니다.")

        # 수강신청 의사 확인
        if confirm_enroll() == False:
            print("수강 신청을 취소했습니다.")
            return

        # 중복 신청 확인
        if check_enroll(conn, member_id, selected_course):
            print("이미 수강 신청한 강좌입니다.")
            return

        # 수강신청 등록
        enroll(conn, member_id, selected_course)
```

위 코드는 오늘 작성한 최종 `main()`의 구조를 정리한 것이다. 다른 함수의 정의와 DSN, MONTH 등의 설정값이 함께 있어야 실행된다.

### 함수별 역할

| 함수 | 역할 |
|---|---|
| `list_courses()` | 전체 강좌 조회 |
| `search_courses()` | 강좌명 부분 검색 |
| `find_fee()` | 수강료 조회 |
| `find_member_id()` | 회원 ID 조회 |
| `confirm_enroll()` | Y/N 확인 |
| `check_enroll()` | 중복 신청 확인 |
| `enroll()` | 실제 수강신청 저장 |
| `main()` | 실행 순서 관리 |

**중요한 깨달음:** 함수를 만드는 것만으로 프로그램이 완성되는 것이 아니다. 각 함수의 역할을 구분하고 `main()`에서 적절한 순서로 호출해야 하나의 프로그램이 된다.

## 12. f-string을 이용한 출력 정렬

오늘 강좌 검색 결과를 보기 좋게 정렬하는 방법도 학습했다.

```python
print(
    f"강좌명 : {course['course_name']:<15} | "
    f"강좌 번호 : {course['course_id']:>2} | "
    f"가격 : {course['fee']:>8,}원"
)
```

| 표현 | 의미 |
|---|---|
| `:<15` | 최소 15칸, 왼쪽 정렬 |
| `:>2` | 최소 2칸, 오른쪽 정렬 |
| `:>8,` | 천 단위 쉼표 포함, 최소 8칸 |
| `:^10` | 최소 10칸, 가운데 정렬 |

### 한글 정렬 문제

한글은 보통 영문보다 터미널에서 더 넓게 표시된다.

따라서 Python의 f-string 정렬 폭만 지정하면 한글과 영문이 섞인 강좌명이 정확하게 정렬되지 않을 수 있다.

또한 `:<15`는 글자를 15개로 자르는 문법이 아니라 최소 출력 폭을 확보하는 문법이다.

## 13. 수강신청 INSERT와 ON CONFLICT

```python
conn.execute(
    "INSERT INTO enrollments (member_id, course_id, enroll_month, status, pay_amount) "
    "VALUES (%s, %s, %s, '수강중', %s) "
    "ON CONFLICT (member_id, course_id, enroll_month) DO NOTHING",
    (member_id, course_id, MONTH, fee)
)
```

### 문법 설명

- `INSERT INTO` : 신청 데이터 추가
- `VALUES` : 저장할 값 지정
- `ON CONFLICT` : 유일성 제약 조건 등에 충돌이 발생했을 때 처리
- `DO NOTHING` : 충돌이 발생하면 INSERT를 수행하지 않음

### 주의할 점

현재 코드에서는 INSERT가 생략되어도 다음 메시지가 출력될 수 있다.

```python
print("수강신청 완료되었습니다.")
```

따라서 실제 INSERT 성공 여부까지 판별하려면 추가 처리가 필요하다.

이번 과제에서는 `check_enroll()`로 등록 전에 중복 여부를 먼저 조회하고, `ON CONFLICT`도 유지했다.
