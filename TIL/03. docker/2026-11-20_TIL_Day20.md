## 1. Python 리스트와 NumPy 배열

### 1-1. Python 리스트 연산

```python
amounts = [3200, 1500, 15000, 6500, 32000, 4800,
           10900, 1500, 2700, 3000, 18500, 7000]

print(amounts)
print("합계:", sum(amounts))   # 106600
print(amounts * 2)          # 리스트를 2번 이어 붙임
print("===" * 3)            # =========
```

- `sum(amounts)`: 리스트에 있는 숫자의 합계.
- `amounts * 2`: 금액 각각을 두 배로 만드는 것이 아니라 **리스트 전체를 두 번 반복**한다.
- 문자열도 `"===" * 3`처럼 반복할 수 있다.

### 1-2. NumPy 배열 생성과 계산

```python
import numpy as np

arr = np.array(amounts)  # 리스트 → NumPy 배열(ndarray)
print(arr * 2)           # 각 원소의 금액을 2배로 계산

print("합계:", arr.sum())       # 106600
print("평균:", round(arr.mean()))  # 8883
print("최소:", arr.min())       # 1500
print("최대:", arr.max())       # 32000
print("모양:", arr.shape)       # (12,)
print("자료형:", arr.dtype)      # 환경에 따라 정수 dtype 표시
```

| 코드 | 의미 |
|---|---|
| `np.array(리스트)` | 리스트를 NumPy 배열로 변환 |
| `arr * 2` | 각 원소에 2를 곱함 |
| `arr.sum()` | 합계 |
| `arr.mean()` | 평균 |
| `arr.min()` / `arr.max()` | 최솟값 / 최댓값 |
| `arr.shape` | 배열의 형태: `(12,)`는 원소 12개인 1차원 배열 |
| `arr.dtype` | 원소의 자료형 |
| `round(값, 2)` | 소수점 아래 둘째 자리로 반올림 |

**문법 복습:** `.sum()`은 호출하는 *메서드*이고, `.shape`와 `.dtype`은 괄호 없이 읽는 *속성*이다.

### 1-3. NumPy 조건 비교와 불리언 인덱싱

```python
print(arr >= 10000)  # 각 원소에 대한 True/False 배열
arr[arr >= 10000]    # array([15000, 32000, 10900, 18500])
```

1. `arr >= 10000`으로 각 원소가 조건을 만족하는지 검사한다.
2. `arr[조건식]`으로 조건이 `True`인 원소만 추출한다.

## 2. Python 반복문으로 특정 카테고리 합산

```python
shops = ["편의점", "버스", "영화관", "분식집", "온라인쇼핑", "카페",
         "음원앱", "버스", "편의점", "웹툰", "온라인쇼핑", "분식집"]

categories = ["식비", "교통", "문화", "식비", "쇼핑", "식비",
              "문화", "교통", "식비", "문화", "쇼핑", "식비"]

food = 0
for c, a in zip(categories, amounts):
    if c == "식비":
        food = food + a

print("식비:", food)  # 24200
```

- `zip(categories, amounts)`: 같은 위치의 카테고리와 금액을 한 쌍으로 묶는다.
- `for c, a in ...`: 쌍을 반복하며 `c`와 `a`에 각각 대입한다.
- `if c == "식비"`: 식비에 해당하는 금액만 누적한다.
- 이후 Pandas에서는 같은 일을 조건 필터링과 `.sum()`으로 간단히 처리할 수 있다.

## 3. Pandas DataFrame 만들고 살펴보기

```python
import pandas as pd

spend = pd.DataFrame({
    "day": [2, 3, 4, 5, 7, 15, 17, 19, 20, 22, 25, 30],
    "shop": shops,
    "category": categories,
    "amount": amounts
})

spend.shape   # (12, 4): 12행 4열
spend.head(5)  # 위에서부터 5행 출력
spend.info()   # 열별 자료형, 비결측 값 개수, 메모리 정보 등
```

- **DataFrame:** 행(row)과 열(column)로 구성된 2차원 표 형태 데이터.
- **Series:** DataFrame에서 열 하나를 선택했을 때 주로 얻는 1차원 데이터.
- `head(5)`는 **현재 행 순서 기준 상위 5행**이다. 금액이 큰 5건이라는 뜻은 아니다.

### 하나의 열 vs 여러 열 선택

```python
spend["amount"]             # 한 열 선택 → Series
spend["shop"]               # 상점 열 선택 → Series
spend[["shop", "amount"]]   # 두 열 선택 → DataFrame

print("합계:", spend["amount"].sum())            # 106600
print("평균:", round(spend["amount"].mean(), 2)) # 8883.33
```

- 한 열은 `spend["amount"]`처럼 **대괄호 한 겹**.
- 여러 열은 열 이름 리스트를 전달하므로 `spend[["shop", "amount"]]`처럼 **대괄호 두 겹**.
- 실제 열 이름은 `amount`이며 `amounts`가 아님. `amounts`는 Python 리스트 변수 이름이다.

## 4. Pandas 조건식과 불리언 인덱싱

### 4-1. 조건 검사와 행 추출의 차이

```python
spend["category"] == "문화"           # 조건 검사: True/False Series
spend[spend["category"] == "문화"]    # 조건을 만족하는 행 전체 추출

spend["amount"] >= 10000              # 금액별 True/False
spend[spend["amount"] >= 10000]       # 10000원 이상인 행 전체 추출
```

`spend["amount"]`는 한 **열**을 선택하지만, `spend[조건식]`은 조건이 `True`인 **행**을 선택한다. 조건 필터링 결과에는 `day`, `shop`, `category`, `amount` 등의 열이 함께 남는다.

**SQL과 연결하기**

```sql
SELECT *
FROM spend
WHERE amount >= 10000;
```

위 SQL의 `WHERE`와 Pandas의 `spend[spend["amount"] >= 10000]`은 비슷한 필터 역할을 한다.

### 4-2. 여러 조건 동시에 적용

```python
# 식비이면서 5000원 이상
spend[(spend["category"] == "식비") & (spend["amount"] >= 5000)]
```

- `&`: 두 조건을 **모두** 만족 (AND).
- 각 비교 조건을 `( )`로 묶는다.
- 이 데이터에서는 **분식집 6500원과 분식집 7000원**, 두 행이 추출된다.
- 참고: `|`는 두 조건 중 하나라도 만족 (OR)할 때 사용한다. *(추가 복습)*

## 5. 정렬하기

```python
top4 = spend.sort_values("amount", ascending=False).head(4)
top4
```

- `sort_values("amount")`: `amount` 열을 기준으로 정렬.
- `ascending=True`: **오름차순**(작은 값 → 큰 값), 기본값.
- `ascending=False`: **내림차순**(큰 값 → 작은 값).
- `.head(4)`: 정렬 결과 중 앞에서 4행 선택.
- 따라서 `top4`는 **지출 금액이 가장 큰 4건**이다.

## 6. 새 열 생성과 데이터 수정

### 6-1. 포인트 열 추가

```python
spend["point"] = spend["amount"] // 100
print(spend["point"].sum())  # 1066 (금액 변경 전)
spend
```

- `spend["point"] = 계산식`: `point` 열을 새로 만들고 계산한 값을 저장한다.
- `//`: 나눗셈의 **몫을 내림한 값**을 구한다. 여기서는 100원당 1포인트 계산.
- `/`: 일반 나눗셈, `%`: 나머지 연산.
- 예: `3200 // 100 → 32`, `3200 / 100 → 32.0`, `3200 % 100 → 0`.

### 6-2. `.loc`로 특정 데이터 수정

```python
spend.loc[2, "amount"] = 14000  # 인덱스 레이블 2번 행의 amount를 14000으로 변경
spend["point"] = spend["amount"] // 100  # 변경된 금액으로 포인트 다시 계산
spend
```

- `.loc[행 레이블, 열 이름]`: 행·열 **레이블**로 값 조회 또는 수정.
- 여기서 `2`는 `day` 값이 2라는 뜻이 아니라 **행 인덱스 레이블이 2**라는 뜻이다. 실제로는 영화관의 15000원을 14000원으로 수정.
- `amount` 값을 바꿔도 예전에 계산한 `point` 값이 **자동 재계산되지는 않음**. 별도로 재대입해야 한다.
- 수정 후 전체 합계는 **105600원**, 포인트 합계는 **1056점**이 된다.

## 7. 그룹별 분석

### 7-1. `groupby()` — 같은 값끼리 그룹화

```python
spend.groupby("category")["amount"].sum()
```

`category` 값이 같은 행을 묶고, 그룹마다 `amount` 합계를 구한다. SQL의 `GROUP BY category`와 유사하다.

**영화관 금액을 14000원으로 수정한 뒤 결과**

| 카테고리 | 지출 합계 |
|---|---:|
| 교통 | 3,000원 |
| 문화 | 27,900원 |
| 쇼핑 | 50,500원 |
| 식비 | 24,200원 |

### 7-2. `sort_values()` — 그룹별 합계 정렬

```python
spend.groupby("category")["amount"].sum().sort_values(ascending=False)
```

- 먼저 카테고리별 금액을 합산한다.
- 이후 합계가 큰 순서로 정렬한다.
- 결과 순서: **쇼핑(50,500) → 문화(27,900) → 식비(24,200) → 교통(3,000)**.

### 7-3. `value_counts()` — 각 값이 나온 횟수

```python
spend["category"].value_counts()
```

| 카테고리 | 결제 횟수 |
|---|---:|
| 식비 | 5 |
| 문화 | 3 |
| 교통 | 2 |
| 쇼핑 | 2 |

- `groupby(...).sum()`: **얼마를 썼는지** (금액 합계).
- `value_counts()`: **몇 번 썼는지** (등장 횟수).

## 9. 오늘 만난 오류와 해결 방법

### 9-1. `IndentationError: unexpected indent`

**원인:** `if`, `for`, `def` 같은 코드 블록이 없는데 `print()` 앞에 불필요한 들여쓰기를 넣음.

```python
# 잘못된 예
# spend["shop"]
    # print("합계:", spend["amount"].sum())  # 앞에 공백이 있으면 오류

# 올바른 예
print("합계:", spend["amount"].sum())
```

**해결:** 블록 바깥의 불필요한 들여쓰기 제거.

### 9-2. `NameError: name 'spend' is not defined`

**원인:** 현재 Jupyter 커널에 `spend` 변수가 존재하지 않았음. 커널 재시작·변경이나 생성 셀의 미실행 등 여러 원인이 가능하며, 정확히 무엇이 일어났는지는 확인되지 않음.

**해결:** `spend = pd.DataFrame(...)`가 있는 셀부터 필요한 셀을 다시 실행하니 해결됨.

```python
print("spend" in globals())  # 현재 커널에 해당 변수가 존재하는지 확인
```

- Jupyter Notebook의 **셀 배치 순서와 실행 순서는 서로 다를 수 있음**.
- VS Code Notebook 상단 **Run All(모두 실행)**로 필요한 변수들을 순서대로 생성할 수 있음.
- 단, 파일 수정·저장·삭제와 같은 부작용이 있는 셀이 있다면 전체 실행 전에 확인.

## 10. 헷갈리지 말아야 할 핵심 비교

| 헷갈리는 개념 | 차이 |
|---|---|
| `amounts * 2` vs `arr * 2` | 리스트 반복 vs 배열의 원소별 곱셈 |
| `spend["amount"]` vs `spend[["shop", "amount"]]` | Series 한 열 vs DataFrame 여러 열 |
| `spend["amount"] >= 10000` vs `spend[조건식]` | True/False 판별 vs 조건에 맞는 행 추출 |
| `head(4)` vs `sort_values(...).head(4)` | 단순 앞 4행 vs 정렬 후 상위 4행 |
| `ascending=True` vs `False` | 오름차순 vs 내림차순 |
| `.sum()` vs `.value_counts()` | 값의 합계 vs 값의 등장 횟수 |
| `.loc[2, "amount"]` vs `spend["day"] == 2` | 인덱스 레이블 2인 행 vs day 값이 2인 행 |
| `arr.shape` vs `arr.sum()` | 속성 조회 vs 메서드 실행 |
